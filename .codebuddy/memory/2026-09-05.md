## 共用「字段选择导出」组件 —— 设计已定稿（待实现）

- 用户需求：表格页导出 Excel，弹窗勾选字段、默认全选、支持拖拽排序决定导出列顺序；字段来源 = 表格全列（含隐藏列）+ 页面可追加字段；分页场景要能拉全量。
- **经多轮澄清后的最终交付形态**：两套入口共用同一个字段勾选弹窗子组件。
  - 入口 A `table-export.vue`：绑定 vxe-table 实例，走官方导出插件 `vxe-table-plugin-export-xlsx`（依赖注入 exceljs），确认后调实例 `exportData({ filename, sheetName, type:'xlsx', columns, data })`。
  - 入口 B `data-export.vue`：不依赖表格，调用方传字段清单 + 行数据，纯 `exceljs` 生成下载。
  - 共用子组件 `field-select-dialog.vue`（纯 UI，NModal + VueDraggable + checkbox，参考 advanced/table-column-setting.vue 风格，含全选/半选/重置/拖拽，confirm 回传勾选且排序后的字段）。
- Excel 引擎：**全项目仅引入 exceljs 一个依赖**，vxe 插件与入口 B 共用，避免两份 Excel 引擎。vxe 插件版本适配 vxe-table 4.0~4.6（本项目 4.5.9 恰好匹配；该插件已停止维护，vxe 4.7+ 官方改用 @vxe-ui/plugin-export-xlsx）。
- 数据范围：组件默认导当前 data；可选传 `fetchAll` 回调拉全量（有则优先）。
- 触发方式：页面放导出按钮打开弹窗（按钮样式页面控制）。
- 落地结构：`src/components/Export/`（index.ts / type.ts / field-select-dialog.vue / table-export.vue / data-export.vue / export-xlsx.ts）。
- 关键改动：通用 `src/components/Table/table.vue` 需 `defineExpose` 内部 vxe-table 实例（一行，供入口 A 调用真实 exportData）。
- 验证页：`views/system-manage/user/index.vue` 接入口 A（含 status 列导出为文案、fetchAllUsers mock）。
- 详细设计文档：`changelog/共用导出组件设计.md`（已写入 AGENTS_CHANGELOG 2026-09-05 组）。
