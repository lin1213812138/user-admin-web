- 关键技术事实（下次复用）：
  - `NFormWrap` 是本地组件（`@/components/Form/index.vue` 默认导出），**不是** naive-ui 导出；模板里必须显式 `import NFormWrap from '@/components/Form/index.vue'`，否则 build 报 `NFormWrap is not exported by naive-ui`。
  - `bwip-js` 用 `bwip-js/browser` 子路径导入（带类型），`import * as bwipjs`。
  - 条码/二维码/图片用 `<img>` 渲染，浏览器默认 `<img draggable>` 会劫持拖拽事件，导致无法整体移动元素。元素渲染器里必须加 `draggable="false"`。
  - 路由生成靠 elegant-router 的 vite 插件（`pnpm dev`/`build` 扫描 views），`sa gen-route` 是脚手架命令、会交互式要路由名，不能用来整目录重新生成。
  - `print-format` service DEV 返回裸数据、prod 走 request 包裹，index.vue 按 DEV 裸数据 cast 消费。

## label-designer：右侧属性面板视觉优化

- 问题：X/Y/宽/高数字精度太长撑开输入框、整体布局平铺且能滚动，用户觉得难看。
- `property-panel.vue` 优化：
  - 位置/尺寸数值统一 `round2` 保留两位小数（`Math.round(n * 100) / 100`），避免 `40.7392095253...` 这种长串。
  - 颜色字段（文本 color、矩形 borderColor/bgColor、线条 borderColor）改用取色器。
  - 按「位置与尺寸」「内容与绑定」「样式」三个 `NCard` 分组展示，间距更清爽。
  - 删除按钮继续固定在面板底部。
- `components/Form` 扩展：新增 `type: 'color'`，底层渲染 `NColorPicker`；`form-config.ts` 同步扩展类型定义。
- 修复横向溢出：面板根容器加 `min-w-0 overflow-hidden`、卡片与栅格项加 `min-width:0`，并把原先两列（span 12）的表单项统一改成单列（span 24），避免右侧面板过窄时内容冲出边界。
- store 新增：`duplicateElement`(复制+偏移4mm)、`copyElement`/`pasteElement`(剪贴板复制粘贴,新增 `clipboard` ref)、`bringToFront`/`sendToBack`(置顶/置底)、`moveLayer(id,dir)`(上移/下移一层)。均已 `commit()` 进撤销栈，并导出。
- `design-canvas.vue`：用 naive-ui `NDropdown`(`trigger="manual"` + `:x/:y/:show`) 实现右键菜单；元素与纸张空白处均绑定 `@contextmenu.prevent="openMenu"`；空白处右键仅在有剪贴板时显示「粘贴」。菜单项：复制元素/删除/分隔/上移一层/下移一层/置于顶层/置于底层/分隔/复制到剪贴板，及条件项「粘贴」。
- 交互修复：`begin` 与 `onViewportPointerDown` 均加 `e.button !== 0` 守卫，右键只弹菜单、不误启拖拽或记空撤销点。
