## 打印设计标尺不显示（根因：设计画布未加载 hiprint 全局 CSS；二次根因：NScrollbar 裁剪）

- 现象：画布左上角无 mm 刻度尺。DOM 中 `.hiprint_rul_wrapper` 及其 `.h_img`/`.v_img` 的 `src` 都是有效的 base64 SVG，元素存在。
- 根因：标尺依赖 hiprint 的 class 样式，而本仓库只在预览 iframe 引入 `print-lock.css`，设计画布从未加载该样式。设计器其他视觉靠 hiprint 行内样式存活，唯独标尺全靠 class CSS 所以塌缩。
- 修复：
  1. `index.vue` 全局 `<style>` 显式补充 `.hiprint_rul_wrapper` / `.h_img` / `.v_img` 样式，限定作用域 `#hiprint-printTemplate`，不影响预览 iframe。
  2. 二次修复：标尺通过 `margin: -16px` 伸出纸张外，但被包裹 `#hiprint-printTemplate` 的 `NScrollbar` 的 `overflow: hidden` 容器裁剪（100% 时不可见，放大后可见）。给 `#hiprint-printTemplate` 加 `position: relative; padding: 16px;`，让标尺负 margin 区域落在容器 padding 内，不被裁剪。

## 打印预览测试数据不更新（根因：固定 sample 覆盖 testData）

- 现象：右侧属性面板改字段「测试数据」后预览仍显示原始示例值。
- 根因：`instance.getHtml(buildSampleData())` 传入固定示例数据，hiprint 对绑定字段元素按 `data[field] ?? testData` 渲染，固定 `data[field]` 非空直接覆盖了用户改过的 `testData`。
- 修复：`index.vue` 新增 `extractPreviewData(fallback)`，遍历 `instance.getJson()` 的 `printElements`，把每个 `options.field` 对应的最新 `options.testData`（非空）作为预览填充数据，未编辑字段回退固定示例值；`handlePreview` 改用 `instance.getHtml(extractPreviewData(buildSampleData()))`。仍走 `instance.getHtml()`，不违反 round-trip 禁令。

- 补丁：Task5 集成时 `FormItemConfig` 漏了决定触发区形态的 `mode` 字段，已补 `mode?: UploadMode` 并透传给 `<Upload :mode>`；否则 `type:'upload'` 默认 text 永远显示按钮。用法：`{ type:'upload', mode:'image', accept:'image/*' }` 显图片框，`mode:'card'` 卡片网格，省略则默认 text。
- **重要修复**：原 `Upload` 组件 prop 名是 `listType`（不是 `mode`），且 `FormItemConfig.mode` 字段类型一开始错写成了 `UploadMode`（语义是 'auto'|'manual'）。结果 `<Upload :mode="item.mode">` 中 `mode` 被 Vue 当 fallthrough attr 忽略，组件永远走默认 `listType:'text'` 显示按钮，typecheck 也不报错（attr 不检查类型）。统一重命名：`ListType → Mode`（形态 'text'|'image'|'card'），Upload prop 也改名为 `mode`，与 FormItemConfig.mode 对齐；`UploadMode` 保留为 'auto'|'manual'（上传触发模式）。改 ExportFormat.vue 的 `mode="image"` 现在能真正生效。
- **三模式分离（参考 antd/el-upload 的 listType+drag）**：`Mode` 现在为 `'text' | 'image' | 'card' | 'drag'`。`text`=按钮+文本列表；`image`=单图框（仅点击）；`card`=图片网格+末尾加号；`drag`=大虚线拖拽区+文本列表。关键：`@drop` 只绑在 `mode==='drag'` 的大区域，image/card 框**不响应拖拽**，避免拖拽与图片框混。FormItemConfig 冗余的 `listType` 字段 + Form/index.vue 的 `:list-type` 绑定已删除（Volar 报“未知属性”的根因）。
