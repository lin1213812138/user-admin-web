## pnpm release 首次报错（根因：仓库无 git tag）

- `pnpm release` = `sa release`（`packages/scripts/src/commands/release.ts`），基于 bumpp，是**交互式**命令（需真实终端用方向键选版本后回车）。
- 报错 `fatal: No names found, cannot describe anything.` 根因是**仓库没有任何 git tag**，bumpp 与 `@soybeanjs/changelog` 都靠 `git describe` 定位上一个版本作基准；无 tag 时 changelog 静默空跑、release 卡死/报错。
- bumpp **不会自动建基准 tag**，首次发版必须先手动建一个本地 tag（已执行 `git tag v0.0.0`，`git describe --tags --abbrev=0` 已能返回 `v0.0.0`）。
- 修复后用法：真实终端 `pnpm release` → 选 `next/patch`（→ 0.0.1）回车。若需远端也有基准再 `git push origin v0.0.0`。讨论记录：`changelog/pnpm-release命令报错诊断.md`。

## 路由：非菜单路由与菜单路由分离（已实现，含踩坑）

- 需求：用户要在 `src/router/elegant/routes.ts` 本文件里把非菜单路由与菜单路由分开。
- **关键约束（踩坑，务必记住）**：`generatedRoutes` **必须是字面量数组**。`@elegant-router/vue/vite` 插件在 dev/build **启动时**用 magicast 解析 `routes.ts`，读取 `generatedRoutes` 的真实路由数据（用于重新生成时保留手工 meta，如 icon/order）。因此任何非字面量写法都会让启动直接崩：
  - `[...nonMenuRoutes, ...menuRoutes]` → `MagicastError: Casting "SpreadElement" is not supported`（vite build 直接 exit 1）。
  - `nonMenuRoutes.concat(menuRoutes)` → `TypeError: r.forEach is not a function`（插件拿不到数组）。
  - 插件配置在 `build/plugins/router.ts`（`ElegantVueRouter`），无选项可关闭该解析行为。
- 用户最终选择（2026-09-01，**已落地**）：**单字面量 + 派生**。`generatedRoutes` 只保留一个字面量数组（即插件生成的全部 8 条，原样不动、给插件用），`nonMenuRoutes`/`menuRoutes` 改为在 `routes.ts` 末尾用 `generatedRoutes.filter(...)` 派生：
  - 判定函数：`isNonMenuRoute = (r) => Boolean(r.meta?.constant) || Boolean(r.meta?.hideInMenu)`。
  - `nonMenuRoutes = generatedRoutes.filter(isNonMenuRoute)`；`menuRoutes = generatedRoutes.filter(r => !isNonMenuRoute(r))`。
  - **零重复**（路由对象只在 `generatedRoutes` 写一次），`generatedRoutes` 仍是字面量 → 插件正常；新增页面只改 `generatedRoutes`（插件自动生成），拆分自动跟随，无需手动同步。这是比"三处字面量"更优的终版。
  - 已验证 `read_lints` 0 error；运行时 `createBuiltinVueRoutes()` 走 `routes/builtin.ts`，并不读 `generatedRoutes`，派生数组不干扰运行时。
- 插件重新生成时（`ne()` 里 `D(n)` 整文件按 AST 输出）会保留 `nonMenuRoutes`/`menuRoutes` 这两个附加导出与 `isNonMenuRoute` helper，不会丢失。
- 分组结果：`nonMenuRoutes` = 403/404/500/iframe-page/login；`menuRoutes` = home + data-manage(+3) + system-manage(+3)。
- `routes/index.ts` 的 `createStaticRoutes()` 已按 `meta.constant` 分 `constantRoutes`/`authRoutes`；本项目"非菜单"恰好等于"constant"，但以 `hideInMenu` 判定可见性更准（若以后出现"常驻但显示菜单"或"不常驻但隐藏"路由）。
- 排查手法：`pnpm build > build.log 2>&1` 再用 `Select-String` 过滤 `MagicastError|TypeError|built in` 提取真实报错（PowerShell 下 `head` 不可用）。注意构建耗时长，重复执行可能因日志文件被占用而失败。
