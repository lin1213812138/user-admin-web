## pnpm release 首次报错（根因：仓库无 git tag）

- `pnpm release` = `sa release`（`packages/scripts/src/commands/release.ts`），基于 bumpp，是**交互式**命令（需真实终端用方向键选版本后回车）。
- 报错 `fatal: No names found, cannot describe anything.` 根因是**仓库没有任何 git tag**，bumpp 与 `@soybeanjs/changelog` 都靠 `git describe` 定位上一个版本作基准；无 tag 时 changelog 静默空跑、release 卡死/报错。
- bumpp **不会自动建基准 tag**，首次发版必须先手动建一个本地 tag（已执行 `git tag v0.0.0`，`git describe --tags --abbrev=0` 已能返回 `v0.0.0`）。
- 修复后用法：真实终端 `pnpm release` → 选 `next/patch`（→ 0.0.1）回车。若需远端也有基准再 `git push origin v0.0.0`。讨论记录：`changelog/pnpm-release命令报错诊断.md`。
