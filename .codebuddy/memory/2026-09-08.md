## 通用 Table 表头高度 / 垂直居中修复（第二次）

- 用户反馈第一版修复无效（表头仍偏高、文字贴顶）。
- 根因有二：
  1. **CSS 根本没进 DOM**：`src/plugins/vxe-table.ts` 的 `injectScrollbarStyle()` 发现 `#vxe-table-scrollbar-style` 已存在就 `return`，dev 下改 `scrollbar.css` 走 HMR 不会更新该 style 元素。
  2. **`.vxe-cell` 高度没填满 `<th>`**：vxe-table 的 `.vxe-cell` 默认 `display:flex;align-items:center`，但默认 `padding:8px` 把单元格撑高；且 `<th>` 高 35px 而 `.vxe-cell` 只有文字高，文字停 `<th>` 顶部而非居中（align-items 居中只在 `.vxe-cell` 内部生效）。
- 修复：
  - `injectScrollbarStyle()` 改为 style 元素存在时直接更新 `textContent`（HMR/重载都能生效）。
  - `scrollbar.css` 表头规则改为：`.vxe-cell{height:35px !important; min-height:35px; padding-top/bottom:0; display:flex; align-items:center; box-sizing:border-box}`，让它填满 `<th>` 后 `align-items:center` 才真正居中。
  - `headerCellStyle` 全局与组件级都只保留 `height:'35px'`（去掉 lineHeight/textAlign 覆盖）。
- 验证：`pnpm typecheck` / `pnpm lint` 通过。用户需**刷新页面**或依赖 HMR 即可看到效果。

## 整页滚动修复（方案 A）

- 表头回退后用户反馈「整个界面滚动」。根因不是表头改动，而是 `scrollbar.css` 1.5–1.7 节的 `height:100%` 布局覆盖规则**全局生效**，强制每个 vxe-table 撑满父容器；而应用外壳内容区（GlobalContent 路由组件）是 `flex-grow` 子项（默认 `min-height:auto` 不收缩），表格建立不了内部滚动容器 → 内容铺开 → 整页滚动。
- 修复（已实施）：① `scrollbar.css` 1.5–1.7 全部加 `.vxe-table.h-full` 作用域，只对 `height:'100%'` 的表格生效；② `table.vue` 的 `<vxe-table>` 在 `height==='100%'` 时加 `:class="'h-full'"`；③ `field-select-dialog.vue` 的 vxe-table 始终 `height="100%"`，加 `class="h-full"`；④ `global-content/index.vue` 路由组件补 `min-h-0`，让 flex 子项可收缩、表格 `height:100%` 能解析到有限高度建立内部滚动。
- 数字高度 / auto 高度的表格走 vxe 默认行为，不再被全局规则干扰。

## vxe-table 竖向撑满容器

- 用户反馈表格主体未占满页面（下方留白）。根因：`Table.vue` 根元素是 `h-full flex flex-col`，但包裹 `<vxe-table>` 的内部容器只在 `height==='100%'` 时加 `flex-1`，当外层父级不是 flex 容器时 `flex-1` 失效，导致 `<vxe-table height="100%">` 解析不到确定高度，表格按内容收缩。
- 修复：`src/components/Table/table.vue` 中表格容器在 `height==='100%'` 时同时加 `flex-1 h-full`，既在 flex 布局下伸缩，也在 block 布局下占满父级高度。

## vxe-table render-wrapper 被 JS 内联高度限制

- 刷新后发现 `.vxe-table` padding 实际已是 0；进一步排查发现 `.vxe-table--render-wrapper` 的 `height` 被 vxe-table JS **内联写死为 690px**（`el.style.cssText` 中有 `height: 690px`），这才是 8px 留白的真正来源。

- 刷新页面后验证。

## vxe-table 底部 8px 横向滚动条预留轨道

- 解决 render-wrapper 内联高度后，表格底部仍留约 8px 白边。用户确认这不是 `mt-12px`（分页上边距），而是**横向滚动条的预留轨道高度**。

- 修复：`src/plugins/vxe-table.ts` 的 `scrollbarConfig.height` 由 `8` 改为 `0`；`.vxe-table--scroll-x-handle` 的实际高度仍由 `scrollbar.css` 的 `height: 8px !important` 强制渲染（浮动覆盖、不占布局）。
- 注意：`VxeUI.setConfig` 在 `setupVxeTable` 中，dev 下需刷新页面（或重启 dev server）生效。
