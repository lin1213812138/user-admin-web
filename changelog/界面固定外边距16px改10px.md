# 界面固定外边距 16px → 10px

> 日期：2026-09-18
> 触发：用户要求「每个界面固定加的 p-16px 能不能改成 p-10px」，并明确范围为「所有界面」。

## 1. 背景与定位

仓库所有界面（路由页/竖排 tab 页）的外边距统一来源于 **3 个源头**，其余页面根 div 写的 `p-16px` 只是与 layout 兜底同名的原子类，视觉不叠加：

| 源头          | 文件:行（改前）                                                                           | 作用范围                                                                     |
| ------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 布局兜底      | `src/layouts/modules/global-content/index.vue:50`（`:class="{ 'p-16px': showPadding }"`） | 所有非排除路由页（`base-layout` 的 `contentShowPadding` 排除列表之外的页面） |
| 竖排 tab 右栏 | `src/components/VerticalTabLayout/index.vue:114`（`p-16px`）                              | setting / data-manage\* / personal-center 等走 `VerticalTabLayout` 的页面    |
| 通栏贴边补偿  | `src/components/Table/table.vue:261`（`-mx-16px -mt-16px`）                               | `searchActionFlush` 开启时抵消父容器 16px 实现快速搜索栏通栏贴边             |

`p-10px` 是 UnoCSS presetWind3 支持的任意值原子类，无需额外配置即可生效。

## 2. 决策（方案 A：原子类直改）

经确认采用方案 A（非方案 B 引入统一 CSS 变量），直接把全站固定外边距相关原子类 16px → 10px，改动小、风险低、立即生效。

## 3. 改动清单（共 14 处 + 1 文档）

**源头（必改）**

- `src/layouts/modules/global-content/index.vue:50` → `p-10px`
- `src/components/VerticalTabLayout/index.vue:114` → `p-10px`（标题行 `px-16px` 同步 → `px-10px`）
- `src/components/Table/table.vue`
  - `:261` `-mx-16px -mt-16px` → `-mx-10px -mt-10px`
  - 注释（54 行、259 行）`p-16px`/`外扩 16px` 同步 → `p-10px`/`外扩 10px`

**同源重复（页面根 div，为一致性一并改）**

- `src/views/system-manage/user/index.vue:237`、`site/index.vue:240`、`role/index.vue:240`、`log/index.vue:157`、`group/index.vue:242` → `p-10px`
- `src/views/customer-manage/customer/index.vue:212` → `p-10px`

**设置页内部容器（同为界面固定 padding，一并统一）**

- `src/views/system-manage/setting/components/MasterDetail.vue:102,137` `px-16px py-16px` → `px-10px py-10px`
- `src/views/system-manage/setting/components/FieldMapping.vue:125` `px-16px py-16px` → `px-10px py-10px`
- `src/views/system-manage/setting/modules/trace-capture/TraceCapture.vue:39` `px-16px py-16px` → `px-10px py-10px`

**特例页面左内边距**

- `src/views/channel-quote/ship/index.vue:197`、`receive/index.vue:197` `pl-16px` → `pl-10px`

**组件文档**

- `src/components/VerticalTabLayout/README.md` 两处 `p-16px` 描述同步 → `p-10px`

## 4. 明确不纳入（边界）

以下属于卡片/弹窗/图标内部样式，非「界面固定外边距」，保持不变：

- `Table` 的 `NCard` `content-style: padding: '12px 16px'`（卡片内部）
- `home/modules/card-data.vue`、`label-designer` 预览弹窗 `p-16px pb-32px`、各 `theme-drawer` 内部
- 所有 `text-16px` / `gap-16px`（图标尺寸、元素间距，非容器外边距）
- 登录页 `register.vue` / `code-login.vue` 的 `gap-16px`（登录表单内间距）

## 5. 验证

- 全仓残留 `p-16px` / `px-16px py-16px` / `pl-16px` / `-mx-16px` 已全部为上述边界内的非固定外边距场景，无遗漏。
- 静态检查：`pnpm typecheck` / `pnpm lint` 应无新增错误（纯样式类名替换，不影响类型与逻辑）。
- 视觉：`pnpm dev` 后抽查系统管理各页、设置页、个人中心、渠道报价页，确认外框内边距由 16px 收紧为 10px，快速搜索栏通栏贴边效果不变。
