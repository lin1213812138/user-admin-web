# 菜单管理多级测试数据

> 日期：2026-09-01

## 背景

菜单管理列表为树形表格（由 `buildMenuTree` 按 `parentId` 组装）。原 `mock.ts` 的 `menus` 仅 2 层（catalog → menu），无法直观验证多级展开/缩进。

## 改动

文件：`src/service/api/mock.ts`（`menus` 数组）

新增一个独立的多级分支「电商管理」，共 4 层，用于演示树形深度：

- L1 电商管理（catalog, id 30, parentId 0）
  - L2 商品中心（catalog, id 31）
    - L3 商品列表（menu, id 311）
    - L3 商品分类（menu, id 312）
  - L2 营销中心（catalog, id 32）
    - L3 优惠券管理（catalog, id 321）
      - L4 优惠券列表（menu, id 3211, status=2 禁用）
      - L4 新建优惠券（menu, id 3212, visible=2 隐藏）

使用既有 `createMenu` 帮助函数构造，显式覆盖 `routePath` / `componentPath` / `permission`，并含一个禁用项与一个隐藏项以覆盖状态渲染。

## 验证

- `pnpm typecheck` 通过。
- 菜单管理页可见新多级数据，可正常展开/收起。
