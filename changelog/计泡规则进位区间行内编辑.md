# 计泡规则 · 进位区间去框 + 行内增删

> 日期：2026-09-20 ｜ 状态：已实施，待手动冒烟 ｜ spec：`docs/superpowers/specs/2026-09-20-计泡规则进位区间行内编辑-design.md`
> 上一轮：`changelog/计泡规则进位类型改多选.md`

## 背景

用户贴「件实重和件体积重进位」组卡片截图，要求：

1. 去掉组内那个**框**（含列标题 + 暂无区间 + 加区间 的内层容器）。
2. 去掉列标题行（开始重量 / 结束重量 / 计重单位）。
3. 每组**默认带一行**区间。
4. 「新增行」按钮移到**每行右侧**，与「删行」并排。

## 定位到的问题

`WeightRuleOperateDrawer.vue` 的进位组是**两层套框**：外层组卡片（`border + rd-6px + p-12px`）里又套一层带底色的内层容器（`border + rd-4px + bg-[var(--n-fill-color)] + p-10px`）。内层容器里先渲染一行整组共用的列标题（与三个输入框的 placeholder 完全重复，且行一多就失去指引作用），空时再叠「暂无区间」，底部再挂一个整行虚线「加区间」按钮——增行入口离目标行很远，还与行内的「删行」不同源。

## 决策（设计闸门）

按 AGENTS.md 走「先设计后编码」：加载 `frontend-design` skill 定方向（克制的极简 / 一层框 / 无表头 / 就地增删，全部沿用 naive-ui token，不引入新字体色板）→ 产出 spec → `ask_followup_question` 两处岔路确认 → 实现。用户确认结论：

- 操作区形态：**图标按钮 ⊕/⊖**（非文字按钮），恒定宽度约 60px，横向空间让给三个输入框。
- 空组策略：**至少保留一行**（非允许删空），保证「进位规则组必有区间」。

## 实施

`src/views/data-manage/ship/modules/weight-rule/WeightRuleOperateDrawer.vue`

- **去框**：删除内层容器 `div.border.rd-4px.bg-[var(--n-fill-color)].p-10px`，行直接坐在组卡片上；行容器改 `space-y-8px`（行间距 8px）。
- **去表头**：删除列标题行；三列语义由输入框 placeholder（开始重量 / 结束重量 / 计重单位）承载。
- **默认一行**：新增 `emptyRule()` 返回 `{ start: undefined, end: undefined, unit: undefined }`；`selectedCarryTypes` 的 set 分支生成新组时 `ruleList: [emptyRule()]`，`addRule()` 也复用它。
- **行内增删**：行末操作区改为 `flex gap-4px` 包两枚 `LButton quaternary circle size="small"`，⊕ `icon-ic-round-add`（加区间）、⊖ `icon-ic-round-remove`（`type="error"`）；文案走 `LButton` 内置 `tooltip` prop（disabled 时自带 span 垫层，提示仍可 hover）。
- **至少一行**：新增 `canRemoveRule(group) = (group.ruleList?.length ?? 0) > 1`，为 false 时 ⊖ `disabled`，tooltip 文案切为「至少保留一行区间」。
- **兜底**：`ruleList` 为空（仅可能来自编辑态的历史数据，旧版可保存「无区间的组」）时，渲染「暂无区间」提示 + 一枚 ⊕，避免组内出现无加行入口的死局。

i18n（zh-cn / en-us）+ `src/typings/app.d.ts`：新增 `weightRule.keepOneRule`（至少保留一行区间）；复用既有 `addRule`（加区间）/ `removeRule`（删行）/ `ruleEmpty`。

## 边界（未动）

- 数据契约不变：`carryList: [{ carry, ruleList: [{ start, end, unit }] }]`，接口/列表页/后端无需改动。
- 抽屉宽度 700px、`FormWrap` 基础字段、顶部进位类型多选、组标题、提交与校验逻辑均未动。

## 追加修正（最外层框也去掉，已实施）

用户追加要求「最外层框也要去掉」。

- 组容器 class 由 `mt-12px border border-[var(--n-border-color)] rd-6px p-12px` → **`mt-16px`**：外框、圆角、内边距全部移除。
- 组间距 12px → **16px**，补足失去边框后的分组可辨识度；分组语义完全由「组标题（主题色竖条 + 进位类型名）」承载。
- 正向副作用：去掉 `p-12px` 后，行内容左边缘与 `FormWrap` 表单项对齐（原先被内边距缩进 12px）。
- 未加组间分隔线（避免视觉重新变重）。若多组连排仍难分辨，备选：极浅虚线分隔 / 弱化组标题竖条层级。
