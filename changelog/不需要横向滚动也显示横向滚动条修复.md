# 不需要横向滚动也显示横向滚动条 — 定位与修复

> 日期：2026-09-16
> 触发：用户截图（资料管理 → 财务资料 → 结算方式）底部出现横向滚动条，疑问「为什么不需要横向滚动也会显示横向滚动条？」
> 决策：用户先选「保留 hover 浮现交互」（方案 B），再确认 `--x-scrollbar-size` 用「运行时测量」（方案 A）

## 一、现象

表格列宽总和未超出容器，但 hover 表格时底部恒出现一条横向滚动条：滑块几乎占满整条轨道（约 98%），右侧留一小段空白；鼠标移出即消失。右侧纵向滚动条同理浮现。

## 二、根因（vxe-table 4.5.9 源码 + 本项目配置）

横向滚动条**不是 vxe 判定「内容溢出」后显示的**，而是三件事叠加：

1. **vxe 本意是隐藏**：`x: { visible: true }`（`src/plugins/vxe-table.ts`、`Table/table.vue:295` 两处）是布尔值，而 vxe `calcScrollbar()` 只识别字符串 `'visible' / 'hidden'` 或 `false`，`true` 不命中任何分支 → 显示与否交给 `overflowX = scrollXWidth > 主区宽度` 自动判定。列宽由 `autoCellWidth()` 按主区宽度分配（无宽度列走 `remainList` 均分兜底），分配完两者相等 → `overflowX = false`，vxe 写入的是 `visibility: hidden`。
2. **项目 CSS 强制显示回来**：`scrollbar.css` 的 `.vxe-table:hover .vxe-table--scroll-x-virtual { visibility: visible !important }` 覆盖内联 `hidden`，所以 hover 必浮现（这是刻意保留的交互）。
3. **handle 内部恒有 16px「伪溢出」，浏览器必然画滑块**：
   - 8px：JS 内联 `xWrapperEl.style.width = el.clientWidth - osbWidth`（轨道宽 = 容器宽 − 纵向滚动条宽），但本项目把纵向滚动条改成绝对定位浮动、**不再挤占布局**，主区宽度与 `scrollXWidth` 都是容器满宽；
   - 8px：`handle` 自身的原生 `scrollbar-width: thin` 滚动条占位（无法 overlay）。
   - 结果：可视内容区 = 容器宽 − 16，而填充元素 `--scroll-x-space` 宽度 = `scrollXWidth` = 容器宽 → 溢出 16px → 滑块长度 ≈ 98%，与截图吻合。

另外，浮动化后 `.vxe-table--scroll-x-virtual`（absolute 无 `width`）宽度塌成 0，使 `handle` 的 `width: 100%` 失去正确基准。

## 三、修复（保留 hover 浮现，只让「不需要滚动时没有滑块」）

### `src/plugins/vxe-table.ts`

- 新增 `measureScrollbarSize()`：用离屏探针 div（`overflow: scroll; scrollbar-width: thin`）实测滚动条占位宽度，写入 `document.documentElement` 的 `--x-scrollbar-size`。跨浏览器版本 / 系统缩放 / 高 DPI 精确（写死 8px 在 thin=12px 等环境会残留偏差、滑块复现）。
- 在 `setupVxeTable()` 内、`injectScrollbarStyle()` 之前调用。

### `src/styles/css/scrollbar.css`

```css
.vxe-table .vxe-table--scroll-x-virtual {
  width: 100% !important;
} /* 补回浮动化后塌成 0 的宽度基准 */
.vxe-table .vxe-table--scroll-x-wrapper {
  width: 100% !important;
} /* 覆盖 JS 内联的「容器宽 − osbWidth」 */
.vxe-table .vxe-table--scroll-x-handle {
  width: calc(100% + var(--x-scrollbar-size, 8px)) !important;
} /* 仅补回滚动条自身占位 */
```

效果：handle 可视内容区 == 容器宽 == `space` 宽度 → 不溢出 → 无滑块；真溢出时（列总宽 > 容器）`space` 更宽，滑块按比例出现、可拖动，vxe 滚动同步不受影响。

## 四、取舍

- 轨道右端比表格右边缘多出 `--x-scrollbar-size`（滑块右端伸入浮动纵向滚动条区域约 8px，两者仅 hover 同时出现，与 Naive 浮动滚动条观感一致）；未加 `overflow: hidden` 裁剪。
- 全局生效（所有使用 `Table` 组件的页面统一）。
- 仅改横向；纵向 handle 无此固定偏差（其 space 宽仅 1px 且 `overflow-x: hidden`），本次不动。
- 未改 `node_modules`、未改自动生成文件、未新增文件。

## 五、验证

- `pnpm exec oxlint src/plugins/vxe-table.ts`：0 warnings / 0 errors；`read_lints` 两文件 0。
- `pnpm typecheck`：exit 0。
- 待浏览器复核：hover 结算方式页应看不到滑块；缩窄窗口令列总宽超出容器时滑块出现且横向滚动正常。
