# 标签标题与内容垂直错位

> 日期：2026-09-12　模块：`src/views/system-manage/label-designer`

## 现象

文本元素开启「关联标题」后，画布上标题（如 `sku`）与内容（如 `SKU-882910`）同行显示，但垂直方向明显错位：标题偏上、内容偏下，基线不在一条线上。

## 根因

两处渲染（画布 `element-renderer.vue` 与打印 `render-element-html.ts`）标题+内容同行排列时，flex 容器用的是**盒子顶对齐**（画布 `items-start`、打印 `align-items:flex-start`），注释写的「基线对齐」实际并未实现：

- 标题默认 10pt / lineHeight 1.2，内容字号与 lineHeight 独立配置（行框通常更高）；
- 顶对齐时两个盒子顶部贴齐，但文字在各自行框内的垂直位置不同 → 首行基线错开。

## 方案对比

- **方案 A（采纳）：`align-items: baseline` 真基线对齐**。文字首行基线天然对齐，字号/行高变化自适应。
- 方案 B（否决）：保持顶对齐 + 给标题手动 padding-top 补偿。字号/行高任一变化都要重算，pt/px 换算易引入 1px 误差。
- 方案 C（否决）：回到标题在上、内容在下的上下结构。用户此前已明确选择同行排列。

## 方案 A 的关键细节

**参与基线解析的 flex 子项不能带 `overflow: hidden`（overflow 非 visible 会干扰浏览器基线合成，可能导致对齐失效）**。因此：

- 画布：两个直接子项去掉 `overflow-hidden`，裁剪统一由外层容器 `overflow-hidden` 兜底；非基线模式（无标题/非文本）保持 `items-stretch` + `h-full overflow-hidden` 原行为。
- 打印：`wrapContent` 增加 `baseline` 参数，仅文本路径传 `true` → 容器 `align-items:baseline`、子项去掉 `height:100%` / `overflow:hidden`；图片/条码/矩形/线条等非文本保持 `flex-start` 原样（无文字基线概念）。裁剪由 `pos` 里既有的 `overflow:hidden` 兜底。

## 修复

- `element-renderer.vue`：`items-start` → `items-baseline`；标题 div 与内容包裹 div 在基线模式下不再裁剪。
- `render-element-html.ts`：文本路径 `align-items:baseline`，`wrapContent` 加 `baseline` 参数区分文本/非文本。

两处保持同步（画布与打印渲染必须一致，见既有约定）。验证：`pnpm typecheck` 通过。

## 追加：用户否定分栏结构，改为行内连续排版

基线对齐修复后用户进一步反馈：**不要「左标题块 + 右内容块」的分栏**（截图标注两个并排块），期望是「把标题和内容都填到元素框里」——经确认选定**行内连续排版**：

- 标题作为**行内前缀 span** 与内容排在同一文本流：第一行「`标题内容123…`」，内容长了自动折行到下一行**行首顶格**，整个元素框被文字填满，不分块。
- 同一文本流内基线**天然对齐**（inline 布局默认行为），字号/行高任意组合都不会错位——基线问题从根源消失，无需任何对齐补偿。
- 实施要点：
  - 画布 `element-renderer.vue`：文本类型整体退出 flex 结构，单容器 `overflow-hidden break-all` + 内容行高，内部 `<span :style="titleStyle">标题</span>{{ text }}`；`baselineAlign` computed 删除。非文本（图/条码/二维码/矩形/线条）保持水平 flex（标题在左、内容在右）。
  - 打印 `render-element-html.ts`：文本分支不再走 `wrapContent`，直接 `pos + 文本样式 + <span>标题</span> + 内容`；`wrapContent` 删掉 `baseline` 参数恢复 `flex-start`；`titleHtml` 统一为 **span 版**（`flex:none` 对 inline 无害），`line-height:1.2` 去掉（行内流继承内容行高）。
  - `titleStyle` 去掉 `textAlign`（行内流下跟随内容对齐）与 `lineHeight`；标题与内容间 8px 间距保留（`margin-right`）。
- `pnpm typecheck` 通过。

## 追加：标题后自动拼接冒号

- 要求：标题与内容之间自动加「:」（半角），关闭关联标题 / 标题为空时不显示冒号。
- 实现：冒号拼在**标题 span 内部末尾**（画布 `{{ titleText }}:`、打印 `escapeHtml(title)}:`），随标题一起渲染、样式跟随标题，`v-if="titleText"` / `showTitle` 分支天然保证「无标题即无冒号」。标题与内容间 8px margin 保留。
- 画布与打印两处同步，`pnpm typecheck` 通过。
