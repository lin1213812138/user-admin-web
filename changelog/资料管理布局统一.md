# 资料管理布局统一（按系统设置页样式）

> 日期：2026-09-17
> 来源：用户截图红框标菜单「资料管理」下的三个子项——「资料管理也要按系统设置界面这么改，保证布局样式统一」

## 现状对比

| 维度       | 系统设置页（目标样式）                               | 资料管理页（改造前）                                             |
| ---------- | ---------------------------------------------------- | ---------------------------------------------------------------- |
| 菜单层级   | 「系统管理」下单个入口，点进即页面                   | 「资料管理」下挂 3 个子项：基础资料 / 业务资料 / 财务资料        |
| 页面内布局 | `VerticalTabLayout`：左「标题 + 竖向 tab」+ 右内容区 | 自绘 `ArchiveSwitch`：左侧 180px 按钮列表 + 右内容区             |
| 贴边       | `contentShowPadding` 排除 `system-manage_setting`    | 未排除（GlobalContent 注入 p-16px）                              |
| 子模块切换 | 左右两栏由布局组件承载，切 tab 重建组件              | 左侧按钮 + `Transition` + `KeepAlive` 懒加载组件，切回不重新取数 |

## 需求澄清（两项确认）

- **层级** = 保留 3 个子菜单：菜单、路由、URL、页签标题全不动，只改三个页面各自的内部布局。
- **实现路径** = 方案 A：三个页面各自直接使用 `VerticalTabLayout`（写法与 `setting/index.vue` 完全同款），`ArchiveSwitch` 退役（按仓库死代码惯例保留不删）。

## 最终形态

每个资料页面（以基础资料为例）：

```
┌─ 贴边整页 ──────────────────────────────────────────────┐
│ ▍基础资料        │ 搜索栏（SearchBar，原样）             │
│ ─────────────── │ ────────────────────────────────────── │
│  国家地区 ←选中  │  表格卡片（原样）                      │
│  邮政路线        │                                        │
│  FBA 仓库        │                                        │
│  客户等级        │                                        │
│  客户来源        │                                        │
└─────────────────────────────────────────────────────────┘
```

- 左侧：标题（竖条 + 文字）+ 竖向 `NTabs` 栏 = 该组资料项（基础 5 / 业务 9 / 财务 4）；
- 右侧：现有表格页原样搬入（搜索栏、表格、新增/编辑抽屉、列配置全部不动）。

## 改动清单

1. `src/layouts/base-layout/index.vue`：`contentShowPadding` 排除名单加入 `data-manage_basic` / `data-manage_business` / `data-manage_finance`（与 `system-manage_setting` 同机制）→ 整页贴边。
2. `src/views/data-manage/{basic,business,finance}/index.vue`：`ArchiveSwitch` → `VerticalTabLayout`：
   - `title` = `route.data-manage_*`（菜单名，与设置页用 `route.system-manage_setting` 一致）；
   - `tabs` 由原 `items` 的 `labelKey` 经 `$t` 映射；
   - 右侧 `defineAsyncComponent` 懒加载（沿用原 `load` 函数与 NSpin 占位）+ `:key="activeKey"` 重建；
   - **去掉 `KeepAlive` / `Transition`**。
3. `src/components/MasterData/types.ts`：新增 `ArchiveTabItem` 类型（`key` / `labelKey` / `load`），供三个页面共享（替代退役组件里的 `ArchiveSwitchItem`）。
4. `src/components/MasterData/master-data-archive.vue`：外层去掉 `py-8px pl-16px`（右侧内容区已自带 p-16px，避免双倍留白）。
5. `src/components/VerticalTabLayout/README.md`：已接入页面表 +3 行。

## 行为变化（与设置页对齐）

- 切左侧 tab **重新取数**（原 `KeepAlive` 缓存取消，设置页为同款行为）；
- 切换**无过渡动画**（原 `Transition` 去掉，设置页无）。

## 保留与非目标

- `ArchiveSwitch`（`components/MasterData/archive-switch.vue`）不再被引用，按仓库惯例保留为死代码；
- 搜索栏形态（SearchBar 表单式，与设置页的 search-action 卡片形态不同）、表格、抽屉、路由、i18n 全部不动。
