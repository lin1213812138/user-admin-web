# 资料管理模块设计讨论

- 日期：2026-09-01
- 结论：**方案 A（通用配置驱动组件）**，已与用户确认。
- 完整设计文档：`docs/superpowers/specs/2026-09-01-data-manage-modules-design.md`

## 决策要点

1. **数据来源**：后端 `wms-user` 暂无接口，先以 mock 搭完整 CRUD 骨架，字段用典型 WMS 主数据占位，后续替换真实接口（prod 地址约定为 `/data-manage/:archive/(list|create|update|delete)` 占位）。
2. **模块结构**：每个模块内含多个子档案，用 `NTabs` 切换。
3. **子档案组合（共 12 张）**：
   - 基础资料 basic：客户 / 供应商 / 商品 / 商品分类
   - 财务资料 finance：结算账户 / 币种 / 税率 / 结算方式
   - 业务资料 business：仓库 / 库位 / 承运商 / 门店
4. **架构**：新增通用 `MasterDataArchive` 组件（搜索栏 + 表格 + 增删改抽屉 + 列配置），由 `ArchiveConfig` 驱动；`fetchGetDataManageList/create/update/delete(archiveKey,...)` 通用 fetch；mock 数据集在 `mock-data-manage.ts`；类型在 `Api.DataManage` 命名空间。

## 遵循约定

- 路由由 `views/data-manage/{basic,finance,business}/index.vue` 目录自动生成，仅 `customRoutes` 补 icon/redirect；禁止手改 `src/router/elegant/*`。
- i18n 中英文 + `src/typings/app.d.ts` 三处同步；复用 `FormWrap`/`useVxeTable`/`Table`，不另封装表格。
