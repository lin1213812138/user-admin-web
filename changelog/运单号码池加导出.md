# 运单号码池加「导出」（复用 TableExportAction）

> 日期：2026-09-20 ｜ 状态：已实施（待手动冒烟）
> 页面：资料管理 / 单号资料 / 运单号码池（`src/views/data-manage/no-rule/modules/no-pool/NoPool.vue`）
> spec：`docs/superpowers/specs/2026-09-20-运单号码池导出-design.md`

## 1. 背景与用户诉求

> 运单号码池再加个导出功能，使用已经封装好的导出组件

追问「导出「全部数据」怎么取」→ 用户回复：**按照当前条件查询全部数据**。

## 2. 选型（已封装的两套导出组件）

| 组件                | 形态                                                                             | 适用                   |
| ------------------- | -------------------------------------------------------------------------------- | ---------------------- |
| `TableExportAction` | 自带触发按钮 + 字段勾选弹窗 + 数据范围（全部 / 当前页 / 勾选），字段来源是表格列 | **表格页**（本次选用） |
| `DataExport`        | 无触发按钮，字段与数据全由调用方给                                               | 非表格场景             |

本页是标准表格页（`useVxeTable` + `Table`），且已有可复用状态：`show-checkbox` 的 `checkedRows`（勾选数据）、`useVxeTable` 返回的 `columnConfigs`（含隐藏列，本次补解构）。

## 3. 后端约束（已核 `tms-user`）

| 约束                                 | 位置                                                           | 处理                                                  |
| ------------------------------------ | -------------------------------------------------------------- | ----------------------------------------------------- |
| 单次查询上限 `SAFE_MAX_LIMIT = 5000` | `lib/common/utils/index.js#safeLimit`                          | 一次大 `size` 取全会**静默截断** ⇒ 全量取数改分页循环 |
| 默认套近 12 个月 `createDate` 区间   | `lib/services/no-pool.js#query` → `setDefaultDate(params, 12)` | 列表本身也受此限制；导出沿用同一条件，口径与列表一致  |

## 4. 实施

`NoPool.vue` 单文件改动：

- **入口**：`#operation-left` 末尾（导入 → 批量删除 → 导出，与 `Product.vue` 先例同序）挂 `TableExportAction`，传 `:columns="columnConfigs"`（含隐藏列）、`:data="data"`（当前页）、`:checked-data="checkedRows"`（勾选）、`:fetch-all="fetchAllNoPools"`、`:extra-fields="exportFields"`、`:filename="$t('page.dataManage.noRule.noPool.title')"`（文件名复用「运单号码池」，**不新增 i18n key**）。
- **取数**：抽出 `buildWhere()` 供列表 api 与导出共用（保证「导出 = 所见」）；`fetchAllNoPools()` 以 `pageSize=1000` 循环翻页直到累计行数 ≥ 后端 `total`。
- **字段取值**：4 个插槽渲染列导出会失真，用 `extraFields`（按 key 覆盖同名列）补 formatter：
  - `refType` → 收货 / 发货 / 派送渠道文案（查不到输出空串，不把表格的 `--` 带进文件）；
  - `status` → 已提取 / 未提取（**不能**走内置 `status` 的启用 / 禁用格式）；
  - `pickDate` / `createDate` → `YYYY-MM-DD HH:mm:ss`，空值输出空串。
- 其余列（`no` / `refName` / `pickBy` / `creator`）原值导出。

## 5. 边界

- 不加 `v-auth`：本页权限树节点 `system:dataNoRule:noPool` 的 `buttons` 为空，导入 / 批量删除同样未加。
- 不改后端、不加导出专用接口；不改列表列 / 搜索 / 导入 / 批量删除；不动 `Table` 内置的 vxe 原生导出（`actionExport`）；不动菜单权限树。
