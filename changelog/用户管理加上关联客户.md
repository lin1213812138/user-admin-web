# 用户管理加上关联客户

## 需求

用户：「用户管理加上关联客户跟站点一样」——用户管理列表新增「关联客户」列，点击「查看」弹窗展示该用户关联的客户，交互与站点管理的关联用户/客户完全一致。

## 关键决策

- **关联范围（用户拍板）**：调 `/customer/user/query` 接口，不自己拼 where 条件。
- **后端事实（tms-user，零改动）**：
  - `/customer/user/query` 与 `/customer/query` 共用 `ctrl.query` → `customerService.query(getCtxQueryParams(ctx))`，请求体直传。
  - 请求体带顶层 `userId` 时，后端自动按 `salesmanId / serviceId / cashierId` 的 `$or` 过滤（与删除用户的绑定检查口径一致，另 cashierId 财务）；若用户角色含 `DATA_AUTH.GROUP` 数据权限，还会追加 `{ groupId: $in(user.groupIds) }` 条件。
  - `scene != 1` 时后端默认 `where.status = 1` 只查启用客户 ⇒ 管理列表传 `scene: 1` 包含停用客户，且 scene=1 时走 `fillNames` 回填 `site` 站点名称。
  - 返回 `ret: { list, total }`（queryCommon 分页）。

## 实施

1. `service/api/user/index.ts`：新增 `fetchGetUserCustomerList({ page, size, userId })` → `POST /customer/user/query`，body `{ page, size, scene: 1, userId }`，返回 `Api.SystemManage.SiteCustomerList`（类型复用站点关联客户，实体字段一致：`_id/code/name/site/status`）。
2. `views/system-manage/user/index.vue`：
   - 列表新增 `relationCustomer` 列（居中，「查看」文字按钮，复用 `page.manage.site.view`）。
   - `cacheKey` 升 `system-manage-user-v3`（新增列需换缓存 key 避免旧列配置残留）。
   - 复用公共组件 `RelationModal`：`openRelationModal(row)` 先探查 `page:1,size:1`，`!total && list.length===0` 时 `window.$notification?.info(common.noData)` 不弹窗（与站点页 2026-09-17 行为一致），否则打开弹窗。
   - 弹窗列：客户编码/客户名称/所属站点/状态（复用 `page.manage.site.customerCode|customerName|siteName` + `page.manage.user.status`）。
3. i18n：`page.manage.user.relationCustomer`（关联客户 / Related Customers）+ `app.d.ts` Schema 同步。

## 坑

- i18n key 必须同步加到 `src/typings/app.d.ts` 的 `page.manage.user` Schema，否则 vue-tsc TS2353/TS2345（本仓 locale 对象有严格类型约束）。
