# 无滚动条时隐藏滚动条端点（hover 浮现的小色块）

> 日期：2026-09-16
> 触发：用户截图（用户管理 → 角色管理）红框标出表格左下角、右下角、右侧上端的小色块，问「没有滚动条的时候这个能不能也不显示呢？」
> 前置：同一会话已完成《不需要横向滚动也显示横向滚动条修复》（见 `changelog/不需要横向滚动也显示横向滚动条修复.md`）

## 一、现象

鼠标悬停在表格上时，滚动条浮层的**两端**（横向层的左下/右下、纵向层的右端上方）各出现一个小色块；此时表格并没有滚动条滑块。

## 二、定位（用户实测确认）

1. 鼠标移出表格 → 色块消失 ⇒ 属于滚动条浮层（`.vxe-table--scroll-x-virtual` / `---scroll-y-virtual` 的 hover 显示范围）。
2. 右键「检查」拿到的元素：

```html
<div class="vxe-table--scroll-x-handle">
  <div class="vxe-table--scroll-x-space" style="width: 1720px;"></div>
</div>
```

3. `--scroll-x-space` 宽 1720px，与截图换算出的表格实际宽度一致 ⇒ **列宽总和 == 容器宽，表格并没有横向溢出**（所以没有滑块）。排除了「四角补块 corner」的可能：vxe 与项目 CSS 都已将其 `display: none`。
4. 真正原因：vxe 给两条 handle 设的是 **`overflow-x: scroll` / `overflow-y: scroll`**（`vxe-table/es/table/style.css:2540-2557`），`scroll` 语义是「不管内容是否溢出都渲染滚动条」⇒ 没有滑块时浏览器仍把轨道端点画出来，hover 时就成了那两个小色块。

## 三、修复

`src/styles/css/scrollbar.css` 新增 0.4 小节：

```css
.vxe-table .vxe-table--scroll-x-handle {
  overflow-x: auto !important;
}
.vxe-table .vxe-table--scroll-y-handle {
  overflow-y: auto !important;
}
```

- `auto` = 内容溢出才渲染滚动条：没有滑块时轨道/端点一个像素都不画；真需要滚动时滑块照常出现、可拖动。
- 不影响 vxe 自身的滚动同步（vxe 的 `overflowX / overflowY` 判定基于 `scrollXWidth` 与主区宽度，与 handle 的 overflow 取值无关）。
- 与上一处修复（handle 宽度补偿 `--x-scrollbar-size`）互补：那条保证「可视宽 == 内容宽」不产生伪滑块，这条保证「真的不需要滚动时连轨道都不渲染」。

## 四、验证

- 待用户复核：hover 表格不再出现两端色块；缩窄窗口令列总宽超出容器时，滑块正常出现且可拖动。
- CSS 改动不涉类型，未跑 typecheck；`read_lints` 无诊断。
