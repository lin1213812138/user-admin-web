## 决策（已与用户确认）

1. 搜索栏：关键字 + 状态（对齐费用类型，能筛出停用项）。
2. 列表列严格按截图：序号 / 账户别名(含内置 tag) / 开户银行 / 开户名称 / 开户账号 / 账户余额(右对齐) / 备注 / 状态 / 操作；不加创建人/创建时间。
3. 内置项前端限制停用（按钮 disabled + tooltip，批量自动过滤），编辑不限制（仅后端无白名单）。
4. 余额可编辑（抽屉新增/编辑可填，直接 update 覆盖）。

## 后端契约要点（已查 tms-user，零改动）

- `/trade-account/{query,get,create,update,disable}`，全部 POST。
- `query`：`if (!scene) where.status = 1` → 管理页必须 `scene:1` 才能看到停用项；分页字段 `page`（非 current）；响应 `{ list, total }`。
- `update`：走 `uniqField:'alias'`，局部更新（停用/启用）必须随行回传 `alias`，否则误写 `aliasUpdate` 脏字段。
- `disable`：`{ ids }` 批量置 `status=0`，无 buildIn 拦截（前端限停）。
- `create`：`alias`/`bank` 必填，`alias` 唯一；无 delete 路由。
