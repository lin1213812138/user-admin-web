# tab 指示条与系统设置不一致（同一个组件、位置却不同）

> 日期：2026-09-17
> 来源：用户贴个人中心左侧 tab 栏截图（红框圈出激活 tab 右侧的蓝色竖线）："都是同一个组件为什么跟系统设置的就是不一样呢？"

## 现象

个人中心左侧竖向 tab 的激活指示条（蓝色竖线）"飘"在侧栏内部、离侧栏右边框约 15px；系统设置页同一位置基本贴着侧栏右边框。两页用的是同一个 `VerticalTabLayout`。

## 根因（实测）

- naive `NTabs` 的竖线指示条 `.n-tabs-bar` 是 `position: absolute; width: 2px; right: -1px`（左/右 placement 下），**锚点是 tab 列表 `.n-tabs-nav` 的右边缘，不是侧栏右边缘**。
- `VerticalTabLayout` 的侧栏是 `w-fit`：宽度由「最宽的孩子」决定；tab 列表自身不撑满（宽度 = tab 文案 + 左右各 16px padding）。
- 于是：最宽的孩子是标题行时（个人中心），列表比侧栏窄 → 蓝条离右边框 15px；最宽的孩子恰好是 tab 文案时（系统设置），列表正好撑满 → 蓝条贴边。

| 实测项                  | 个人中心（改前）                      | 系统设置（对照）                       |
| ----------------------- | ------------------------------------- | -------------------------------------- |
| 侧栏宽度                | 103px（标题行「个人中心」102px 最宽） | 117px（tab「轨迹抓取配置」115px 最宽） |
| tab 列表 `.n-tabs-nav`  | 88px                                  | 116px                                  |
| 蓝条 `.n-tabs-bar` left | 306（侧栏右边缘 323，差 15px）        | 334（侧栏右边缘 337，差 1px=边框）     |

## 决策（用户确认：方案 A）

- **方案 A（采用）**：让 tab 列表撑满侧栏宽度，蓝条随之移到侧栏右边缘（与系统设置一致）。
- 方案 B（未采纳）：保持现状、仅解释差异。
- 未考虑把蓝条改成贴着文字：naive 的 bar 是内部绝对定位在列表右边缘，改它需要覆盖库内部样式。

## 改动清单

`src/components/VerticalTabLayout/index.vue` 新增 scoped 样式块（该组件原无 style）：

```css
:deep(.n-tabs-nav) {
  width: 100%;
}
```

- 未加 `!important`：实测规则直接生效（naive 未给 `.n-tabs-nav` 设宽度）。
- 附带效果：tab 行同时撑满（`.n-tabs-tab` 87 → 101px），整行可点、hover 背景铺满；文字仍左对齐（padding-left 16px 不变）。
