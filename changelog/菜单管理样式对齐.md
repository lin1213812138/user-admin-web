# 菜单管理模块样式对齐

> 日期：2026-09-01
> 关联：[菜单管理模块设计](./菜单管理模块设计.md)

## 背景

`src/views/system-manage/menu/index.vue` 的列表页外壳（布局、按钮、图标、列配置位置）与同目录的 `user` / `role` 模块不一致：

- 容器用 `h-full w-full p-16px` 平铺，而非 `user`/`role` 的 `flex flex-col gap-12px p-16px` + `flex-1 min-h-0` 表格区。
- 新增/刷新/列设置按钮未用 `<NSpace>` 包裹，且用 `NButton type="primary"`（无 `size="small"` / `ghost`）这种非统一写法。
- 图标用 `<SvgIcon icon="mdi:xxx" />` 字符串写法，而 `user`/`role` 统一用自动导入图标组件（`icon-ic-round-plus` 等）。
- `TableColumnConfig` 被放在 `<Table>` 内部 `operation-right` 插槽里，而 `user`/`role` 将其作为 `</Table>` 之后的兄弟节点，由 `configVisible` 控制。
- 操作列按钮用 `quaternary`（非统一 `text`），且 status 列缺 `fixed: 'right'`。

## 范围确认（与用户对齐）

- 保留 `tree-config` 树形展示（菜单天然有层级）。
- 不加搜索栏、不加序号/复选框/分页。
- 仅对齐「外壳」：布局、按钮区、图标、列配置位置、操作列、status 固定列。
- `menu-operate-drawer.vue` 不在本次范围。

## 改动

文件：`src/views/system-manage/menu/index.vue`

1. 外层容器改为 `flex flex-col gap-12px p-16px`，`<Table>` 包进 `<div class="flex-1 min-h-0">`。
2. `operation-left`：`<NSpace>` 包裹新增按钮，改为 `<NButton size="small" type="primary" ghost>` + `<icon-ic-round-plus class="text-icon" />`。
3. `operation-right`：`<NSpace>` 包裹列设置（`<icon-mdi-cog>`）与刷新（`<icon-mdi-refresh`），移除内联的 `<TableColumnConfig>`。
4. `<TableColumnConfig>` 移到 `</Table>` 之后作为兄弟节点，由 `configVisible` 控制显隐。
5. 操作列：编辑 `<NButton size="small" type="primary" text>`，删除 `<NButton size="small" type="error" text>`；`<Table>` 加 `action-align="center"`。
6. status 列配置加 `fixed: 'right'`。
7. 保留 `#icon` 插槽的 `<SvgIcon>`（渲染数据驱动的菜单图标字符串）与 `#menuType` 的 `NTag`。

## 验证

- `pnpm typecheck` 通过（无类型变更，仅模板/配置对齐）。
- `pnpm lint` 通过。
- 手动核对：列表页布局、新增/刷新/列设置按钮、操作列、列设置抽屉行为与其它模块一致。
