# 标签打印模板设计器设计方案（vue-plugin-hiprint）

- 日期：2026-09-07
- 关联：打印格式（`src/views/system-manage/setting/modules/PrintFormat.vue`）
- 完整设计文档：[docs/superpowers/specs/2026-09-07-print-label-design.md](../docs/superpowers/specs/2026-09-07-print-label-design.md)

## 需求

用 `vue-plugin-hiprint` 做「设计标签」界面：左侧可拖拽面板（业务字段分组 + 基础元素）+ 中间画布 + 右侧属性面板 + 顶部工具栏（返回上一页 / 纸张尺寸 / 缩放 / 清空 / 保存 / 预览）。

## 决策

| 项       | 结论                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 页面入口 | 独立路由页 `src/views/system-manage/print-design/index.vue`，从打印格式列表「设计」按钮带 query 进入，顶部「返回上一页」 |
| 页面位置 | **不放 `setting/` 子目录**：会生成子路由 + 父路由自动 redirect，与守卫叠加曾导致重定向死循环卡死                         |
| 左侧面板 | 业务字段分组（运单/收件人/发件人/物品/费用/系统）+ 基础元素；自定义 provider，拖入即生成带 `field` 的元素                |
| 属性面板 | 直接挂 hiprint 自带面板（`#PrintElementOptionSetting`），不自研 Naive UI 面板                                            |
| 预览打印 | 浏览器预览 + `window.print()`，不依赖 electron-hiprint 客户端；`disAutoConnect()` 关 socket                              |
| 工具栏   | 与截图一致（返回 / 纸张 / 缩放 / 清空 / 保存 / 预览），不加导入导出 JSON、不加示例数据开关                               |
| 保存     | `Template` 增加 `designJson` + `paperSize`；新增 detail / saveDesign 接口（DEV 走内存 mock，后端待实现）                 |

## 关键技术点

- **jQuery 全局**：hiprint 依赖全局 `$` → 禁止静态 import；`onMounted` 内先 `await import('jquery')` 挂 `window.$`，再 `await import('vue-plugin-hiprint')`（顺序很重要）。
- **Vite**：`optimizeDeps.include: ['vue-plugin-hiprint', 'jquery']`（UMD/CJS 需预构建）；依赖动态 import 避免进主包。
- **类型**：新增 `src/typings/hiprint.d.ts` 手写最小声明（`declare module 'vue-plugin-hiprint'`），不用 `any`。
- **打印样式**：`import 'vue-plugin-hiprint/dist/print-lock.css'` 仅在设器页引入。
- **缩放/纸张**：`hiprintTemplate.zoom(scale)`（0.5–2.0，步进 0.1）、`setPaper(w, h)`（mm）；清空优先 `clear()`，无则重建实例。
- **预览**：`new PrintTemplate({template:json}).getHtml(sampleData)` 注入 `iframe`，打印调 `iframe.contentWindow.print()`。

## 落地核对（Task 1 实际 grep `node_modules/vue-plugin-hiprint/dist/vue-plugin-hiprint.js` 结果）

- 版本 `0.0.60`，jQuery 必须锁 **3.x**（`pnpm add` 默认装到 4.0.0，API 不兼容，已改 `jquery@^3.7.1`）。
- `PrintTemplate.prototype.setPaper(t, e)`：`t` 匹配数字正则时走 `editingPanel.resize(undefined, parseFloat(t), parseFloat(e))` → **数值宽高可用**；否则按内置纸张类型名取（`A4` 等），找不到抛 `not found pagetype`。
- `PrintTemplate.prototype.zoom(t, e)`：`this.scale = e ? t : undefined; this.designPaper.zoom(t)` → 缩放用 `zoom(scale, true)`。
- `getJson()` 存在；`clear()` **未确认存在**（dist 里只见 `hinnn.event.clear` 与表格的 clear）→ 清空走「判空 + 重建实例」兜底。
- `PrintTemplate.prototype.getHtml(t, e)` 返回的是 `PaperHtmlResult` 结构（不是字符串），需再取 `html()` → 预览里做 `typeof === 'string' ? x : x.html()` 兼容。
- **`addPrintElementTypes(key, e)` 里 `e.forEach(t => allElementTypes.concat(t.printElementTypes))`** → 第二个参数必须是 `PrintElementTypeGroup[]`，扁平 `PrintElementType[]` 无效（计划里原写法已修正）。
- `options.testData` 确实被读取（元素编辑时用 `options.testData` 做设计态示例值），`options.field` 用于字段绑定。
- 默认元素 tid：`defaultModule.text/image/longText/table/emptyTable/html/customText`（常规组）与 `hline/vline/rect/oval/barcode/qrcode`（辅助组）。
- `hiprint.PrintElementTypeManager.buildByHtml(t)` → 内部 `enableDrag(t)` + `hidraggable`，参数需是 jQuery 对象。

## 已知风险

- hiprint 自带面板为浅色 HTML，暗黑模式先用 `:deep` 覆盖，不追求完美。
- hiprint 2.5.4 为 LGPL（npm 包 MIT）：仅作库引用不改源码。
- 后端 `designJson` 相关接口未实现，先走 mock。
