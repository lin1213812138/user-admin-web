# 表格分页默认改成 50

> 日期：2026-09-16
> 触发语：「表格分页默认改成50」

## 1. 背景与现状

用户要求所有表格默认每页 50 条。核实现状：

1. **全局兜底**：`src/components/Table/use-vxe-table.ts:95` `size: options.defaultPageSize ?? 20`。
2. **17 处页面显式传 `defaultPageSize: 20`**：user / role / group / site / customer（客户列表）/ log / channel-quote receive+ship / `MasterData/master-data-archive.vue` / setting 下 9 个子表（WaybillRule、TraceTransformTable、TraceKeywordTable、TraceConfigTable、OperationTraceTable、PrintFormat、InitDataCategory、ExportFormat）。
3. **分页条选项** `table.vue` NPagination `page-sizes=[50, 100, 200, 500, 1000, 2000, 5000]`——50 已是首项，但**旧默认 20 不在选项里**（页长显示与下拉选中态脱节）；默认改 50 后正好对齐，选项无需动。
4. 分页 size 无 localStorage 持久化（只缓存列配置 `vxe-table-column:*`），改完即生效无残留。
5. `hooks/common/table.ts`（SoybeanAdmin 模板 naive `useTable`，pageSizes `[10,15,20,25,30]`）**零引用死代码**，不动。

## 2. 方案（用户确认选 A）

- **方案 A（采纳）**：删 17 处页面显式 `defaultPageSize: 20`，全局兜底 `?? 20` → `?? 50`——今后调默认只改一处，与「默认」语义一致。
- 方案 B（否决）：17 处 20 全改 50，显式传值保留（重复声明依旧存在）。

## 3. 实施结果

- `use-vxe-table.ts` 兜底改 50 并加注释（说明可被页面 defaultPageSize 覆盖、与分页条首项对齐）。
- 17 处显式 `defaultPageSize: 20,` 行删除；`master-data-archive.vue` 处留注释指向全局兜底。
- 编辑器小坑：4 处 old_str 猜测 cacheKey 失配（`user/index.vue` 实为无注释、`WaybillRule`/`TraceConfigTable`/`InitDataCategory` 实际 cacheKey 与推测不同），重读上下文后补齐——**删行类编辑的 old_str 需带真实相邻行**。

## 4. 验证

- `pnpm typecheck` exit 0；`pnpm lint` oxlint 0 error + eslint 0 error（link.vue 2 条既有 warning 不动）；`pnpm fmt` 已跑。
- 全局 grep `defaultPageSize: 20` 仅剩接口可选属性声明，无业务残留。
- 浏览器效果（默认 50/页、下拉选中「50」）待用户复核。

## 5. 遗留

- `hooks/common/table.ts` 死代码按仓库惯例保留未删（模板底座，勿误删）。
- 个别 setting 子表数据量小（几条 mock），默认 50 无实际影响。
