# order 目录新增「包裹类型选择」公共组件

日期：2026-09-17
范围：`src/components/order/`（新建组件）+ `src/locales/langs/zh-cn.ts`、`en-us.ts`、`src/typings/app.d.ts`（i18n 三处）

## 背景

运单字段清单（`modules/input-format/fields-config.js`）中 `packType` 的 type 为 `select`，需要一个可在各页面复用的包裹类型选择组件。`src/components/order/` 为用户新建的空目录，作为运单域公共组件的落脚点。

后端口径（`tms-user/lib/common/models/order.js`）：`packType` Number，0-包裹 / 1-袋子 / 2-文件。

## 设计决策（已与用户确认）

1. **控件形态 = NSelect 下拉**（与字段清单里 `packType` 的 `type: 'select'` 一致）。
2. **选项文案走 i18n**（`zh-cn.ts` / `en-us.ts` / `app.d.ts` 三处同步，支持中英切换）。
3. **单文件组织**：`components/order/pack-type-select.vue`（对齐 `common/custom` 单文件范式，不建子目录 + README）。

## 实现

### 1. 组件 `src/components/order/pack-type-select.vue`

- 受控组件：`v-model:value`（`value?: number | null`，emit `update:value`），值与后端 `packType` 数字口径一致。
- Props：`value` / `disabled` / `clearable` / `placeholder`（缺省「请选择包裹类型」）；其余未声明 attrs（如 `size`、`class`）自动透传到内部 `NSelect`。
- 选项用 `computed` 生成（`page.order.packTypeOption.*`），保证切换语言后文案即时更新（模块级常量会失去响应性，故不用）。
- 值类型断言 `$event as number | null`（`NSelect` 的 `update:value` 参数为 `string | number | array | null` 联合）。

### 2. i18n 三处新增 `page.order` 段

| 键                                  | zh-CN          | en-US                      |
| ----------------------------------- | -------------- | -------------------------- |
| `page.order.packTypeOption.package` | 包裹           | Package                    |
| `page.order.packTypeOption.bag`     | 袋子           | Bag                        |
| `page.order.packTypeOption.file`    | 文件           | File                       |
| `page.order.packTypePlaceholder`    | 请选择包裹类型 | Please select package type |

插入位置：`page.manage` 之后、`page.dataManage` 之前（三个文件保持同序）。

### 3. 自动生成文件

`pnpm build` 触发 unplugin 全量重生成 `src/typings/components.d.ts`：新增 `PackTypeSelect` 声明，同时顺带清理了此前 `MasterData` 目录迁移遗留的悬空声明并补上 `VerticalTabLayout`（均为自动生成内容，未手改）。
