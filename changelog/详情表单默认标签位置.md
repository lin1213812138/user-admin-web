# 详情表单默认标签位置

## 需求

用户："查看详情的时候 form 组件默认这样显示：`label-placement="left"` `label-width="auto"`"。

现状：`FormWrap`（`src/components/Form/index.vue`）的 `labelPlacement` 静态默认值为 `'top'`，而 5 处详情（view）调用点都没显式传 `label-placement`，所以详情态标签一律在顶部。

## 澄清确认

- 生效范围：**方案 A** —— `FormWrap` 内部按 `mode` 决定默认值（view → `'left'`、edit → `'top'`），**父级显式传值仍优先**；编辑态保持顶部不变。
- 标签宽度：`auto`。即 `label-width="auto"`。naive 的实现（`Form.mjs` 的 `maxChildLabelWidthRef` + `utils.mjs` 的 `mergedLabelWidthRef`）是**取整个 NForm 内所有 label 的最大宽度、统一应用**，故各行 label 等宽对齐（此处初版描述写成了"各项各自算宽、可能参差"，已按源码修正）。

## 设计

- `props.labelPlacement` 去掉静态默认值（`withDefaults` 中置为 `undefined`），新增 computed：

  ```ts
  const resolvedLabelPlacement = computed<'left' | 'top'>(
    () => props.labelPlacement ?? (isView.value ? 'left' : 'top')
  );
  ```

- 模板 `NForm` 的 `:label-placement` 由 `labelPlacement` 改绑 `resolvedLabelPlacement`。
- `labelWidth` 默认已是 `'auto'`，无需改动（view / edit 语义一致）。
- 影响面：5 处 `mode="view"` 调用点自动变为左标签 —— `system-manage/user`、`site`、`group`、`role`（其模板写 `<NForm>`，实为 `@/components/Form/index.vue` 别名）四个抽屉 + `setting/modules/print-format/PrintFormat.vue`。
- **显式传值优先**：`components/MasterData/master-data-archive.vue` 传了 `label-placement="top"`，该详情抽屉保持原样（其详情态仍走 `:disabled`，未使用 `mode="view"`）。

## 改动文件

- `src/components/Form/index.vue`：3 处 —— props 默认值 `labelPlacement: 'top'` → `undefined`（附注释）、新增 `resolvedLabelPlacement` computed、模板 `:label-placement` 改绑。

## 验证

- `pnpm typecheck` 通过（0 错误）；
- oxfmt / oxlint / eslint 对 `src/components/Form/index.vue` 均 0 warning、0 error；
- 本地无后端（登录接口必 500）+ 路由守卫拦截，未做浏览器端到端；预期表现 = 详情抽屉标签左置、宽度自适应，编辑态标签仍在顶部，显式传 `label-placement` 的调用方不受影响。
