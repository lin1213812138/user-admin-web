# 表格快速搜索栏贴边

> 日期：2026-09-17
> 来源：用户「tab组件的快速搜索栏如果想要完全贴边怎么处理？」（中途更正为「表格组件」）

## 需求

`Table` 组件的 `search-action` 快速搜索栏在默认布局下与内容区边缘保持 16px 间距，用户要求提供「完全贴边」能力。

## 需求澄清（两项选择）

- 贴边程度 = **B：左右 + 上方都贴边**（卡片顶到内容区顶部、左右贴边），下方间距与表格位置保持现状。
- 生效范围 = **B：做成 Table 组件可选能力**（加 prop 按需开启），而非仅录单格式页或布局级统一。

## 定位（关键）

快速搜索栏的 16px 留白**不是 Table 自身产生的**：search-action 卡片本身铺满父容器宽度，外侧留白来自父容器内边距——

- `VerticalTabLayout` 右内容区写死 `p-16px`（`src/components/VerticalTabLayout/index.vue`）；
- 普通路由页面来自 `GlobalContent` 的 `p-16px`（`showPadding` 默认 true）。

两种容器内边距同为 16px，是负边距方案成立的前提。卡片内部的 `content-style: 12px 16px` 属卡片视觉样式，本轮不动。

## 方案（用户确认 A）

Table 新增 `searchActionFlush` 布尔 prop（默认 `false`，现有页面零影响）；开启时给 search-action 外层 div 追加 `-mt-16px -mx-16px`，向上/左/右各外扩 16px 正好抵消父容器 `p-16px`，卡片通栏贴边；`mb-12px`（卡片与按钮行/表格的间距）保持不变。

否决备选：

- B `searchActionGutter` 自定义偏移量：把布局数值暴露给业务、易误用（过度设计）；
- C 页面 `:deep()` 覆盖：不满足「组件可选能力」，每个要贴边的页面都要重复。

## 改动清单

- `src/components/Table/table.vue`：
  - Props 加 `searchActionFlush?: boolean`（注释说明语义与适用场景）；
  - withDefaults 默认 `false`；
  - search-action 外层 div 条件类 `:class="searchActionFlush ? '-mx-16px -mt-16px' : ''"`；注释块同步补充说明。
- `src/views/system-manage/setting/modules/input-format/InputFormat.vue`：`<Table search-action-flush ...>` 开启。

## 使用与边界

- 用法：`<Table search-action-flush ...>`。
- 语义 = 「抵消父容器 16px 内边距」；父容器本身无 padding 的页面不要开启（负边距会让卡片溢出）。
- 卡片保留主题圆角，贴边后四角紧贴容器边缘；如需顶部直角另议。

## 验证

- `pnpm typecheck` exit 0、`read_lints` 无诊断。
- playwright 实测（dev 9111，录单格式页）：搜索卡片外层 class = `mb-12px -mx-16px -mt-16px`、computed `margin-left/-top = -16px`、`margin-bottom = 12px`；卡片 `left/top/right = 323/40/1280` 与内容区容器 `left/top/right = 323/40/1280` 完全一致（左/上/右三边贴合，宽 957px）。
- 回归抽查：站点管理页（未传 prop）search-action 外层仍为 `mb-12px`、margin 0，零影响。

## 追加变更（同日）：改为默认贴边

用户「改成默认贴边」→ `searchActionFlush` 默认值 `false` → `true`（Props 注释与 withDefaults 同步）；录单格式页移除冗余的 `search-action-flush` 传参。语义变为「默认贴边，父容器无 16px 内边距的页面传 `false` 关闭」。

影响面核对（全部 6 个 `search-action` 使用页面）：

| 页面                                                    | 容器内边距来源                                                         | 实测卡片 left/top/right | 对照容器                                  |
| ------------------------------------------------------- | ---------------------------------------------------------------------- | ----------------------- | ----------------------------------------- |
| input-format / print-format / init-data / export-format | VerticalTabLayout 右内容区 p-16px                                      | 337/40/1280             | 内容区容器 337/40/1280（完全一致）        |
| site / log                                              | 页面根自带 p-16px（与 GlobalContent 注入的 `p-16px` 同值合并，非叠加） | 220/40/1280             | 页面根（灰底卡片）220/40/1280（完全一致） |

- 曾担心的 export-format「Table 上方提示文字重叠」经实测不存在（当前代码该 div 已不在）；其余页面 Table 上方均无兄弟元素，无重叠。
- 布局说明：负 margin 使 Table 内部整体上移 16px，表格区（`flex-1`）自动补高 16px、底部锚定不动，`mb-12px` 与分页位置不变。
- 实测 6 页均无溢出、无 console 报错；`read_lints` 0、`oxfmt --check` 通过。
