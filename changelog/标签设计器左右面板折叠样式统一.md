# 标签设计器：左右面板折叠区块样式统一

> 日期：2026-09-12

## 需求

用户截图对比标签设计器左（基础元素 / 业务字段）右（位置与尺寸 / 数据预览 / 样式）两侧折叠区块，问「这两个布局能不能改成一样的」。

## 问题定位

两侧差异四个维度：

| 维度 | 左侧 field-panel                  | 右侧 property-panel             |
| ---- | --------------------------------- | ------------------------------- |
| 容器 | 裸 `NCollapse`，无卡片            | 每块套一层 `NCard size="small"` |
| 结构 | 一个 `NCollapse` 两个 item        | 三个独立 `NCollapse` 各套各卡   |
| 标题 | 默认字重 14px                     | `text-13px font-medium` 加粗    |
| 箭头 | header `flex-1` 撑满 → 贴面板右缘 | 无 `flex-1` → 箭头紧跟标题文字  |

## 方案（A，用户确认）：右侧向左侧看齐

候选三案：A 右侧改左侧样式（去卡片合并 collapse，推荐）/ B 左侧改右侧卡片样式 / C 两侧自定义第三种轻量折叠头。用户选 A。

`property-panel.vue` 模板重组：

- 删除三张 `NCard`（含 `size="small"` / `segmented`），三个 `NCollapseItem`（`geo` / `dataPreview` / `style`）合并进**一个** `NCollapse`；
- `default-expanded-names="['geo', 'dataPreview', 'style']"` 三项全展开（与原三个独立 collapse 各自默认展开行为一致）；
- header 统一为左侧同款 `<span class="flex-1">标题</span>`——箭头贴面板右缘，去掉 `text-13px font-medium`；
- 保留零改动：`v-if="showDataPreview"` / `v-if="styleItems.length"` 条件渲染、`title` 插槽、`fieldBindText` 绑定信息条、`NScrollbar`、底部删除按钮、窄面板 `grid-x-gap=8`、script 全部逻辑；
- 清理：删 `NCard` 显式 import、scoped 样式 `:deep(.n-card)` 规则；
- 左侧 `field-panel.vue` 不动。

折叠行为无变化：合并后每个 item 仍可独立收起/展开，仅视觉上从「三张卡片」变为「带分隔线的裸折叠列表」，与左侧完全同款；右侧窄面板（300px）少一层卡片内边距，内容更宽松。

## 验证

- `pnpm typecheck` 通过；
- `read_lints` 无新增错误。

## 二次迭代：折叠内容区包白底描边卡（用户确认）

用户看效果后截图圈住「位置与尺寸」内容区：「里面可以加个卡片」——折叠头保持裸样式（与左侧一致），但表单内容裸露在面板上缺少容器感。

方案确认：三个区块（geo / dataPreview / style）**内容区**统一包 `NCard size="small"`（默认白底 + 细边框，无标题），折叠头不动；候选的浅灰 embedded 卡 / 轻量 div 被否，用户选白底描边（更接近原版三张卡片的观感）。

- `fieldBindText` 绑定信息条留在数据预览卡片内部（`mt-8px` 间距保留）；
- 恢复 `NCard` 显式 import 与 scoped `:deep(.n-card) { min-width: 0 }`（防窄面板撑破）；
- 左侧字段面板仍不动（拖拽项本身是白底卡，再套一层嵌套过深）。

最终形态：**裸折叠头（箭头贴右、默认字重）+ 内容白底描边卡**。typecheck / lint 通过。
