# 标签设计器：文本类型落纸尺寸（宽 50mm、高按内容自适应）

日期：2026-09-14
范围：`store/modules/label-design/index.ts`、`modules/canvas/drag-preview.vue`、`modules/canvas/drag-ghost.ts`、`modules/canvas/design-canvas.vue`

## 需求

用户：「文本类型高度按内容自适应，宽度定为 50mm」。

## 方案

### 1. 默认宽度 40mm → 50mm

`defaultSize('text')` 的 width 改为 `mmToPt(50)`；height 保留 `mmToPt(8)` 作为兜底 / 最小高度。

### 2. 高度按内容自适应（复用「按下即预览」的实测，无需额外的文本测量逻辑）

- `drag-preview.vue`：文本类型预览容器 `height: auto`（内容撑开），并加 `minHeight = 类型默认高度`
  —— 空内容时预览不塌成 0，实测值也因此天然带底线；
- `drag-ghost.ts`：预览渲染后（`nextTick`）实测 `offsetHeight / PX_PER_PT` 存进会话，导出 `getPreviewHeight()`；
- `design-canvas.vue` 的 `onDrop`：文本类型落纸用 `{ width: 默认50mm, height: 实测高度 }` 覆盖默认尺寸
  （`textDropSize()` helper；拿不到实测值时返回 `undefined` 回退类型默认尺寸）；
- `store.addElement(desc, at, size?)` 新增可选 size 参数（不传时行为与之前完全一致）。

### 3. 效果

拖入文本（或 elementType 为 text 的业务字段）时：**预览与落纸元素都是「宽 50mm、高 = 内容自然高度」**，
内容为空时以 8mm 为底线；其它类型（条码 / 二维码 / 矩形 / 线条等）尺寸不变。

## 修正：最小高度改用「单行高度」（同日，用户反馈「这不没什么变化吗」）

**现象**：用户拖入 SKU 文本（宽 50mm）后觉得「没什么变化」。

**原因**：上一版把文本预览的 `minHeight` 设为**类型默认高度（8mm）**，而单行文本的自然高度只有
`8pt × 1.2 = 9.6pt ≈ 3.4mm` —— 下限比内容还高，元素被撑到 8mm，「高度自适应」被完全掩盖。

**修法**：`minHeight` 改为**单行高度**（`fontSize × lineHeight × PX_PER_PT`，从元素 options 取，缺省 8pt / 1.2）：

- 单行文本：实测高度 ≈ 下限 ≈ 3.4mm，元素贴合内容（明显变扁）；
- 空内容：高度 = 单行高度，不会塌成 0；
- 多行文本：自然高度 > 下限，自适应不受影响。

验证：`pnpm typecheck` 0 error；`oxfmt` / `oxlint` / `eslint` 单文件 0 error。
