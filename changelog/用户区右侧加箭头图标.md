# 用户区右侧加箭头图标

## 需求

用户截图（红框标侧栏底部用户区按钮）并手绘了一个向上的 `^` 形："右侧加一个这样的图标"。即：用户区按钮（头像 + 用户名）右侧加一个向上展开的指示箭头，提示点击后向上弹出菜单。

## 决策（澄清确认）

- 图标形态：**线形 chevron**（`mdi:chevron-up`，细线条 V 形 `^`，与截图手绘形状一致）；「实心小三角 ph:caret-up」「实心粗三角 ph:caret-up-bold」两案未采纳。

## 实施

只改 `src/layouts/modules/global-header/components/user-avatar.vue` 模板（用户区组件从 global-header 目录复用）：

```vue
<ButtonIcon>
  <SvgIcon icon="ph:user-circle" class="text-icon-large" />
  <span v-if="!appStore.siderCollapse" class="text-16px font-medium whitespace-nowrap">
    {{ authStore.userInfo.userName }}
  </span>
  <!-- 展开指示箭头：提示点击后向上弹出菜单（同 NDropdown placement="top"）；折叠态无文字不显示 -->
  <SvgIcon v-if="!appStore.siderCollapse" icon="mdi:chevron-up" class="text-14px" />
</ButtonIcon>
```

- 大小 14px（比用户名 16px 略小，轻盈不抢眼）；与文字间距 = 插槽内既有 `gap-8px`。
- 颜色 `currentColor`：常态 82% 白、hover 随文字转纯白（复用 `sider-footer--inverted` 变量覆盖机制）。
- 只在侧栏展开态显示；折叠态只有头像图标，不显示箭头。
- 方向朝上，与 `NDropdown placement="top"`（向上弹出）一致。
- 未登录态「登录或注册」按钮不加箭头；热区、hover 效果、按钮结构不变。

## 验证

- `pnpm typecheck` / `oxlint` / `eslint` 均 0 error。
- playwright 实测 dev 9111（登录后量测 DOM）：
  - 按钮内 svg 数量 = 2（头像 + chevron），chevron 实测 14×14；
  - 渲染出真实 path `d="M7.41 15.41L12 10.83l4.59 4.58L18 14l-6-6l-6 6z"`（确认为 mdi:chevron-up、非空图标）；
  - 常态 `color: rgba(255,255,255,0.82)`；hover 时 `color: rgb(255,255,255)` 且按钮背景 `rgba(255,255,255,0.16)`（与上一轮 hover 机制正确联动）；
  - 与用户名间距 `gap = 8px`、垂直中心差 `0`、右缘与内容区右缘同为 176（箭头贴内容最右）；console 0 error。

## 踩坑（验证时）

用 `btn.querySelector('span')` 取用户名会命中 naive 的 `.n-button__content` 容器（NButton 用 span 包内容），导致算出 `gap = -14` 的假重叠；应选 `.flex-center > span`（ButtonIcon 插槽内层 div 的直接子 span）。
