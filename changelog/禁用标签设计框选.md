# 禁用标签设计框选

- 日期：2026-09-11
- 关联：`src/views/system-manage/print-design/index.vue`
- 前置：[标签设计工作区无限画布改造](./标签设计工作区无限画布改造.md)

## 问题现象

在设计器标签纸张内的空白处按下并拖动，会出现红色矩形选框（hiprint 的区域框选 / 多选），需要禁用该框选。

## 排查（源码定位）

从 `node_modules/vue-plugin-hiprint/dist/vue-plugin-hiprint.js` 定位到 `bindBatchMoveElement()`：

```js
this.designPaper
  .getTarget() // = .hiprint-printPaper（冒泡阶段绑定）
  .on('mousemove', function (t) {
    if (s.a.instance.draging) return;
    if (1 === t.buttons && s.a.instance.rectDraging && e.mouseRect) {
      e.mouseRect.updateRect(t.pageX, t.pageY, e); // 更新红框
      e.updateRectPanel(e.mouseRect);
    }
  })
  .on('mousedown', function (t) {
    s.a.instance.rectDraging = !0; // 无条件置位
    // ...
    if (1 === t.buttons && t.target.className.includes('hiprint-printPaper hidroppable design')) {
      e.mouseRect = new at(t.pageX, t.pageY /* ... */); // 仅“纸张本身”作为 target 时创建选框
    }
  })
  .on('mouseup', function () {
    s.a.instance.rectDraging = !1;
  });
```

## 根因

- 框选 = `rectDraging` 标志 + `mouseRect` 选框，绑定在 **`.hiprint-printPaper` 的冒泡阶段**；
- 触发前提：mousedown 的 `target` 正好是纸张本身（空白处、无元素覆盖）。

## 修复

`index.vue` 的 `.print-design-canvas` 改为**捕获阶段**监听 mousedown（`@mousedown.capture`），在祖先处拦截，事件不会到达 hiprint 的监听器：

```ts
function handleCanvasMouseDown(e: MouseEvent) {
  const target = e.target as HTMLElement | null;
  // 纸张内的元素：放行，交给 hiprint 拖拽/选中/编辑
  if (target?.closest('.hiprint-printElement')) return;

  // 其余区域（画布空白 + 纸张空白）：阻止 hiprint 收到 mousedown
  // → 不置 rectDraging、不创建 mouseRect，框选被禁用
  e.stopPropagation();

  // 该区域同时用于平移工作区
  // ...
}
```

- 捕获阶段早于 hiprint 在纸张上的冒泡监听，`stopPropagation()` 后 hiprint 收不到 mousedown，框选不再出现。
- **必须对纸张内的元素放行**（`closest('.hiprint-printElement')` 判断），否则会连带禁用 hiprint 的元素拖拽（其拖拽依赖 document 上的冒泡监听）。

## 行为变化

- 纸张空白拖拽：由「框选」变为「平移工作区」（与上一轮「鼠标可拖动标签画布」的需求一致）。
- 纸张内元素拖拽 / 选中 / 双击编辑、键盘方向键移动：不受影响。

## 验证

1. 纸张空白处按下拖动：不再出现红色选框，改为平移工作区。
2. 纸张内元素：可正常拖动、点击选中、双击编辑。
3. 画布空白：仍可平移。
