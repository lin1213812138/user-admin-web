# 站点管理 关联用户/客户为空时不弹窗

## 用户提示词

> 如果没有关联的用户和客户就提示为空，不要弹窗

（附站点管理列表截图，红框圈「关联用户」「关联客户」两列的「查看」按钮）

## 背景

站点管理列表新增的「关联用户 / 关联客户」列点击「查看」会无条件打开 `RelationModal` 弹窗。当站点没有任何关联用户或客户时，用户看到的是一个空表格弹窗，体验不佳。

## 需求

没有关联数据时，直接给一个「为空」的提示，**不要**打开弹窗。

## 方案与实施

改动仅一处：`src/views/system-manage/site/index.vue` 的 `openRelationModal()`。

- 改为 `async`：先设置 `relationRow.value = row`（弹窗取数函数 `fetchRelationUsers` / `fetchRelationCustomers` 通过闭包读取该 ref，必须先赋值）。
- 复用现有 fetcher 做一次**探查请求**（`page: 1, size: 1`），只取 `total` / `list.length` 判断是否为空：
  - 为空 → `window.$notification?.info({ title: $t('common.noData'), duration: 3000 })`（复用既有 i18n key「无数据」，不新增词条；按用户要求使用 Notification 组件而非 message），并 `return`，不打开弹窗；
  - 不为空 → 按原逻辑打开对应弹窗（弹窗打开后 `RelationModal` 自己会重新拉第一页完整数据，探查请求仅多一次 size=1 的轻量查询）。
- 用户 / 客户两条路径共用同一逻辑，零重复代码。

## 不做的事

- 不改 `RelationModal` 公共组件（「打开即取数」语义保持不变，判空属于调用方交互策略）。
- 不改后端、不新增 i18n key。

## 验证

- read_lints：0 诊断。
- 建议实测：点击无关联站点的「查看」应只出现「无数据」提示；点击有关联站点的「查看」弹窗行为与之前一致。
