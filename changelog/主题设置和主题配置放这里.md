# 主题设置和主题配置放这里

- **日期**：2026-09-16
- **用户指令**：截图红框标在标签栏右侧（刷新 + 全屏按钮处）：「主题设置和主题配置放这里」

## 背景定位

- 本仓库 header 栏已整体下线（`base-layout/index.vue` `header-visible="false"`，`GlobalHeader` / `ThemeDrawer` 均被注释，用户区移至侧栏底部），主题相关入口随之完全消失。
- 标签栏右侧现状：`ReloadButton`（刷新）+ `FullScreen`（内容全屏，即截图中的九宫格图标）。
- 主题配置抽屉 `ThemeDrawer`（标题「主题配置」；外观/布局/通用/预设 4 tab + ConfigOperation）组件完好未渲染；`appStore.openThemeDrawer` 状态仍在。

## 澄清确认

问询「主题设置和主题配置」具体指什么 → 用户选**两个按钮**：

1. 主题模式切换（浅色/深色/跟随系统三态循环，原 header 上的太阳/月亮图标）；
2. 主题配置抽屉入口（打开完整主题抽屉）。

- **A（采纳）**：global-tab 右侧直接追加两按钮，`ThemeButton` 跨目录 import 复用 + 恢复 `ThemeDrawer`。零新文件。

## 组件注册方式（决定引入写法）

- `ThemeSchemaSwitch` = `src/components/common/theme-schema-switch.vue` → unplugin 自动注册，模板直接写标签。
- `ThemeButton` = `src/layouts/modules/global-header/components/theme-button.vue` → layout 局部组件，global-tab 显式 `import ThemeButton from '../global-header/components/theme-button.vue'`。
- 两者均为 `ButtonIcon` 封装，与刷新/全屏同尺寸同 hover；tooltip 复用 i18n `icon.themeSchema`（主题模式）/ `icon.themeConfig`（主题配置），零 i18n 新增。

## 改动（2 文件）

1. `global-tab/index.vue`：script 加 ThemeButton import；模板右侧操作区变为 **刷新 → 全屏 → ThemeSchemaSwitch（`:theme-schema` + `@switch="themeStore.toggleThemeScheme"`）→ ThemeButton**（工具类在左、主题类在右）。
