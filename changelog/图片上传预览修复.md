# 图片上传控件选图后不显示预览修复

日期：2026-09-15

## 问题定位

用户截图反馈（公司 LOGO 位置只剩一个空图片卡片）："上传后看不到也不能预览"。

根因（naive-ui `NUpload` 源码核对）：

- `NUpload` 在 `default-upload=false` 时选择文件，生成的文件项是
  `{ status: 'pending', url: null, thumbnailUrl: null }`（`Upload.mjs:442-453`）；
- `image-card` 的缩略图与预览按钮判定条件为 **`status === 'finished'` 且 `mergedThumbnailUrl` 非空**
  （`UploadFile.mjs:117-129`、`:282`），预览弹层也用 `file.url`（`:300`）；
- `FormWrap` 的 `handleUploadChange` 仅在 `last.url` 已是 blob 时才记录本地预览，而 naive 从不给未上传文件
  `url` —— 于是重建 file-list 时 `url` 恒为空，卡片只能显示占位图标，也无法点预览。

## 修复

`src/components/Form/index.vue`（通用 FormWrap，所有 `image`/`file` 控件受益）：

- 新增 `resolveUploadPreview(file)`：优先用文件项已有地址，否则 `URL.createObjectURL(file.file)` 生成 blob
  预览地址；
- `handleUploadChange`：改用该方法生成预览并写回 `uploadPreview[key]`（替换原「仅当 last.url 为 blob 才记录」）；
  换图时 `URL.revokeObjectURL` 回收上一个 blob；
- 新增 `onBeforeUnmount` 兜底回收本组件创建的 blob 地址，避免内存泄漏。

不改：`uploadFileList`（仍以 `status: 'finished'` + 派生地址构造受控列表）、模板、`type: 'file'` 行为、
其它字段与校验逻辑。

## 验证

- `pnpm typecheck` 0 错误；单文件 oxfmt / oxlint / eslint 0；
- 无浏览器端到端（本地无后端会话），最终效果由用户确认（预期：选图后卡片内即显示缩略图，卡片上出现
  预览 / 删除按钮，点预览可放大）。
