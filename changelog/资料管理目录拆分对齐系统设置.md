# 资料管理目录拆分对齐系统设置

> 用户贴 `data-manage/modules/archives` 目录树截图（红框圈 `archives`）：「把这个拆开，跟系统设置的文件布局一样」。

## 决策（用户确认）

1. **拆掉 `archives` 中间层**，把 basic / business / finance / no-rule 各自子档案搬进本页私有目录，整体对齐 `system-manage/setting` 的三段式布局：
   - `index.vue`（壳，VerticalTabLayout）
   - `modules/<项>/<Item>.vue`（每个子档案一个目录，Pascal 命名、非 index.vue）
   - `components/`（页面/跨页私有共享文件）
2. **`master-data-archive.vue` 不再作为公共组件**：每个分组各持一份副本（basic / business / finance 各 1 份）。no-rule 页的 `NoRule.vue` 本就自包含、并不消费该组件，故不建副本（避免死代码）。
3. 共享的 `shared.ts`（`useArchiveStatusOptions`）、`types.ts`（`ArchiveConfig<T>` / `ArchiveTabItem`）、`archive-switch.vue`（死代码，保留）搬进 `data-manage/components/`。

## 目标结构

```
src/views/data-manage/
├── basic/        index.vue + modules/{country-region,postal-route,fba-warehouse,customer-level,customer-source}/<Item>.vue + components/MasterDataArchive.vue
├── business/     index.vue + modules/{address,clearance-method,customs-type,declared-goods,export-reason,goods-category,problem-category,sales-terms}/<Item>.vue + components/MasterDataArchive.vue
├── finance/      index.vue + modules/{account,currency,expense-type,settlement}/<Item>.vue + components/MasterDataArchive.vue  (tax/ 为预存孤儿，未动)
├── no-rule/      index.vue + modules/no-rule/NoRule.vue
└── components/   shared.ts · types.ts · archive-switch.vue(死代码)
```

## 实施

- 文件夹整体 `Move-Item`（规避 Windows `git mv` 的 ENOENT）+ `git add -A`；`master-data-archive.vue` 复制 3 份，副本内部 `from './types'` 改 `@/views/data-manage/components/types`。
- 不新增任何 `index.vue` / `[*].vue`，私有组件命名均非 index.vue、`components/` 被 elegant-router 排除 ⇒ **不生成任何新路由**，4 个既有路由页不变。

## 踩坑（已排）

1. **PowerShell `Set-Content` 默认 UTF-16 LE 写坏 7 个文件**（4 个 `index.vue` + 3 份 `MasterDataArchive` 副本：BOM `FF FE` + 每字符带 `0x00` ⇒ oxlint 报 「stream did not contain valid UTF-8」）。纯 ASCII 的 18 个档案 `.vue` 不受影响。
   - 3 份副本为 ASCII（含已修正的 `./types` 导入），用 `utf16le → utf8` 解码无损恢复。
   - `no-rule/index.vue` 含中文注释，用 UTF-8 安全的 `write_to_file` 按正确内容重写。
2. **误用 `git checkout` 回退 3 个受跟踪的 `index.vue`**：这 3 个文件「指向 `views/data-manage/modules`」是 2026-09-17 重构的**未提交**改动，`git checkout` 把它们回退到旧的 `@/components/MasterData/...` 引用 ⇒ typecheck 报 TS2307。改为按工作树正确内容重建：`basic` 5 项 / `finance` 4 项 / `business` 8 项（business drop 旧 `waybill`，当前 `business/modules` 已无该目录）。
