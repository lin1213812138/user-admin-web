# 合并用户「新增 / 编辑 / 详情」抽屉并改用两张卡片

> 日期：2026-09-18
> 触发：用户贴编辑抽屉截图，要求「个人档案」也用卡片包起来；随后明确「新增界面也要用两个 card 包起来，算了直接把新增修改界面合并一下」，并最终拍板「新增和修改都用 `user-operate-drawer.vue` 就可以了」。

## 背景与问题

改造前用户管理有两套抽屉，字段集不一致且入口分裂：

- `user-operate-drawer.vue`：一体化 `NFormWrap`，支持 **新增/编辑/详情** 三种模式，含 `password` / `idCard` / `qrCodeUrl` 等字段，但整张表单只用一个 `section` 标题分块、没有卡片。
- `user-edit-drawer.vue`：拆成 `BasicInfo` + `Profile` 子组件，用 `NCard(基本信息)` + `NTabs(个人档案 / 配置权限 / 账号配置)`，但**只支持编辑**，且 `Profile` 漏掉了 `idCard`、`qrCodeUrl` 两个字段。

问题：同一业务「编辑」有两个入口、两套字段口径；「个人档案」未用卡片包裹，与「基本信息」视觉不一致；截图还标注要去掉「配置权限 / 账号配置」两个 tab。

## 决策（用户确认）

- 合并为统一抽屉，**新增/编辑/详情都走 `user-operate-drawer.vue`**。
- 整体用**两张卡片**包裹：`基本信息` + `个人档案`。
- 移除「配置权限 / 账号配置」两个 tab（及其 `Perm` / `Account` 组件）。

## 实施

### `src/views/system-manage/user/modules/user-operate-drawer.vue`（统一抽屉）

- 引入 `naive-ui` 的 `NCard`。
- 拆 `formItems` 为两段 `computed`：
  - `basicItems`：账号 / 名称 / 密码 / 站点 / 状态 / 角色 / 组别（角色、组别仍为 `custom` 插槽走多选 `NSelect`）。
  - `profileItems`：真实姓名 / 性别 / 生日 / 身份证 / 电话 / 邮箱 / 微信 / 其它联系方式 / 职位 / 入职 / 地址 / 附件 / 二维码 / 备注。
  - 去掉原来 `basicInfo` / `profileInfo` 两个 `section` 标题项（改由 `NCard` 标题承载）。
- 表单 `ref` 拆为 `basicFormRef` / `profileFormRef`（两个 `NFormWrap` 各自对应一张卡片，但共享同一个 `model`）。
- 模板改为两张 `NCard`：`<基本信息>` 包 `basicFormRef` 那个 `NFormWrap`（含 roleIds/groupIds 插槽），`<个人档案>` 包 `profileFormRef` 那个 `NFormWrap`。
- `handleSubmit`：`Promise.all` 同时校验两张卡片，`basicValid || profileValid` 任一不过则拦截；其余提交逻辑（`md5` 加密密码 / 编辑留空不修改 / create vs update 分支）保持不变。
- `:mode="isDetail ? 'view' : 'edit'"` 下传到两个 `NFormWrap`，详情态只读脱敏；`:footer="!isDetail"` 详情态隐藏底部按钮。

### 删除

- `src/views/system-manage/user/modules/user-edit-drawer.vue`
- `src/views/system-manage/user/modules/edit/BasicInfo.vue`
- `src/views/system-manage/user/modules/edit/Profile.vue`
- `src/views/system-manage/user/modules/edit/Perm.vue`
- `src/views/system-manage/user/modules/edit/Account.vue`

### `src/views/system-manage/user/index.vue`（父页面）

- 删除 `UserEditDrawer` 导入与 `editVisible` / `editRow` 状态。
- `handleEdit(row)` 改为调用统一的 `openDrawer('edit', row)`；`create` / `edit` / `detail` 三个入口全部经 `UserOperateDrawer`（`:mode` / `:row` / `@submitted`）。
- 模板删除独立的 `<UserEditDrawer>` 调用。

## 不做

- 不引入新的公共 `UserDrawer` 抽象（沿用现有 `@/components/common/drawer.vue`）。
- 不保留「配置权限 / 账号配置」功能（当前列表页无其它入口引用）。
- 不改动后端、路由、菜单、权限、i18n 结构（`basicInfo` / `profileInfo` 等 key 已存在）。
