# 申报物品改造为地址簿布局（申报物品库 + 清关目的地）

> 状态：**已实施（2026-09-19），待手动冒烟**

## 用户输入

- 提供 tms-user 后端两个 Schema：`Product`（申报物品，nameCn/nameEn/price 必填，含 hsCode/destHsCode/currency/unit/weight/producer/brand/material/use/model/standard/feeCustom/taxRate/sku/sellUrl/imgUrl 等字段）、`ProductCountry`（清关目的地，code/nameCn 必填，含 nameEn/name/code2/code3/order）。
- 附老系统侧栏截图：`申报物品(15)` 下有 `申报物品库(9)`、`清关目的地(6)` 两个子项。
- 要求：「申报物品」跟「地址簿」的布局一样。

## 现状定位

- 前端现有 `src/views/data-manage/business/modules/declared-goods/DeclaredGoods.vue` 走 `MasterDataArchive` 通用档案（code/name/remark 三字段），与 Product Schema 完全不符，属占位实现。
- 「地址簿」布局参考 `business/modules/address/Address.vue`：NCard + NTaps 双子页签（收件地址/发件地址）+ KeepAlive 懒加载；每个子组件 = `useVxeTable` + `<Table>` + `XxxOperateDrawer`（Drawer + NFormWrap）。
- 后端接口已就绪（tms-user）：
  - `/product/query|get|create|update|delete`（delete 传 `ids: string[]`，create 校验 nameCn/nameEn/price）
  - `/product-country/query|get|create|update|delete`（delete 传 `_id`，create uniq: code+nameCn）
  - 分页契约 `{ page, size, keyword, keywordFields, where }` → `{ list, total }`（queryCommon），与 data-manage-bl 一致。
  - product query 服务端按 `order:-1` 排序并 fillName 目的地；product-country query keywordFields 为 `code/name/nameCn`，排序 `order:-1, code2:1`。

## 设计方案

1. **类型**：新建 `src/typings/api/declared-goods.d.ts`，`Api.DeclaredGoods` 命名空间：`Product` / `ProductCountry` / `QueryParams` / `QueryResult<T>`。
2. **接口层**：新建 `src/service/api/declared-goods/index.ts`（真实接口、flat request、`{ data, error }` 解包，风格对齐 `data-manage-bl`）：`fetchGetProductList / fetchCreateProduct / fetchUpdateProduct / fetchDeleteProducts(ids)` + `fetchGetProductCountryList / fetchCreateProductCountry / fetchUpdateProductCountry / fetchDeleteProductCountry(_id)`。
3. **容器重写**：`DeclaredGoods.vue` 改为 `Address.vue` 同款双 tab —— `申报物品库` / `清关目的地`，KeepAlive + 动态组件。
4. **申报物品库**：`modules/declared-goods/product/Product.vue` + `ProductOperateDrawer.vue`；列（中文名称/英文名称/HS编码/单价/币种/单位/净重/SKU/品牌/材质/目的地/备注），关键字搜索 `keywordFields: ['nameCn','nameEn','hsCode','sku']`；抽屉表单含全部 Product 字段，unit 下拉 14 项（PCS/SET/MTR/KG/ROLL/BOX/PRS/DOZ/PKGS/EA/M2/M3/CM/CM3），nameCn/nameEn/price 必填（与后端校验对齐）。
5. **清关目的地**：`modules/declared-goods/product-country/ProductCountry.vue` + `ProductCountryOperateDrawer.vue`；列（编码/中文名称/英文名称/常用名称/二字码/三字码），code/nameCn 必填。
6. **i18n**：`zh-cn.ts` / `en-us.ts` 的 `page.dataManage.business.declaredGoods` 下补 `library / clearanceDestination` 及字段文案；`typings/app.d.ts` 同步类型。
7. **不动**：菜单/路由/权限 tab（沿用 `system:dataBusiness:declaredGoods`）、MasterDataArchive 公共组件与 `data-manage-archive` 接口（其它档案仍用）。
