# 资料管理子档案按需懒加载

日期：2026-09-03

## 问题

`src/views/data-manage/{basic,finance,business}/index.vue` 三页结构几乎相同，打开模块页会一次性构建本页 **4 个子档案表格**并发 4 个请求：

- 静态 `import` 本模块全部 4 个档案组件（同页 chunk 一起打包）；
- 页面 `onMounted` 后 `requestIdleCallback` 把 4 个档案全部标记已挂载；
- 每个档案（`MasterDataArchive`）`setup` 即触发 `useVxeTable({ immediate: true })` → 初始化一张 VXE 表格 + 一次数据请求。

首屏因此明显卡顿。

## 决策（用户已确认）

改为**首次访问才加载 + 界面缓存**：

- 打开模块页只加载当前默认档案（1 表格 + 1 请求）；
- 点击其它档案时才首次加载（异步 chunk）；
- 已访问档案用 `<KeepAlive>` 缓存：切回秒恢复、搜索条件/页码保留、不重发请求；
- 不做路由/菜单/i18n/mock/`MasterDataArchive` 改动。

用户要求必须用 `KeepAlive` 缓存界面，而非"隐藏层常驻 DOM"（后者所有访问过的表格实例一直占 DOM/内存）。

## 实现

1. **新增共享容器** `src/components/MasterData/archive-switch.vue`：
   - `props.items: { key, labelKey, load }[]`；
   - 用 `defineAsyncComponent({ loader, loadingComponent })` 生成异步组件（`loadingComponent` 为函数式组件：全屏居中 `<NSpin>`，符合项目禁 Options API 的 lint）；
   - 内容区单实例渲染：`<KeepAlive><component :is="asyncComps[activeKey]" :key="activeKey" /></KeepAlive>`；
   - `activeKey` 默认第一个档案。
2. **三个模块页瘦身为纯配置壳**：`basic/finance/business/index.vue` 仅提供 4 个档案的 `key/labelKey/load`（labelKey 沿用原 `archiveMap` 的 i18n key，load 指向各自 `index.vue`）。

## 追加调整（动画 + loading 体验，同会话）

1. **切换带动画（跟随主题）**：内容区外层加 `<Transition :name mode="out-in">`，`name` 读 `themeStore.page.animate ? themeStore.page.animateMode : ''`（与布局主内容 `global-content/index.vue` 完全同一套写法），关闭主题"页面动画"开关后切换动画一并关闭；CSS 动画类复用全局 `src/styles/css/transition.css`，无需新增样式。
2. **loading 落在表格而非整屏**：用户明确"不要整个界面的 loading，要表格 loading"。撤销上一版 `sleep(300)` 人为整屏 NSpin（`MIN_LOADING_MS`）。`defineAsyncComponent` 的 `loadingComponent` 仅作为 chunk 真实加载期间的兜底（本地毫秒级、几乎不可感知）。
3. **mock 数据异步化**：`src/service/api/mock-data-manage.ts` 四个函数由同步 `Promise.resolve` 改为 `await delay(...)`：列表 `LIST_DELAY_MS=400`、增/删/改 `MUTATE_DELAY_MS=200`。这样 loading 有真实可见时长——界面/表格先渲染，数据稍后填充，符合真实请求形态。切换已访问档案仍走 KeepAlive 缓存，无请求无 loading。
4. **表格 loading 改用 Naive UI `NSpin`**（用户明确要求，不用 vxe-table 自带遮罩）：通用 `Table` 组件 `src/components/Table/table.vue` 去掉 `vxe-table :loading`，改在表格外层包 `<NSpin :show="loading" size="large" class="h-full w-full" :content-style="{ height: '100%' }">`（`NSpin` 全局自动注册，`components.d.ts` 已有，无需显式 import）。NSpin 包裹时对内容做 `--n-opacity-spinning` 淡化和居中转圈，符合组件库 loading 语义；对全项目所有 `Table` 生效。`content-style` 高度 100% 保证 vxe-table `height: 100%` 不塌陷。
5. `Transition`/`KeepAlive` 组合与 `global-content` 一致，档案组件根为单元素 `div.h-full.w-full`，out-in 安全。
