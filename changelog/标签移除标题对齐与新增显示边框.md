# 标签样式：移除标题对齐 + 新增显示边框

> 日期：2026-09-12　模块：`src/views/system-manage/label-designer`

## 一、移除「标题对齐」样式项

行内连续排版（见《标签标题与内容垂直错位》）下标题跟随内容对齐，「标题对齐」（`titleAlign`）已无意义，用户要求移除：

- `types.ts`：`DataPreviewExtras` 删 `titleAlign` 字段。
- `store/modules/label-design/index.ts`：text/longText/barcode/qrcode 默认 options 删 `titleAlign: 'center'`。
- `property-panel.vue`：`titleStyleItems` 删该项（剩标题字号/颜色/字重 3 项）。
- i18n：`propTitleAlign`（zh/en/typings 三处）删除。
- 旧 designJson 中残留的 `titleAlign` 无害（渲染层已不读取），无需迁移。

## 二、新增「显示边框」

经确认：范围 = **文本+条码+二维码**（与标题能力同范围）；参数 = **开关+宽度+颜色**（与矩形同模式，默认关）。

- `types.ts`：新增 `BorderExtras`（`showBorder?` / `borderWidth?` / `borderColor?`），`DataPreviewExtras extends BorderExtras`，text/longText/barcode/qrcode 自动获得能力。
- `store` 默认值：`showBorder: false, borderWidth: 1, borderColor: '#000000'`。
- `property-panel.vue`：`borderStyleItems`（开关 + 开启时才显示宽度/颜色，`borderEnabled` computed 控制显隐），追加到 text/longText/barcode/qrcode 四类样式项末尾。⚠️ 条件展开数组需 `as FormItemConfig[]` 标注，否则对象字面量 `type` 被推宽为 string 报 TS2769。
- 画布 `element-renderer.vue`：`borderStyle` computed（`showBorder` 时 `border: Npx solid color` + `box-sizing:border-box`），应用到文本分支（`:style="[textStyle, borderStyle]"`）与非文本分支容器。
- 打印 `render-element-html.ts`：`borderCss` 字符串，文本分支与 `wrapContent`（img / 容器）统一拼接；`pos` 已含 `box-sizing:border-box`，边框不撑大元素，两端尺寸一致。
- 旧数据兼容：`showBorder` 缺省 = 关，渲染层 `?? 1` / `?? '#000000'` 回退。
- i18n：新增 `propShowBorder`（显示边框 / Show Border），zh/en/typings 三处同步；`propBorderWidth` / `propBorderColor` 复用矩形既有键。

验证：`pnpm typecheck` 通过。
