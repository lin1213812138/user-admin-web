# 录单格式改纯列表 + Drawer 新增/编辑界面

> 日期：2026-09-17
> 触发语：「录单格式该成纯列表形式，这个直接变成新增、编辑界面」

## 1. 背景与现状

`views/system-manage/setting/modules/input-format/InputFormat.vue` 原为 `MasterDetail` 左右布局：左侧 240px 常驻格式列表（含搜索框），右侧常驻「基本信息表单 + 字段映射」，靠顶部按钮切换只读/编辑态；数据为页面内 `ref` 假数据（10 条显式 + 30 条铺量），无 service。

用户要求：列表回归普通列表页形态，右侧详情区改成点「新增/编辑」才打开的编辑界面。

## 2. 方案（用户逐项确认）

| 项           | 结论                                                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------------------------- |
| 编辑界面载体 | Drawer 右侧滑出，宽 900（对齐 export-format / print-format 范式）                                                   |
| 列表操作     | 勾选 + 批量删除 + 行内「编辑/删除」，顶部「新增」                                                                   |
| 状态列       | 只读状态标签（`type: 'status'`），编辑界面内切换                                                                    |
| 数据层       | 抽成 service（DEV 内存 mock），对齐 print-format，后续换真接口只改该文件                                            |
| 搜索         | 保留简版名称搜索（Table `#search-action` 快速搜索卡片）                                                             |
| 顺带修复     | 原数据 `scope` 含 `wechat`（微信小程序）但表单勾选项只有两项 → 勾选项补全三项，列表「适用范围」列用 `NTag` 多值展示 |

## 3. 实施结果

- 新增类型 `src/typings/api/input-format.d.ts`：`Api.InputFormat`（`Scope` / `FieldMappingValue` / `Format` / `List` / `SearchParams` / `CreateParams`），对齐 print-format/export-format 命名空间范式。
- 新增 service `src/service/api/input-format/index.ts`：DEV 内存 mock（原 40 条数据搬迁 + `mockSeq` 自增），`fetchGetInputFormatList`（名称模糊 + 分页）/ `fetchCreateInputFormat` / `fetchUpdateInputFormat` / `fetchDeleteInputFormat`（批量）；非 DEV 走 `request`（URL 自拟 `/input/format/*`，待后端）；`src/service/api/index.ts` barrel 追加导出。
- 重写 `input-format/InputFormat.vue`：`Table` + `useVxeTable`（cacheKey `setting-input-format`，分页默认 50）；列 = 格式名称（detail 可复制）/ 适用范围（NTag 三色）/ 备注 / 状态（status，fixed right）+ 操作列；`#search-action` 名称搜索卡片（回车/按钮查询、重置）；`operation-left` = 新增 + 批量删除；`operation-right` = 刷新 + 列配置；`@page-change` / `@selection-change` / `NPopconfirm` 删除确认。
- 新增 `input-format/input-format-drawer.vue`：新增/编辑抽屉（`v-model:show` + `row` + `submit` 事件）；内容 = `NFormWrap`（名称 span 12 必填 / 状态 switch span 12 / 适用范围 checkbox 三项 span 24 / 备注 span 24）+ `FieldMapping`（五组 22 字段，非 fill 模式随抽屉整体滚动）；打开时编辑回显 / 新建清空（`watch([show, row])`）。
- i18n 三处：`setting.inputFormat` 由字符串改为对象（`title/name/scope/scopeInternal/scopeCustomer/scopeWechat/newTitle/editTitle/namePlaceholder/remarkPlaceholder`）——zh-cn、en-us、`typings/app.d.ts` Schema 同步；`setting/index.vue` tab label 引用改为 `inputFormat.title`。

## 4. 验证

- `pnpm typecheck` exit 0（中途修复 1 处：`scopeTagTypes[s]` 因表格插槽 `row` 为 any 报 TS7053，key 类型放宽为 `Record<string, ...>`）。
- `pnpm lint` oxlint 0 error + eslint 0 error。
- 页面效果（列表分页/搜索、Drawer 编辑回显、字段映射勾选、批量删除）待用户复核。

- `MasterDetail.vue` 仍被 print-format、init-data 使用，未删除。
