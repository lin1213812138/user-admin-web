# 标签设计器：按住条目即显示「真实渲染预览」

日期：2026-09-14
范围：`modules/canvas/drag-ghost.ts`（重写）、`modules/canvas/drag-preview.vue`（新增）、`modules/panels/field-panel.vue`、`store/modules/label-design/index.ts`

## 背景

用户需求（设计已逐项确认）：

1. **按下（pointerdown）就立即显示预览** —— 不用等浏览器判定 dragstart；
2. **预览是真实渲染效果** —— 条码字段直接显示条码图 + 编码值，文本字段显示「标题: 值」（带测试数据），与落纸后的元素完全一致；
3. 只是点击（按住没拖）时**预览立即消失**，不做动画；
4. 预览**不加装饰**（1:1 与落纸后一致，无边框/阴影）。

## 架构

### 会话模型（`drag-ghost.ts` 重写）

会话从 **pointerdown** 开始，到 **pointerup**（点击）或 **dragend**（拖拽）结束：

```
pointerdown  → beginDragPreview(e, sourceEl, element)
               ├─ 建立 session（源项 / 抓取偏移 / 指针位置）
               ├─ previewElement = element（Vue 渲染真实内容）
               ├─ nextTick 后按「指针 − 抓取偏移」定位
               └─ 挂 window pointerup / pointercancel（点击判定）
dragstart    → startDragGhost：dragging = true、摘掉点击判定监听、
               1×1 透明图顶掉原生影子、接管 document 级 dragover/drop
dragover     → 更新预览 left/top（跟手；HTML5 拖拽期间 pointermove 不触发）
pointerup    → 未进入拖拽 → 只是点击 → 预览立即收起（无动画）
dragend      → 已落纸：淡出 120ms；未落纸：rAF 补间飞回源项（BACK_MS = 260）
```

按下到 dragstart 之间只有几像素位移，不监听 pointermove（预览基本不动，无感）。

### 预览浮层（`drag-preview.vue` 新增）

- `Teleport` 到 body + `v-if="previewElement"`，内部直接复用画布的 `ElementRenderer`（渲染同源）；
- 尺寸 = 元素默认尺寸（pt → px，`PX_PER_PT`），与画布 zoom=100% 观感一致；
- 位置由 `drag-ghost` 直写 `left/top`（不走响应式，避免跟手时的重渲染开销）；
- 容器 ref 用 script 内函数回调 + `instanceof HTMLElement` 收窄（模板内 `as` 断言会触发 `vue/no-undef-properties` lint 误报）。

### 数据同源（store）

导出 `defaultOptionsFor` / `defaultSize`（`defaultOptionsFor` 参数类型放宽为 `Pick<ElementDescriptor, 'type' | 'defaultOptions'>`），
`field-panel` 用它构建预览元素 —— **预览与落纸创建的元素走同一套默认值**，不会出现「预览一个样、落纸另一个样」。

## 关键实现点

- HTML5 拖拽期间 **pointerup 不触发**：`dragstart` 时必须摘掉「点击判定」监听，否则它会残留到下一次点击才触发（并误收起预览）；
- `pointercancel` 同步兜底（指针被系统收回）；
- 落纸位置用的是 `onDrop` 的 `getDragOffset()`（现在直接读 session 的抓取偏移），与预览定位公式一致 → 松手即「落在预览所在位置」。
