# 设置页：基础配置置顶 + 去掉初始化数据模块

> 日期：2026-09-17
> 触发语：用户 ——「基础配置提到最上面的模块，并且把初始化数据模块去掉」

## 1. 需求与澄清

**原始需求**：① 设置页左侧 tab 中「基础配置」提到最上面；② 去掉「初始化数据」模块。

**两项澄清确认**：

| 问题           | 用户选择                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| 「去掉」的范围 | **连同代码一起删除**：`modules/init-data` 目录、`service/api/init-data`、i18n 中 `initData` 段       |
| 默认选中的 tab | **默认选中「基础配置」**（与它排在最上面一致，打开设置页即显示基础配置表单），而非保持原「录单格式」 |

## 2. 最终形态（设置页 6 个 tab）

| 顺序 | tab          | 变化                           |
| ---- | ------------ | ------------------------------ |
| 1    | 基础配置     | 由第 6 位提到第 1 位，默认选中 |
| 2    | 录单格式     | 位置后移                       |

| —    | 初始化数据   | **整模块删除**                 |

## 3. 实施内容

- **页面** `setting/index.vue`：`tabs` 调整为上述 6 项并重排；`activeKey` 默认值 `'input-format'` → `'basic-config'`；`componentMap` 同步重排并移除 `'init-data'`；`activeComponent` 兜底 `InputFormat` → `BasicConfig`；删除 `InitData` import；注释更新。`?tab=` 同步逻辑与 `VerticalTabLayout` 壳未动（旧 `?tab=init-data` 链接因 `tabs.some` 不匹配自动保持默认基础配置）。
- **删除视图**：`views/system-manage/setting/modules/init-data/` 整目录 —— `InitData.vue`、`InitDataCategory.vue`、`init-data-form-drawer.vue`、`init-data-info.ts`（此前已无引用的 `InitDataCategory.vue` 一并清理）。
- **删除 service**：`service/api/init-data/index.ts`；`service/api/index.ts` 移除 `export * from './init-data'`。
- **删除 mock**：`service/api/mock.ts` 的 init data 段（`createInitData` / `initDataItems` 40 条数据 / `initDataCnNameExists` / `mockGetInitDataList` / `mockCreateInitData` / `mockUpdateInitData` / `mockDeleteInitData`）；被 customer / trace 段共用的 `todayStr` / `CURRENT_OPERATOR` 保留。
- **删除类型**：`typings/api/system-manage.d.ts` 的 `InitDataCategory` / `InitDataItem` / `InitDataList` / `InitDataSearchParams` / `InitDataCreateParams` / `InitDataUpdateParams` 共 6 个类型。
- **删除 i18n**：`locales/langs/zh-cn.ts`、`en-us.ts`、`typings/app.d.ts`（`I18nKey` 派生来源）三处 `setting.initData` 段同步删除。
- **未动**：`setting/components/MasterDetail.vue`（通用死代码组件，按仓库惯例保留）；路由配置（设置页为单路由）；`vxe-table-column:setting-init-data-v2` 的 localStorage 残留（无害）。
