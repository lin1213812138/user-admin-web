## 设计

### 1. 数据文件（src/constants）

`src/constants/button-permissions.ts` → 重命名 **`src/constants/menu-permissions.ts`**（内容保留 + 扩展）：

- 保留：`ButtonPermission`、`op()` 按钮生成器、`user/role/menu/site/group/customer/setting/dataBasic/dataBusiness/dataFinance` 10 组按钮定义、`getMenuButtons()`（索引改为从新配置树构建，签名不变）。
- 新增结构：
  - `SubMenuPermission { code, label }` —— 二级菜单权限（界面内子模块）
  - `MenuPermissionItem` —— 二级菜单（`name/icon/routePath/permission/buttons/subMenus`）
  - `MenuPermissionGroup` —— 一级菜单（`name/icon/children`）
  - `MenuPermissionRow` —— 表格树行（派生 `id` + `home` + `checked`）
  - `MENU_PERMISSION_TREE` —— 「一级菜单 → 二级菜单 → 按钮 / 子模块」配置（顺序与侧栏菜单一致）
  - `getMenuPermissionTree()` —— 配置 → 表格树行（**表格自动生成的入口**）
- 菜单层级按**真实菜单**配置，顺带修正原配置中与实际路由不符的两处：`菜单管理` `/system-manage/menu` → `/permission-manage/menu`、`客户管理` `/system-manage/customer` → `/customer-manage/customer`。
- 行 id 规则：一级 `(i+1)*100`、二级 `(i+1)*100+(j+1)`；无子菜单的一级菜单（「首页」）标记 `home`（必选、不可取消勾选）。目前仅前端勾选 / 提交使用，后端权限接口对接真实菜单 id 时只需改 `getMenuPermissionTree()`。

第三列配置（按用户确认的范围）：

- 系统设置：基础配置 / 录单格式 / 打印格式 / 导出格式 / 运单号规则 / 轨迹抓取配置 / 操作轨迹配置
- 基础资料：国家地区 / 邮政路由码 / FBA仓库 / 客户等级 / 客户来源
- 业务资料：单号资料管理 / 地址簿管理 / 申报物品 / 问题类别 / 物品类别 / 报关类型 / 出口原因 / 清关方式 / 销售条款
- 财务资料：费用类型 / 结算方式 / 银行账户 / 结算币种及汇率

### 2. 分配权限抽屉（role-permission-drawer.vue）

- **数据源替换**：删除 `fetchGetRoleMenuTree` + `fetchGetMenuList` 调用与 `mergeRows / flattenMenus / findHomeIds`，改为 `getMenuPermissionTree()` 同步生成（不再有加载失败分支）。
- **三列**：`title`（树列，`headerSlot: nav-header`）/ `buttons`（按钮权限）/ `subMenus`（二级菜单权限），一级菜单行统一显示 `--`。
- **表头全选**：三列表头各带复选框（全选 / 半选 / 无数据禁用）；「导航菜单」列等价原工具栏全选按钮，故移除工具栏的「全选 / 取消全选」按钮。
- **二级菜单权限**与按钮权限同规则：勾菜单默认全选、取消勾选清空、搜索过滤后仍保留、勾权限但菜单未勾时自动勾菜单（新增 `rowSubMenuChecks`）。
- **提交**：`fetchAssignRoleMenu` 提交体新增 `subMenuCodes`（`Api.SystemManage.RoleAssignMenuParams` 同步加可选字段，与既有 `buttonCodes` 同为待后端支持字段）。
- 抽屉宽度 `min(82vw, 1100px)` → `min(92vw, 1400px)`（三列内容更宽）。

### 3. 公共组件（components/Table）

为支持表头全选，给通用表格加**可选**的自定义表头能力（向后兼容，不改既有页面行为）：

- `VxeColumnRenderColumn` / `VxeColumnConfig` 新增 `headerSlot?: string`
- `table.vue`：`<template v-if="col.headerSlot && $slots[col.headerSlot]" #header>` 透传
- `use-vxe-table.ts`：columns computed 透传 `headerSlot`

### 4. 未改动

`service/api/role`、`service/api/mock.ts`（`fetchGetRoleMenuTree` / `mockGetRoleMenuTree` / `MENU_TREE` 保留为死代码，待后端权限接口对接时启用）、角色列表页、其它页面。
