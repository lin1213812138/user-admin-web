# 菜单管理树形子级不显示

> 日期：2026-09-01
> 关联：[菜单管理样式对齐](./菜单管理样式对齐.md)

## 现象

菜单管理列表页每条菜单都平铺在同一行，子级没缩进、也看不到父子层级（`expandAll: false` 下应至少能看到顶级带 ▷、子级缩进排在其下；`expandAll: true` 应全部展开带缩进）。

## 根因

`vxe-table` v4 的 `tree-config` 有**两种模式**（见 `node_modules/vxe-table/es/table/src/table.js` 的 `loadTableData`）：

- **`transform: true`**：用 `XEUtils.toArrayTree` 按 `rowField` + `parentField` 从「扁平数组」自动组树；要求显式给出 `rowField` / `parentField` / `childrenField` / `mapChildrenField`（最后两个必须不同名，否则 `vxe.error.errConflicts`）。
- **未设 `transform`**：把传入的 `data` **原样当作已组好的树**（`treeData = fullData.slice(0)`），此时 `parentField` 完全被忽略。

之前的 `tree-config = { rowField: 'id', parentField: 'parentId', expandAll: false }` **漏了 `transform: true`**，所以走了「原样当树」分支：扁平数据没有 `children` 数组，vxe-table 把每条都当顶级根节点渲染，全部平铺、零缩进。

之前还把 `buildMenuTree` 预组嵌套树后交给表格，又被 vxe-table 当作「已经是树」处理（每条都取 `.slice(0)` 当根），同样平铺。

## 改动

文件：`src/views/system-manage/menu/index.vue`

1. `transform`（API 响应 transform）直接返回扁平数组 `records: r`，不再预建树。
2. `tree-config` 加上 `transform: true` + `childrenField: 'children'` + `mapChildrenField: '_children'`，让 vxe-table 按 `parentId` 自动组树；`_children` 是 vxe-table 内部用、原数据没有的字段，避免与 `childrenField` 冲突。
3. 抽屉 `MenuOperateDrawer` 的父级选择器依赖嵌套 `children`，因此新增 `menuTree = computed(() => buildMenuTree(data.value))`，仍把「树」传给抽屉——表格用扁平 `data`、抽屉用派生树，两者互不影响。

## 验证

- `pnpm typecheck`、`pnpm lint` 通过。
- 菜单列表可正常展开多级子菜单；新增/编辑菜单的父级下拉层级正确。
