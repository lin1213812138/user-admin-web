# 设置页操作按钮样式不统一

## 问题现象

系统设置各 tab（录单/打印/导出/通知/初始化/站点扫描）右侧 `MasterDetail` 卡片头部的操作区：

- 「新增」是带边框的 `ghost` 按钮（带 `+` 图标）；
- 「编辑」「删除」却是无边框的 `text` 文本按钮，且**没有图标**。

三者同处一个工具栏，却混用 ghost（有边框）与 text（无边框）两种形态，且编辑/删除缺图标，视觉割裂、层级不清晰。

## 根因

`src/views/system-manage/setting/components/MasterDetail.vue` 的「新增」按钮用 `type="primary" ghost`，而「编辑」「删除」按钮用了 `type="primary" text` / `type="error" text`，没有与「新增」保持同一按钮形态。

> 注：项目里管理页（user/role/menu/waybill-rule）的「编辑/删除」多为**行内操作列**里的 `text` 按钮，与工具栏 ghost 的「新增」不冲突；但 `MasterDetail` 把三个按钮并排放进同一工具栏，混用就会显得不一致。

## 修复

把「编辑」「删除」由 `text` 改为 `ghost`，与「新增」保持边框一致的形态：

```html
<NButton v-if="editable" type="primary" ghost size="small" @click="emit('create')">
  <template #icon><icon-ic-round-plus class="text-icon" /></template>
  {{ $t('common.add') }}
</NButton>
<NButton v-if="editable" type="primary" ghost size="small" :disabled="selectedId === null" @click="emit('edit')">
  <template #icon><icon-ic-round-edit class="text-icon" /></template>
  {{ $t('common.edit') }}
</NButton>
<NButton v-if="editable" type="error" ghost size="small" :disabled="selectedId === null" @click="emit('delete')">
  <template #icon><icon-ic-round-delete class="text-icon" /></template>
  {{ $t('common.delete') }}
</NButton>
```

效果：三个按钮统一 `ghost`（带边框）+ 统一图标（`plus` / `edit` / `delete`），同一工具栏内视觉层级一致；「编辑/删除」仍按 `selectedId === null` 置灰禁用。

> 图标来源：`unplugin-icons` + 全量数据集 `@iconify/json` 解析 `ic:round-*`；`ic:round-edit` 与已用的 `ic:round-delete`/`round-plus`/`round-search`/`round-refresh` 同属一个 Material Icons round 数据集，必然存在，不会编译失败。

## 影响范围

`MasterDetail.vue` 被 6 个设置 tab 复用，操作栏按钮样式会同步统一。

## 验证

- 改的是 `NButton` 的 `type`，无类型风险；
- IDE 提示 `--menu-hover-bg` / `--menu-primary` 无法解析属正常现象（scoped 样式引用运行时 `:style` 注入的 CSS 变量），非本次改动引入。
