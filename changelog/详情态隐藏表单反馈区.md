# 详情态隐藏表单反馈区

## 需求

用户："查看详情的时候，显示错误信息的那个地方能不能隐藏？"

所指 = 每个 `NFormItem` 底部的**反馈区**（`.n-form-item-feedback-wrapper`）：正常时是一段空白占位、校验失败时显示红字错误信息。

## 核查（naive 源码）

- `FormItem.mjs` 第 460 行：`this.mergedShowFeedback ? h('div', { class: '...-form-item-feedback-wrapper' }, ...) : null` —— `show-feedback=false` 时整块**不渲染**。
- `form-item.cssr.mjs` 第 104-107 行：wrapper 有 `min-height: var(--n-feedback-height)` —— 所以**没有错误时也占一行高度**。
- `utils.mjs` 第 95-102 行：`mergedShowFeedback = props.showFeedback ?? NForm.props.showFeedback ?? true` —— NFormItem 级传值优先。
- 项目先例：`views/system-manage/label-designer/modules/panels/property-panel.vue` 已有 `:show-feedback="false"`。

## 澄清确认

- **仅 view 态隐藏**（用户选推荐方案）：详情态本来就不校验（`mergedRules` 返回 `{}`），反馈区永远是空白，隐藏零副作用，表单每行少一条约 20~24px 空白。
- 编辑态**一字不动**：错误红字需要位置显示；若编辑态也隐藏，错误出现时会导致行高跳动。

## 改动文件

- `src/components/Form/index.vue`：模板 `NFormItem` 加 `:show-feedback="!isView"`（附注释说明 view 态无反馈、编辑态保留）。

## 验证

- `pnpm typecheck` 通过（0 错误）；
- oxfmt / oxlint / eslint 对 `src/components/Form/index.vue` 均 0 warning、0 error；
- 无浏览器端到端；预期表现 = 详情抽屉每行下方空白消失、编辑态与之前完全一致。

## 追加调整：view 态行距 +10px

隐藏反馈区后详情表单偏紧凑，用户："有点太紧凑了，能不能加10px"。

- 采用方案（用户选）：**行与行之间 10px** —— `NGrid` 加 `:y-gap="isView ? 10 : 0"`。naive `Grid.mjs` 第 119-120 行 `rowGap: pxfy(responsiveYGapRef.value)`，即标准 CSS `row-gap`，只在行间生效、**末行下方不会多出空白**。
- 未采用备选：保留 feedback 占位但压到 `min-height: 10px` —— 末行下方也会多 10px。
- 编辑态 `y-gap` 仍为 0：其行距由 feedback 区（约 20~24px）提供。

改动文件：`src/components/Form/index.vue`（`NGrid` 加 `:y-gap`）。

验证：`pnpm typecheck` 通过；oxfmt / oxlint / eslint 对改动文件 0 warning、0 error。
