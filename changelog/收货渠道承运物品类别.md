# 收货渠道「承运物品类别」入新增/编辑抽屉

> 日期：2026-09-20 ｜ 状态：已实施（待手动冒烟）
> 页面：渠道报价 / 收货渠道（`src/views/channel-quote/receive/modules/channel-operate-drawer.vue`）
> spec：`docs/superpowers/specs/2026-09-20-收货渠道承运物品类别-design.md`（✅ 已确认）

## 1. 需求（用户截图 + 原话）

- 截图：老系统「承运物品类别（勾选就保存）」tab —— 一行复选框（家具 / 家居用品 / 办公文具 / 家用电器(无电) / 家用电器(含电) / 包装食品 / 数码产品(无电) / 数码产品(含电) / 服装(无品牌) / 服装(有品牌)）。
- 原话：**「把这个放到新增弹窗内填写」** ⇒ 放到本仓库收货渠道的**新增/编辑抽屉**里，随表单保存（不复刻「勾选即存」）。

## 2. 契约（已核）

| 事项     | 事实                                                                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 渠道字段 | `Channel.productGroupIds: [String]`（`tms-user/lib/common/models/channel.js`），`/channel/query`、`/channel/get` 均返回，`create/update` 可写 —— **无需改后端**                              |
| 选项来源 | 物品类别 `ProductGroup`（`/product-group/query`）；前端**已有** `fetchGetProductGroupList`（`service/api/data-manage-archive`）与类型 `Api.DataManage.BusinessGoodsCategory`，未新增服务     |
| 选项过滤 | 该接口不强制 `status=1` ⇒ 取全部类别，与物品类别管理页口径一致，避免历史值是停用类别时「不可见却仍提交」                                                                                     |
| 组件能力 | `FormWrap` 的 `type: 'checkbox'`（`NCheckboxGroup` + `NSpace`，`wrap` 默认 true 自动换行）在仓库内**此前 0 处使用**，本次首用；详情态由 `viewText` 的 checkbox 分支按选项 label 以「、」拼接 |

## 3. 决策（用户确认）

| #             | 结论                                                                                                                               |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Q1 字段位置   | ✅ **塞进「基本信息」区块末行**（用户明确指定）：`span: 24` 复选框组，紧随「渠道标签」之后、渠道备注分区之前，**不加独立分区标题** |
| Q2 选项范围   | 按推荐：取**全部**物品类别（不传 `status`）                                                                                        |
| Q3 保存时机   | 按推荐：**随表单提交**（新增/编辑一次保存）                                                                                        |
| Q4 字段 label | 按推荐：「承运物品类别」（不带「勾选就保存」后缀，因为我们不是即时保存）                                                           |

> 用户以「开始吧」（＝开始实现）确认 spec；Q2–Q4 未另答 ⇒ 按推荐执行。

## 4. 实施

- **类型**（`typings/api/channel-quote/index.d.ts`）：`ReceiveChannel` 与 `ReceiveChannelSaveParams` 各增 `productGroupIds?: string[]`（注释指向后端 `Channel.productGroupIds`）。
- **抽屉**（`channel-operate-drawer.vue`）：
  - 新增 `productGroupOptions`，并入既有 `loadOptions()` 的并行请求（`fetchGetProductGroupList({ current: 1, size: 500 })`，不传 status），失败静默保留空列表；
  - `emptyModel()` 用 `[]`、`fillModel()` 用 `row.productGroupIds ?? []`；
  - `formItems` 在「渠道标签」后追加 `type: 'checkbox'` 项（`span: 24`，label 走 i18n）；
  - `buildPayload()` 与 `siteIds` 同口径 —— **始终提交数组**（空数组＝清空），不受「空值不传」约束。
- **i18n**：`page.channelQuote.receive.form.productGroup` = 「承运物品类别」/「Goods Category」（zh-cn / en-us / `typings/app.d.ts` 三处同步）。

## 5. 边界

- 不改列表列（不加「承运物品类别」列）、不改物品类别管理页、不改后端、不新增服务层；
- 不动抽屉其它字段与既有联动（转单号规则 → 发货渠道）；
- 不改 `FormWrap` 组件本体（若冒烟发现复选框换行/间距不合适，另开 spec）。
