# 导出字段弹窗升级为「可新增字段」的编辑表格

## 背景

原 `src/components/Export/field-select-dialog.vue` 是「NCheckbox + VueDraggable 列表」，只能勾选/排序，无法调整导出列名，也无法追加表格里没有的列。业务侧需要在导出时临时加列（例如给每份 Excel 加一列固定的「导出批次」「制单人」）。

## 结论

把弹窗改为**可编辑表格**（vxe-table + sortablejs 行拖拽），支持：勾选导出、编辑导出列名、拖拽排序、新增自定义字段（取数据 / 固定值）、删除自定义字段。

### 交互与列定义

弹窗尺寸 `760 × 520`，顶部工具条 + 主体表格 + 底部按钮：

| 列                  | 说明                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------- |
| 拖拽（56）          | 仅图标为 handle，整行可拖；`onEnd` 只记录索引，确认时应用到数据（避免拖拽中表格重绘跳动） |
| 导出（70）          | 行内 NCheckbox；表头 NCheckbox 全选（含半选态）                                           |
| 字段名称（min 160） | NInput 可编辑，即 Excel 表头；留空回退为 key                                              |
| 数据字段（min 160） | 自定义字段「取数据」时编辑 key、「固定值」时编辑固定值；普通字段只读展示 key              |
| 取值方式（120）     | 自定义字段 NSelect（取数据 / 固定值）；普通字段只读显示「取数据」                         |
| 操作（70）          | 仅自定义字段显示「删除」                                                                  |

顶部「新增字段」按钮追加一行自定义字段，列名为「自定义字段 N」；**默认 `valueMode='field'`（取数据，key 留空待用户填字段名）**，可切换为「固定值」。

### 数据结构

- `components/Export/type.ts`：`ExportField` 新增 `valueMode?: 'field' | 'fixed'`、`fixedValue?: string`；新增导出类型 `ExportValueMode`。
- 弹窗内部行 `FieldItem extends ExportField`：`id`（稳定行标识，自定义字段的 `key` 可被用户编辑）、`checked`、`custom`、`valueMode`、`fixedValue`。

### 导出链路

- `confirm` 仍回传勾选且排序后的 `ExportField[]`：普通字段保留 `sourceType/activeValue/formatter`；自定义字段按模式输出 `key+valueMode:'field'` 或 `valueMode:'fixed'+fixedValue`。
- `components/Export/export-xlsx.ts` 的 `resolveCellText` 优先级调整为：**固定值 > formatter > status 文案 > 原值**。

### 复用与依赖

- 行拖拽沿用 `components/Table/table-column-config.vue` 的做法：`Sortable.create(tbody)` + `startSortablePolling`（弹窗首次打开行渲染异步）+ `@after-render` 兜底。
- 弹窗内直接使用全局注册的 `vxe-table/vxe-column`，不经通用 `Table` 组件，避免 `Table → Export → dialog → Table` 的循环引用。

### i18n

`common` 新增 10 个 key：`addField / customField / fieldName / fieldNamePlaceholder / dataField / dataFieldPlaceholder / valueMode / valueModeField / valueModeFixed / fixedValuePlaceholder`，同步 `zh-cn.ts`、`en-us.ts` 与 `src/typings/app.d.ts` 的 `App.I18n.Schema`。

## 影响范围
