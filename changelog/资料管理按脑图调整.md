# 资料管理结构调整（对齐脑图）

## 需求

用户提供三张脑图，要求资料管理按此结构实现：

- **运单资料**：申报物品、地址簿（收件人 / 发件人）、问题类别、物品类别、报关类型、出口原因、清关方式、销售条款
- **财务资料**：费用类型（运单应收 / 运单应付 / 提单应付）、银行账户、结算方式、结算货币
- **提单资料**：航线、港口、航名/航次、地址簿（买方公司-BY / 送达方-ST / 收货人-CN / 卖方公司-SE / 生产商-MF / 进口商-IM / 订舱人-BKP / 拼箱人-CS / 装柜地址-LG）、柜型、轨迹配置
- **通用资料**：国家地区、FBA仓库
- **发货资料**：服务商（发货服务商 / 派送服务商 / 提单服务商）、渠道类别、计泡规则（按公斤 / 按方）、承运网络
- **单号资料**：单号规则、子单号规则、运单号码池、长单号截短
