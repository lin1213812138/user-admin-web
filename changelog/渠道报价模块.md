# 渠道报价模块（收货渠道 / 发货渠道）

## 背景

用户要求新增「渠道报价」模块，包含「收货渠道」和「发货渠道」两个页面。

## 设计确认

1. **结构**：两个独立一级路由页面，各自独立、互不切换；不套用 `MasterDataArchive` 通用归档组件。
2. **归属**：新建独立一级模块 `channel-quote`，与 `data-manage` 平级。
3. **字段**：先用通用骨架（渠道编码 code / 渠道名称 name / 状态 status / 备注 remark），业务字段（报价、币种、重量段等）后续补充。

## 实现

- `views/channel-quote/receive/index.vue`：收货渠道列表页（自包含）。
- `views/channel-quote/ship/index.vue`：发货渠道列表页（自包含）。
  两个页面均直接用 `Table` + `useVxeTable` + `Drawer` + `NFormWrap` 实现增删改查 + 列设置持久化，逻辑各自独立、不共享 MasterDataArchive。
- `typings/api/channel-quote.d.ts`：`Api.ChannelQuote` 命名空间（ChannelQuoteRow / ChannelQuoteArchiveKey=`receive|ship` / ReceiveChannel / ShipChannel / ChannelQuoteList / ChannelQuoteSearchParams）。
- `service/api/channel-quote.ts`：`fetchGet/Create/Update/DeleteChannelQuote`，按 archive key 区分，DEV 走 mock、PROD 走 `/channel-quote/:archive/xxx`。
- `service/api/mock-channel-quote.ts`：按 archive key 的 factory 造数 + 4 个 mock 函数。
- i18n：`zh-cn.ts` / `en-us.ts` 的 `route`（channel-quote / channel-quote_receive / channel-quote_ship）与 `page.channelQuote.{common,receive,ship}`；`typings/app.d.ts` 的 `Schema.page` 增加 `channelQuote`。
- 路由：`pnpm dev` 触发 elegant-router 自动生成 `channel-quote` 父级 + 两子路由及菜单（不手改 `src/router/elegant/**`）。
