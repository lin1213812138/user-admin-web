# 分配权限回显失败

## 现象

角色管理 → 分配权限：给角色保存过权限后，重新打开抽屉，除「首页」外所有菜单勾选、按钮权限、子模块权限全部不回显。

## 定位

`src/views/system-manage/role/modules/role-permission-drawer.vue` 的 `loadData()` 回显遍历用了 `rows.some(...)`：

```ts
function walk(rows: MenuPermissionRow[]): boolean {
  return rows.some(row => {
    let matched = authSet.has(String(row.id));
    ...
    return matched;
  });
}
```

`Array.some` 在回调首次返回 truthy 时立即短路终止遍历。顶层第一行是「首页」（id=100），提交时 `withHome()` 强制把首页 id 写入 `auths`，因此回显时第一行必然命中 → `some` 立即返回 → 后续「客户管理 / 渠道报价 / 资料管理 / 系统管理 / 权限管理」整棵子树（含按钮、子模块码）不再被遍历，勾选全部丢失。

已排除其它环节：

- 后端 `/role/query`（`queryAllCommon`）不传 `fields`，Role 模型无 `omitFields`、`basicFields` 未定义 → `find(filters, undefined)` 返回全字段，含 `auths`；
- 前端类型 `Api.SystemManage.Role.auths?: string[]` 正常；
- 提交逻辑 `handleSubmit`（三套状态合并扁平 auths）无问题。

## 修复（用户确认）

`walk` 中 `some` 改为不短路的 `forEach` + 局部命中标记 `anyMatched`，保持「父级随子级命中而勾选」的传播语义不变；按钮 / 子模块码回显原逻辑不动。仅改这一个函数（约 5 行），不动模板、提交逻辑与其它文件。

## 验证

- `pnpm typecheck` 通过；
- 手动验证路径：给角色勾选若干菜单 + 按钮 + 子模块 → 保存 → 重新打开抽屉，所有勾选完整回显。
