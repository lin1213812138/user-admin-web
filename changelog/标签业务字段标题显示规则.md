# 标签设计：业务字段标题显示规则（label 不上画布 + showTitle 显式配置）

> 日期：2026-09-12

## 需求

用户在 `BUSINESS_FIELDS` 新增 `orderNoCode`（条形码字段，`title: ''`）后拖入画布，条形码上出现标题「单号（条形码）」。要求：

1. 「这个只是名称，不需要显示，显示的只能是标题，label 不要显示」——label 仅为左侧列表显示名，画布上显示的只能是「标题名称」配置值；
2. 「加个是否显示标题的属性，不要所有的强制默认」——字段级显式配置是否带标题，而不是 title 有值就强制开启；
3. 规则补充：「没有 title 不管 showTitle 是否是 true 都不显示」。

## 问题定位（两处叠加）

- `field-panel.vue` 拖拽 payload：`title: f.title || f.label`——title 未配置时**拿 label 顶上**；
- `store/modules/label-design/index.ts` `defaultOptionsFor`（text/longText、barcode、qrcode 三个分支）：`showTitle: Boolean(seed.title)`——title 有值就**强制**开关联标题。

## 方案（用户确认）

- `FieldDef` / `ElementSeed` / 拖拽 payload / `DropPayload` 全链路新增 `showTitle?: boolean`；
- `field-panel.vue`：`title: f.title`（**删除 label 回退**），payload 带 `showTitle`；
- `defaultOptionsFor` 三分支统一：`showTitle: Boolean(seed.showTitle && seed.title)`——**showTitle 与 title 同时为真才开启**，缺省全部不显示标题；是否显示与标题内容解耦；
- 拖入后属性面板「关联标题」开关仍可随时手动配置（既有能力不变）；
- `BUSINESS_FIELDS` 现有字段均未配 `showTitle` → 默认全部不带标题；需要哪个字段默认带标题（如商品名称），给它显式加 `showTitle: true`。

## 验证

- `pnpm typecheck` 通过；label-designer 目录与 label-design store lint 0 错误。
