# 标签设计左侧面板改用组件库滚动条

> 自研标签设计器（`label-designer`，非 hiprint 的 `print-design`）。
> 需求直接、且仓库内已有同款先例（同页右侧面板 + 姊妹页 `print-design` 左侧面板），故未另开设计确认轮次，直接实施并记录。

## 需求

「不要使用系统滚动条，使用组件库的滚动条」——指左侧字段面板（上一步把基础元素改成单列后内容变高，露出了系统滚动条）。

## 现状核查（先确认范围）

`label-designer` 目录内逐个滚动容器过一遍：

| 位置                                          | 原实现                                                                    | 结论                           |
| --------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------ |
| 左侧 `field-panel.vue`                        | `class="h-full overflow-auto p-12px"`                                     | **唯一的系统滚动条**，本次要改 |
| 右侧 `property-panel.vue`                     | 早已是 `<NScrollbar class="flex-1 overflow-hidden">`                      | 无需改（页面内既有惯例）       |
| 画布 `design-canvas.vue`                      | 视口 `overflow-hidden`                                                    | 无滚动条                       |
| 预览 `preview-modal.vue`                      | `overflow-y: auto` + `scrollbar-width: none` + `::-webkit-scrollbar` 隐藏 | 刻意隐藏，视觉上无系统滚动条   |
| 姊妹页 `print-design/modules/field-panel.vue` | `<NScrollbar class="min-h-0 flex-1">`                                     | 同款先例                       |

## 改动

`modules/field-panel.vue`（仅模板）：

- 根节点由 `div.h-full.overflow-auto.p-12px` 换成 `<NScrollbar class="h-full">`，内层再加 `<div class="p-12px">` 承担内边距。
  **padding 放内部 wrapper 而非滚动容器本身**，这样滚动条贴容器右边缘、内容与滚动条之间不留 12px 空隙——与右侧 `property-panel.vue` 的写法一致。
- 其余内容（NCollapse 两组、条目类名、`draggable` / `@dragstart` / `startDragGhost`）**零改动**。

设计要点：naive `NScrollbar` 的内部容器仍是**原生滚动容器**（`overflow-y: scroll`），只是用 CSS 把系统滚动条隐藏（`scrollbar-width: none`），因此滚轮、触控、以及 HTML5 拖拽到面板边缘时的**自动滚动**行为全部保持原生，仅视觉层换成组件库滚动条。

## 验证（Playwright + 系统 Chrome + 本机后端）

`scripts/panel-shot.cjs`（临时脚本）实测：

```
全页 .n-scrollbar 数量 = 1，其父级 = "w-260px shrink-0 overflow-hidden border-r …"（即左侧面板容器）
.n-scrollbar-container:  overflow-y = scroll，scrollbar-width = none   ← 系统滚动条已隐藏
                          clientHeight = 799，scrollHeight = 843         ← 确实可滚
hover 面板后：            .n-scrollbar-rail opacity = 1（滑块出现）
                          rail.right = 475，面板右缘 = 480              ← 滚动条贴右边缘
                          滑块 top = 153 / height = 761（≈ 可见比例，符合 843/799）
首条拖拽项文本 = "单号orderNo"（面板内容完整）
```

截图核对：面板右侧为 naive 的浅色轨道 + 灰色圆角滑块，无系统滚动条。左下角那个小三角经 `elementFromPoint` 确认为 **Vue DevTools 的悬浮按钮**（`vue-devtools__anchor-btn`），与本次改动无关。

- `vue-tsc --noEmit --skipLibCheck`：仅剩 `packages/scripts` 的 rimraf 既有错误。
- `oxlint`：该目录 0 warnings / 0 errors。

## 备注

- `index.vue` 里左侧面板宽度已被调整为 `w-260px`（用户自行改动，本次未触碰该文件）。
- 若后续希望滚动条常显而非 hover 触发，可给 `NScrollbar` 加 `trigger="none"`，本次保持 naive 默认（与右侧面板一致）。
