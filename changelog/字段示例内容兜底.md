# 标签设计器：字段示例内容兜底（sample 为空时回退）

> 用户反馈（截图红框圈出「日期 date」，该字段 `sample` 被改成空）：「我把这个改成空内容，拖出来也是空的」

## 现状

业务字段拖入 / 拖拽预览的示例内容取 `FieldDef.sample`。`design-canvas.vue` 的 `onDrop` 虽有 `payload.sample ?? payload.field` 兜底，但 `??` 只认 `null / undefined`，**空字符串兜不住** → sample 清空后拖出即空白。

## 改动

`core/constant.ts` 新增 `fieldSampleOf(f: FieldDef)` 作为字段示例的统一兜底；`field-panel.vue` 的**拖拽预览构建**（`onEntryPointerDown`）与 **dragstart payload** 两处共用（预览与落纸同源原则）：

| 场景                                  | 回退                                                        |
| ------------------------------------- | ----------------------------------------------------------- |
| 文本 / 长文本 / 二维码（sample 为空） | `title` → `label` → `key`（字段中文名优先）                 |
| 条码（sample 为空）                   | `key` —— Code128 编码不支持中文，回退中文名会让条码渲染失败 |
| sample 非空                           | 原值                                                        |

## 验证

- `npx oxfmt` / `npx oxlint --fix` / `npx eslint --fix` 单文件：0 error；`pnpm typecheck`：0 error。
- `tsx` 实测（临时脚本已删）：`date`（sample 空）→「日期」；`orderNoCode`（条码 + sample 空）→「orderNoCode」；`qty`（sample 非空）→「100」。

## 已撤销（用户要求）

用户报告「点击元素直接卡死」后要求「撤销这个之后的改动」，本批兜底改动已全部回退：

- `constant.ts`：删除 `fieldSampleOf()` 函数（含注释）；
- `field-panel.vue`：预览构建（`onEntryPointerDown`）与 dragstart payload 恢复 `sample: f.sample`，移除函数引入；
- `design-canvas.vue`：`onDrop` 恢复 `sample: payload.sample ?? payload.field`。

**保留**：基础元素（文本 / 长文本 / 图片）的默认示例值（`basic-elements.ts`）—— 用户诉求正是这三个拖出有内容。

说明：本批被撤销的改动均为纯数据 / 纯函数逻辑，静态分析层面不可能引起「点击卡死」；卡死问题与本次撤销无因果关联，仍在排查（疑似 HMR / Pinia 热更新状态错乱，建议完全重启 dev）。
