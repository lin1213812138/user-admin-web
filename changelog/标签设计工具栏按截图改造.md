# 标签设计工具栏按截图改造（返回上一页/垂直对齐/清空）

## 需求

用户给出目标截图（`← 返回上一页 | 标准内单标签 | 100×150mm | — 100% + | 显示网格 | 垂直对齐 …… 清空 预览 保存`），要求照做。

## 决策（用户确认）

1. **撤销/重做保留**：截图只是样式参考，编辑器核心能力不删。
2. **垂直对齐 = 所有元素整体垂直居中**：不依赖选中，一键把画布上全部元素作为整体在纸张内垂直居中（上下留白相等）。
3. **清空需二次确认**：dialog 确认后清空画布全部元素，可撤销兜底。

## 改动

- `src/store/modules/label-design/index.ts`
  - 新增 `clearAll()`：入撤销栈后清空 elements、清选中。
  - 新增 `verticalCenterAll()`：按 `minTop/maxBottom` 求整体包围盒，对纸张高（`parsePaper().h`，mm 单位与元素坐标同源）求偏移，整体平移；已居中（偏移 <0.01mm）不产生撤销点。
- `src/views/system-manage/label-designer/modules/tool-bar.vue`：按截图重排单行
  - 新增「返回上一页」（quaternary + 返回箭头图标，`router.back()`）。
  - 缩放由 `NButtonGroup` 连体改为独立三元素 `— 100% +`（quaternary 图标按钮 + text 百分比，点击百分比重置 100% 不变）。
  - 「网格」文案改「显示网格」（i18n `grid` 改值）；新增「垂直对齐」按钮（无元素禁用）。
  - 右侧新增「清空」（quaternary，`window.$dialog?.warning` 二次确认，惯例同 print-design）；「预览」由 primary 改白底描边 default，保存保持 primary + loading。
- i18n（zh-cn / en-us / `typings/app.d.ts` 三处同步）：新增 `back` / `verticalCenter` / `clear` / `clearConfirm`；`grid` 文案改「显示网格 / Show Grid」。

## 备注

- 元素坐标单位为 mm，与 `parsePaper` 返回值同单位，偏移直接加在 `y` 上，无需 px 换算。
