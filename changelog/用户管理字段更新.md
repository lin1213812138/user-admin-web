## 追加修复：点「新增」打不开弹窗（同日）

**用户反馈**："点新增打不开弹窗"，并附浏览器控制台报错：

```
RangeError: Invalid time value
    at format$3 (naive-ui)
    at deriveSingleInputState (naive-ui)   ← NDatePicker setup
    at setup
（后续 unmountComponent / nextSibling 报错为组件树损坏的连锁反应）
```

**根因**：`NDatePicker` 的 `formatted-value` 只接受 `string | null`；我的实现用 `v-model:formatted-value="model[item.key] as string"` 把 model 里的**空字符串 `''`** 直接传入（新增时 `hireDate`/`birthday` 初值为 `''`），naive 内部 `parseDate('')` → Invalid Date → `format()` 抛 `RangeError: Invalid time value` → **setup 阶段抛错使抽屉子树渲染中断 → 弹窗打不开**。

**修复**（`src/components/Form/index.vue`）：

- 新增 `dateValue(key)`：model 中的空串转 `null` 传给 `:formatted-value`；
- 新增 `handleDateChange(key, value)`：`@update:formatted-value` 把 `null` 写回空串（与其它文本字段的空值口径一致），按 FormWrap 契约写回 model 并局部 `eslint-disable vue/no-mutating-props`。

**验证**：`pnpm typecheck` 0 / eslint 0 / oxlint 0 / `pnpm fmt` 已跑。用户侧需刷新页面（若组件树已损坏建议硬刷新或重启 dev）。

**教训**：给 naive 受控组件传值前必须做「空值口径转换」——文本字段的 `''` 不等于组件的 `null`（与既有「naive 输入类组件 value===undefined 走非受控分支」属同类坑）。

## 追加修复：必填 validator 的 IDE 类型报错（同日）

**用户反馈**（IDE ts-plugin）：

```
不能将类型“(_rule: FormItemRule, value: any, callback: (error?: string | Error | undefined) => void) => void”
分配给类型“FormItemRuleValidator”。
  不能将类型“void”分配给类型“boolean | Error | Promise<void> | Error[] | undefined”。 ts-plugin(2322)
```

**根因**：`FormWrap` 的 `mergedRules` 用 callback 风格写 `validator`（`callback(new Error(msg))` / `callback()`），函数隐式返回 `void`；naive 的 `FormItemRuleValidator` 返回类型为 `boolean | Error | Promise<void> | Error[] | undefined`（**不含 void**）→ 类型不兼容。（`pnpm typecheck` 带 `--skipLibCheck` 未报此错，IDE 的 TS 服务报出。）

**修复**（`src/components/Form/index.vue`）：改为

```ts
validator: (_rule, value) => (empty ? new Error(message) : undefined);
```

——直接返回 `Error | undefined` 的标准写法（async-validator 支持），保留原有「自定义空值检查」语义与 `required: true` 的必填红星。

**验证**：`pnpm typecheck`（skipLibCheck）0 / `npx vue-tsc --noEmit`（严格口径）Form 组件 0 报错 / eslint 0 / oxlint 0 / `pnpm fmt` 已跑；全项目 grep 无其它 callback 风格 validator。

**经验**：遇到「IDE 报类型错但 `pnpm typecheck` 不报」时，用 `npx vue-tsc --noEmit`（不带 `--skipLibCheck`）复验。
