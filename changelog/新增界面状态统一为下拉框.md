# 新增/编辑界面「状态」统一由 switch 改为下拉框

> 日期：2026-09-20 ｜ 状态：已实施 ｜ 范围：`src/views` 下所有新增/编辑表单

## 1. 诉求

用户要求排查所有「新增/编辑」界面里仍用 `switch` 表示「状态」的表单项，统一改成下拉框。

## 2. 审计结果

全仓 `type: 'switch'` 共出现在 11 个文件；其中语义为「状态」的 **7 处**：

| 文件                                                                   | 资源       |
| ---------------------------------------------------------------------- | ---------- |
| `data-manage/no-rule/modules/item-no-rule/ItemNoRuleOperateDrawer.vue` | 子单号规则 |
| `data-manage/no-rule/modules/long-no-rule/LongNoRuleOperateDrawer.vue` | 长单号截短 |
| `data-manage/bl/modules/bl-unit/BlUnitOperateDrawer.vue`               | 提单单元   |
| `data-manage/bl/modules/bl-trip/BlTripOperateDrawer.vue`               | 航程       |
| `data-manage/bl/modules/bl-port/BlPortOperateDrawer.vue`               | 港口       |
| `data-manage/bl/modules/track-config/TrackConfigOperateDrawer.vue`     | 轨迹配置   |
| `channel-quote/ship/index.vue`                                         | 发货渠道   |

7 处代码完全一致，且各自表单的 `emptyForm()` / `openDrawer()` 均默认 `status: 1`，改成下拉不会出现空选。

其余 **4 处** switch 属真正的布尔开关（非「状态」语义），**予以保留**：

- `system-manage/setting/modules/trace-capture/track-keyword/TraceKeywordDrawer.vue`（是否常用）
- `system-manage/setting/modules/print-format/form-items.ts`（是否默认）
- `system-manage/setting/modules/input-format/fields-config.ts`（是否投保 / 粉末 / 液体 / 带电 / 带磁）
- `system-manage/label-designer/modules/panels/property-panel.vue`（显示标题 / 显示编码值 / 显示边框）

## 3. 改动

7 处统一替换为（与既有 `data-manage/ship/modules/provider/ProviderOperateDrawer.vue` 的写法一致）：

```ts
{
  key: 'status',
  label: $t('common.status'),
  type: 'select',
  span: 24,
  optionsKey: 'status',
  filterable: false
}
```

要点：

- 去掉 switch 专用属性 `checkedValue` / `uncheckedValue` / `checkedText` / `uncheckedText`。
- 选项走全局选项注册表 `status`（启用 1 / 禁用 0，`src/constants/options.ts`），**不使用**本地非响应式的 `statusOptions`，以支持语言切换与统一维护。
- `span` 保持原值 24，仅改控件类型，不动布局。

- `pnpm fmt` ✅
