# 标签设计器：左右两侧面板背景改白

日期：2026-09-14
范围：`src/views/system-manage/label-designer/index.vue`

## 背景

用户反馈：「左右两侧的背景能不能做成白色的」。

现状：标签设计器中间画布区自带底色，左右两个侧栏容器（左 260px 字段面板 / 右 300px 属性面板）
**没有设置背景**，透出的是页面 layout 底色 `rgb(247, 250, 252)`（近白偏灰），视觉上两侧发灰。

## 决策

用主题 token 类 `bg-container` 而不是硬编码 `bg-white`：

- `bg-container` → `rgb(var(--container-bg-color))`：浅色主题下即纯白 `rgb(255, 255, 255)`（`theme/settings.ts` 的 `tokens.light`），
  暗黑主题自动切到 `rgb(28, 28, 28)`，无需额外 `dark:` 变体；
- 项目已有先例：`components/common/dark-mode-container.vue` 用的就是 `bg-container`；
- 面板内已有元素无需改动：字段条目自带 `bg-white dark:bg-#1f1f1f`、属性卡是白底描边卡，白底容器上仍可区分。

## 改动

`index.vue` 左右两个侧栏容器各加一个类：

```diff
- <div class="w-260px shrink-0 overflow-hidden border-r border-#e5e7eb dark:border-#2a2a2a">
+ <div class="w-260px shrink-0 overflow-hidden border-r border-#e5e7eb bg-container dark:border-#2a2a2a">

- <div class="w-300px shrink-0 overflow-hidden border-l border-#e5e7eb dark:border-#2a2a2a">
+ <div class="w-300px shrink-0 overflow-hidden border-l border-#e5e7eb bg-container dark:border-#2a2a2a">
```

分隔线（`border-r` / `border-l`）保持不变；中间画布区不动。
