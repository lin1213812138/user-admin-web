# 导出模板上传控件：图标垂直对齐 + 去掉复制图标

- 日期：2026-09-17
- 涉及文件：`src/views/system-manage/setting/modules/export-format/ExportTemplateUpload.vue`、`ExportFormat.vue`、i18n 三处

## 一、需求

1. 用户贴控件截图：「这个组件的图标没有垂直对齐」
2. 提出修复方案后用户明确：「**必须用这个组件**」⇒ 保留 naive `NUpload`，不改成自管隐藏 `<input type="file">`
3. 追加：「**复制图标去掉只要上传图标就可以了**」

## 二、图标不齐定位（playwright 实测数据，未改代码先定位）

| 元素                                                                        | 垂直中心 y       | display     |
| --------------------------------------------------------------------------- | ---------------- | ----------- |
| `.n-input__suffix`（容器，flex + `align-items:center`，`line-height:34px`） | 278              | flex        |
| 复制按钮（外层 `div.flex.items-center` 的直接 flex item）                   | 278 ✓            | flex        |
| 上传按钮（被 `NUpload` 包裹）                                               | **274** ✗ 高 4px | inline-flex |
| svg（复制 / 上传）                                                          | 278 / **274**    | block       |

**根因**：`NUpload` 会多渲染 `.n-upload` → `.n-upload-trigger` 两层包裹，后者是 `inline-block` 且 `line-height: 34px`（继承输入框高度）；内层 `inline-flex` 按钮在行盒里按**基线**落位、不是居中，因此比复制按钮高 4px。图标本身没问题。

## 三、修复（方案 A，用户确认保留 NUpload）

组件内加 scoped 样式（仅作用于本组件，不碰公共组件 / FormWrap）：

```css
:deep(.n-upload),
:deep(.n-upload-trigger) {
  display: flex;
  align-items: center;
}
```

## 四、去掉复制图标

- 模板只保留 `<NInput readonly>` + 上传图标按钮；删除 `handleCopy` 函数与 `copyText` import
- 组件不再消费 `fileUrl` ⇒ 去掉 `fileUrl` prop（否则 eslint 报 `vue/no-unused-properties` 告警）；上传结果仍通过 `update:fileUrl` 事件回传，`ExportFormat.vue` 改绑 `@update:file-url="formModel.fileUrl = $event"`
- i18n 三处（zh-cn / en-us / app.d.ts）删除随之无用的 `copyUrlEmpty`

## 六、备忘

- naive `NUpload` 的 `.n-upload-trigger` 是 `inline-block`，把它放进 flex 容器（如 `NInput` 的 `#suffix`）时内部按钮会按基线落位；需要显式把包裹层改为 flex 居中，否则与同级按钮/图标差 4px。
- 组件若只负责「回传值」而不消费某个字段，就不要声明该 prop（用 `update:xxx` 事件即可），否则 eslint `vue/no-unused-properties` 会告警。
