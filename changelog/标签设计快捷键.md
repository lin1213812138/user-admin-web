# 标签设计快捷键 + 帮助弹窗

## 需求

用户提供目标截图（编辑器快捷键对照面板），要求加快捷键。

## 决策（用户确认）

1. **帮助弹窗一起做**：工具栏加「快捷键」按钮（键盘图标 + tooltip），点开 NPopover 展示 Windows / Mac 两列对照（截图样式，跟随主题配色）。
2. **方向键步长 1 / 10 / 0.1mm**：方向键 1mm、Shift+方向键 10mm（快速移动）、Alt+方向键 0.1mm（微调），支持长按连发。

## 改动

### 快捷键行为（`index.vue` 页面级 keydown/keyup）

| 快捷键                                | 行为                                                                   |
| ------------------------------------- | ---------------------------------------------------------------------- |
| Ctrl/Meta + S                         | 保存（`preventDefault` 拦浏览器保存对话框）                            |
| Ctrl/Meta + Z                         | 撤销                                                                   |
| Ctrl/Meta + Y / Ctrl/Meta + Shift + Z | 重做                                                                   |
| Ctrl/Meta + X                         | 剪切选中元素（新 store 方法 `cutElement` = 复制 + 删除，删除入撤销栈） |
| Ctrl/Meta + C                         | 复制选中元素                                                           |
| Ctrl/Meta + V                         | 粘贴                                                                   |
| Delete / Backspace                    | 删除选中元素                                                           |
| 方向键（±Shift/Alt）                  | 移动选中元素 1 / 10 / 0.1mm                                            |

实现要点：

- **输入守卫**：焦点在 `input/textarea/select/contentEditable` 时跳过所有快捷键，不影响表单打字。
- **方向键长按会话**：首个 keydown `store.snapshot()` 入一次撤销栈并开启会话，keyup（Arrow 键）结束；连发不再产生碎撤销点。
- **边界钳制**：平移结果 clamp 在 `[0, 纸张尺寸 - 元素尺寸]`（`parsePaper`，mm 同单位）。
- 监听挂 `window`，`onMounted` 绑定 / `onBeforeUnmount` 解绑；无选中元素时方向键/删除/剪切/复制不动作（Ctrl+V 不依赖选中）。

### 帮助弹窗（新组件 `modules/shortcut-help.vue`）

- `NPopover trigger="click"` + `NTooltip` 包 quaternary 键盘图标按钮；**追代（同日）：按钮从右侧区「清空」前移到缩放组「+」号之后（用户截图标注），右侧区只留 清空/预览/保存**。
- 内容 `grid grid-cols-2`：Windows / Mac 两列卡片（`bg-#f3f3f5 dark:bg-#2a2a2a`），行 = 标签（i18n）+ 键位（符号常量）。
- 行数据：保存/撤销/重做复用现有 `save/undo/redo` 键；新增 `shortcut` `shortcutWindows` `shortcutMac` `shortcutCopyPaste` `shortcutMove` `shortcutQuickMove` `shortcutNudge` `shortcutDelete` `shortcutArrows`（zh-cn / en-us / `app.d.ts` 三处同步）。
