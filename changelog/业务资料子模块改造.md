# 业务资料子模块改造

## 用户需求

将「业务资料」（`data-manage_business`，页面内左侧 `ArchiveSwitch` 子导航）的 4 个子模块（仓库 / 库位 / 承运商 / 门店）**完全替换**为以下 9 个新子模块：

1. 单号资料管理
2. 地址簿管理
3. 申报物品
4. 问题类别
5. 物品类别
6. 报关类型
7. 出口原因
8. 清关方式
9. 销售条款

## 确认的设计决策

1. **展示形式**：沿用「基础资料」现有做法 —— `data-manage_business` 单路由 + 页面内左侧 `ArchiveSwitch` 子导航，9 个子档案**不生成路由/菜单**。
2. **旧子模块**：删除，完全替换（与「基础资料」改造口径一致）。
3. **字段**：先按通用字段「编码（code）+ 名称（name）+ 状态（status，组件自动追加）+ 备注（remark）」实现，后续再逐个补充调整。
4. **数据源**：继续走 DEV mock（现有 `mock-data-manage.ts`，生产环境 `/data-manage/:archive/*`）。

## 改造方案

### 1. 删除旧子模块目录

- `src/components/MasterData/archives/business/warehouse/`
- `src/components/MasterData/archives/business/location/`
- `src/components/MasterData/archives/business/carrier/`
- `src/components/MasterData/archives/business/store/`

### 2. 新增 9 个子档案（`archives/business/<dir>/index.vue`）

| 展示名       | 组件目录           | archive key       |
| ------------ | ------------------ | ----------------- |
| 单号资料管理 | `waybill`          | `waybill`         |
| 地址簿管理   | `address`          | `address`         |
| 申报物品     | `declared-goods`   | `declaredGoods`   |
| 问题类别     | `problem-category` | `problemCategory` |
| 物品类别     | `goods-category`   | `goodsCategory`   |
| 报关类型     | `customs-type`     | `customsType`     |
| 出口原因     | `export-reason`    | `exportReason`    |
| 清关方式     | `clearance-method` | `clearanceMethod` |
| 销售条款     | `sales-terms`      | `salesTerms`      |

每个 `index.vue` 结构与 `basic/country-region/index.vue` 完全一致：通用字段 `code`（必填）/ `name`（必填）/ `remark`，`status`/`createTime` 由 `MasterDataArchive` 自动追加；搜索栏 keyword + status + actions。

### 3. 页面 items 替换

`src/views/data-manage/business/index.vue` 的 `items` 改为上述 9 个 `ArchiveSwitchItem`（按截图顺序）。

### 4. 类型（`src/typings/api/data-manage.d.ts`）

- 删除 `BusinessWarehouse` / `BusinessLocation` / `BusinessCarrier` / `BusinessStore` 4 个 interface。
- `DataManageArchiveKey` 联合体移除 `warehouse|location|carrier|store`，并入 `waybill|address|declaredGoods|problemCategory|goodsCategory|customsType|exportReason|clearanceMethod|salesTerms`。
- 新增 9 个 interface（`extends MasterDataRow { code: string; name: string }`）。

### 5. Mock（`src/service/api/mock-data-manage.ts`）

- `factories` 删除 4 旧工厂，新增 9 个（通用 `code`/`name`/`status`/`remark`，仿现有写法）。

### 6. i18n（zh-cn / en-us / app.d.ts 三处同步）

- 抽成 **business 级通用键**：`business.code='编码'`、`business.name='名称'`、`business.form.codePlaceholder='请输入编码'`、`business.form.namePlaceholder='请输入名称'`。
- 9 个模块**只各加一个 `.title`**（如 `waybill.title='单号资料管理'`）。
- 删除旧 4 模块的全部子键（`warehouse`/`location`/`carrier`/`store`）。

### 7. 路由无关

不动 `build/plugins/router.ts`、`src/router/elegant/**`，不跑 gen-route（子档案不生成路由）。
