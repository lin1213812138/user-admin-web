# 新增/编辑表单未独立成文件（定位说明）

> 日期：2026-09-18
> 来源：用户贴「资料管理 → 通用资料 → FBA仓库」列表截图提问「为什么没有把新增文件独立出来」

## 用户所指

通用资料页两个档案（国家地区 / FBA 仓库）的**新增 + 编辑表单没有拆成独立组件文件**，与列表逻辑挤在同一个 `.vue` 里。

## 事实核查

| 项                               | 现状                                                                                                                                                                                                   |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `basic/modules/country-region/*` | `CountryRegion.vue` 295 行自包含：搜索 + Table + useVxeTable + Drawer + NFormWrap + formItems + openCreate/openEdit/handleDrawerSubmit                                                                 |
| `basic/modules/fba-warehouse/*`  | `FbaWarehouse.vue` 343 行同上（另含 countryOptions/countryNameMap 下拉数据与时间格式化）                                                                                                               |
| 改造前（提交 61eb47c 之前）      | 两文件各 ~73 行壳，只声明档案字段配置，列表与抽屉由 `MasterDataArchive` 公共包装提供                                                                                                                   |
| 同批新页                         | `data-manage/bl`（6 个）、`ship`（4 个）、`no-rule` 新增 3 个 tab 也是同样的自包含内联形态                                                                                                             |
| 仓库既有对照                     | `setting/modules/waybill-rule/` = index.vue + `waybill-rule-form.vue` + `waybill-rule.model.ts`；`user/modules/user-operate-drawer.vue`；`customer/modules/customer-detail/address-operate-drawer.vue` |

## 根因

- 直接原因：09-18「按脑图重构资料分组并新增提单资料」（提交 `61eb47c`）把这两个档案从通用归档组件切到真实接口（`/country/*`、`/fba/*`）自实现时，按「一个 tab 一个自包含页面」的最短路径重写，抽屉顺势内联。
- 规则层面：违反 2026-09-10 已确立的仓库原则 —— **列表页与表单/编辑界面必须拆成独立组件文件，`<script setup>` 内不 export 类型（类型放共享 `.model.ts`）**；`changelog/资料管理按脑图调整.md` 的实施记录里也没有拆分步骤。
- 非单点遗漏：同批 bl / ship / no-rule 新页统一同款写法，属那轮的统一形态偏差。

## 候选修复方案（待用户选择，尚未改动任何代码）

- **A 最小范围**：只拆通用资料两个 → `modules/country-region/CountryRegionDrawer.vue`、`modules/fba-warehouse/FbaWarehouseDrawer.vue`。
- **B 统一口径**：data-manage 下 15 个自包含页（通用 2 + 提单 6 + 发货 4 + 单号 3）全部拆出抽屉文件。
- **C 维持现状**。

共同注意点：

1. FBA 抽屉依赖父页面已加载的 `countryOptions` / `countryNameMap`，拆出后需 props 传入或子组件自行拉 `/country/query`；
2. 新文件不能用 `index.vue`（elegant-router 会扫成路由）。
