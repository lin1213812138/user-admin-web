# 打印预览测试数据不更新

## 问题现象

在右侧属性面板修改字段元素的「测试数据」后点击预览，预览弹窗显示的仍是原始示例值，没有反映最新编辑。

例如 `receiverName` 字段示例值为 `Hans Muller`，在属性面板把测试数据改成 `Hans Mullerqweqweqwq` 后，画布上已更新，但预览仍然显示 `Hans Muller`。

## 根因

预览渲染调用的是 `instance.getHtml(buildSampleData())`，传入一份**固定**的示例数据：

```ts
const body = toHtmlString(instance.getHtml(buildSampleData()));
```

`buildSampleData()` 始终返回 `{ receiverName: 'Hans Muller', ... }` 这一份静态对象。

hiprint 对「绑定字段」的元素渲染规则是：`data[field] ?? options.testData`。
因为传入的 `data[receiverName]` 永远是非空的 `Hans Muller`，就直接命中 `data[field]`，**把用户在属性面板里改过的最新 `testData` 给覆盖了**，所以预览永远显示固定的示例值。

## 修复

预览填充数据改为**读取设计器当前模板里各字段元素最新的 `testData`**，未编辑（测试数据为空）的字段回退到固定示例值：

- `src/views/system-manage/print-design/index.vue`
  - 新增 `extractPreviewData(fallback)`：遍历 `instance.getJson()` 的 `printElements`，把每个 `options.field` 对应的 `options.testData`（非空）写入预览数据；兼容 hiprint 的 `{ panels:[{printElements}] }` / 顶层 `{ printElements }` / 裸数组三种模板结构。
  - `handlePreview` 改用 `instance.getHtml(extractPreviewData(buildSampleData()))`。

仍走 `instance.getHtml()` 直接生成预览，符合「禁止 getJson → 新建 PrintTemplate → getHtml round-trip」的既定方案；只是把填充数据从固定 sample 换成设计器当前测试数据。

## 验证

1. 拖入一个字段元素（如收件人），在右侧属性面板把测试数据改成任意新值。
2. 点击预览，弹窗应显示该新值（所见即所得）。
3. 未编辑测试数据的字段仍显示默认示例值。
