# 标签设计器：水平对齐 / 垂直对齐并排一行

日期：2026-09-14
范围：`src/views/system-manage/label-designer/modules/panels/property-panel.vue`（样式卡）

## 背景

用户截图反馈：「水平对齐和垂直对齐放在同一行」。

现状：样式卡里两个对齐下拉框各是 `span: 12` 的标准 item，站位由「前序 span 累计」的流式栅格决定。
「关联标题」开启时前面会多出 3 个标题样式项（titleFontSize / titleColor / titleFontWeight），
使前序累计变为 84（84 ≡ 12 mod 24）——「水平对齐」落在行右半，「垂直对齐」被挤到下一行行首。

根因：`titleStyleItems` 是 3 项（奇数），title 开 / 关会让后续 item 的配对整体翻转。
数学上无法同时让两种场景都恰好配对（前缀相差 36 ≡ 12 mod 24），所以**纯调整排序解决不了**。

## 方案

把「水平对齐 + 垂直对齐」合并为**一个 span 24 的 custom item**（`key: 'alignGroup'`），
slot 内两列并排渲染两个 `NFormItem`：

- 整行独占 → 对 item 列表的站位完全免疫，title 开 / 关都不会被拆行；
- slot 内用嵌套 `NFormItem`：label 的字号（12px）/ 颜色 / 间距与其它项天然一致，不必手写克隆样式；
- 外层 item `label: ''`：naive `FormItem.renderLabel` 对空 label 直接返回 null 并挂 `--no-label` 类，
  不会产生空 label 行（已核对 naive 源码 `if (!labelText) return null` 分支）；
- 选项抽成 `alignOptions` / `valignOptions` 两个 computed 常量供模板复用；
- 把「行高」移到对齐组之后：title 开启时整卡恰好排满（颜色|字重 → 对齐组 → 行高|显示边框）。

## 改动清单

| 位置                                 | 改动                                                                                                                                     |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `styleItems`（text / longText 分支） | 删除 align、verticalAlign 两个 select item；新增 `{ key: 'alignGroup', label: '', type: 'custom', span: 24 }`；lineHeight 移到对齐组之后 |
| script                               | 新增 `alignOptions` / `valignOptions` computed 常量                                                                                      |
| 模板（样式卡 `NFormWrap`）           | 新增 `#alignGroup` slot：`flex gap-8px` 两列，各一个 `NFormItem`（label 为水平对齐 / 垂直对齐）+ `NSelect`（size small）                 |

## 已知取舍

「关联标题」关闭时（默认场景）「字重」会独占半行（右侧留空）——这是流式布局下 title 项奇偶差（36）的必然结果；
本次优先保证 title 开启时（用户截图场景）所有行排满。
若后续想两端都满行，可把 `titleStyleItems` 中任一项的 span 改为 24（代价：该标题项独占一行）。

## 追加修正：对齐组上下间距不统一（同日）

用户截图反馈：「为什么上下间距没有统一？」——对齐组与相邻行的间距明显大于其它行。

### 根因（naive NFormItem 的两个默认值）

1. `mergedShowLabel` **默认 `true`**（`naive-ui/es/form/src/utils.mjs`：`showLabel ?? NForm.showLabel ?? true`，**不判断 label 是否为空**）→
   外层 alignGroup item 虽然 `label: ''` 使 label 文字不渲染，但栅格仍保留 `grid-template-areas: "label" ...` 的空 label 行
   （`minmax(var(--n-label-height), auto)`），对齐组上方多出一段空隙；
2. `mergedShowFeedback` **默认 `true`** → 每个 NFormItem 底部自带 feedback 占位区；嵌套的两个内层 NFormItem 各自再加一个
   → 对齐组下方间距变成两倍。

### 修复

- `FormWrap` 新增可选字段 `showLabel?: boolean` 并透传 `:show-label` 到 NFormItem（不传时 `undefined`，naive 走默认 `true`，其它使用方零影响）；
- alignGroup item 显式 `showLabel: false` → 外层走 `--no-label` 栅格（`blank` + `feedback` 两行），高度与普通字段行一致；
- 内层两个 NFormItem 加 `:show-feedback="false"` → 去掉多余的 feedback 占位。
