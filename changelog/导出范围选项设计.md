# 导出组件增加「数据范围」选项（全部 / 当前页 / 勾选数据）

- 日期：2026-09-05
- 状态：**已实现**（待浏览器手测）
- 实现计划：[导出范围选项实现计划.md](./导出范围选项实现计划.md)
- 影响面：`src/components/Export/*`、用户管理页（示例页）、i18n 三处

## 1. 背景与目标

现有两条导出管线：

| 管线                    | 引擎                         | 位置                               | 现有数据范围                                    |
| ----------------------- | ---------------------------- | ---------------------------------- | ----------------------------------------------- |
| A. vxe 原生一键导出     | `@vxe-ui/plugin-export-xlsx` | `Table` 右上 `action-export`       | 仅当前已加载数据（= 当前页）                    |
| B. exceljs 字段选择导出 | 自建 exceljs 动态 import     | 页面左侧操作栏 `TableExportAction` | 传了 `fetchAll` 就**永远导全量**，否则导 `data` |

B 管线的范围目前是「由有没有传 `fetchAll` 隐式决定」，用户无法选择。本次目标：在 B 管线的字段弹窗内显式提供**数据范围**选项，让用户自己决定导出全部 / 当前页 / 勾选数据。

**明确不做**：A 管线（vxe 原生导出）本次不动，保持只导当前页。

## 2. 用户决策记录

| 问题             | 决策                                                              |
| ---------------- | ----------------------------------------------------------------- |
| 加在哪条管线     | 只加 B（字段选择导出 / exceljs）                                  |
| 选项呈现位置     | 字段弹窗内顶部，确认时连同字段一起提交                            |
| 不可用选项       | **灰显禁用 + 说明原因**（不隐藏，让用户感知存在该能力）           |
| 默认选中         | 有 `fetchAll` → 全部；否则 → 当前页（与现状行为一致，迁移无感知） |
| 是否记忆上次选择 | 不记忆，每次打开弹窗都回到默认值                                  |

## 3. 设计

### 3.1 类型层 `src/components/Export/type.ts`

新增：

```ts
/** 导出数据范围 */
export type ExportScope = 'all' | 'page' | 'checked';

/** 范围选项（弹窗渲染用；disabled 时灰显并展示 hint 说明原因） */
export interface ExportScopeOption {
  value: ExportScope;
  label: string;
  disabled: boolean;
  hint?: string;
}

/** 字段弹窗确认回传：范围 + 字段 */
export interface ExportConfirmPayload {
  scope: ExportScope | null; // null = 调用方未启用范围区（DataExport 场景）
  fields: ExportField[];
}
```

### 3.2 `field-select-dialog.vue`（纯 UI，范围区为可选能力）

- 新增 props：
  - `scopes?: ExportScopeOption[]` —— **不传或空数组则不渲染范围区**，保证 `DataExport`（非表格页）行为零变化。
  - `scope?: ExportScope` —— 配合 `update:scope` 双向绑定。
- 新增 emit：`(e: 'update:scope', scope: ExportScope)`。
- 变更 emit：`confirm` 由 `(fields: ExportField[])` 改为 `(payload: ExportConfirmPayload)`。
  两个调用方同步适配（均为仓库内部组件，无外部使用方）。
- 模板：**与「新增字段」按钮同一行**（2026-09-05 用户要求合并，原为独占一行）—— 该行左侧依次放 `数据范围` 标题 + `NRadioGroup`（`v-if="scopes?.length"`，不传 `scopes` 时整块不渲染）与「新增字段」按钮，右侧「已选 N 项」位置不变；禁用项 `disabled` 取 option，`title` 显示 `hint`。弹窗高度保持 `520px`（合并后不额外占行）。
- 打开时（`watch visible`）把 `props.scope` 同步进本地值；`loading`（导出中）时整组禁用，防中途切换。
- 「重置」按钮**只重置字段**（名称 / 顺序 / 自定义字段），不重置范围 —— 范围不属于字段编辑副本。

### 3.3 `table-export-action.vue`（业务装配层）

新增 props：

| prop          | 类型        | 默认        | 说明                                                            |
| ------------- | ----------- | ----------- | --------------------------------------------------------------- |
| `checkedData` | `unknown[]` | `undefined` | 勾选行；由页面 `@selection-change` 透传                         |
| `showScope`   | `boolean`   | `true`      | 关闭后退化为旧行为（不显示范围区，按 `fetchAll ? 全量 : data`） |

已有 props `data`（当前页）、`fetchAll`（全量）语义不变。

范围选项计算：

| 范围             | 数据源              | 可用条件        | 禁用时的 hint                                        |
| ---------------- | ------------------- | --------------- | ---------------------------------------------------- |
| 全部             | `await fetchAll()`  | 传了 `fetchAll` | `common.exportScopeAllUnavailable`（未配置全量取数） |
| 当前页（N 条）   | `props.data`        | 恒可用          | ——                                                   |
| 勾选数据（N 条） | `props.checkedData` | 长度 > 0        | ——（label 自带 `（0 条）`已说明）                    |

默认选中：`props.fetchAll ? 'all' : 'page'`，**每次打开弹窗都重置为默认值**。

`handleExport(payload)` 按范围取数：

```
all      → await props.fetchAll()
page     → props.data
checked  → props.checkedData ?? []
```

边界处理：

- `checked` 但为空 → `window.$message?.warning($t('common.exportScopeCheckedEmpty'))` 并 return，**不关闭弹窗**。
- `all` 取数抛错 → 沿用现有 catch：`console.error` + `common.exportFailed`，**不关闭弹窗**便于重试。
- 导出成功后提示 `common.exportSuccess` 并关闭弹窗（现状不变）。

### 3.4 `data-export.vue`（非表格页）

不传 `scopes` → 不渲染范围区，行为完全不变。唯一改动是适配 `confirm` 新签名：取 `payload.fields`。

### 3.5 i18n（三处同步：`zh-cn.ts` / `en-us.ts` / `typings/app.d.ts` 的 `App.I18n.Schema`）

| key                                | zh-cn                  | en-us                              |
| ---------------------------------- | ---------------------- | ---------------------------------- |
| `common.exportScope`               | 数据范围               | Data Scope                         |
| `common.exportScopeAll`            | 全部数据               | All Data                           |
| `common.exportScopePage`           | 当前页（{count} 条）   | Current Page ({count})             |
| `common.exportScopeChecked`        | 勾选数据（{count} 条） | Selected Rows ({count})            |
| `common.exportScopeCheckedEmpty`   | 请先勾选要导出的行     | Please select rows to export first |
| `common.exportScopeAllUnavailable` | 未配置全量取数         | Full data source not configured    |

### 3.6 页面改造（用户管理页作示例）

```vue
<TableExportAction
  :columns="columnConfigs"
  :data="data"
  :checked-data="checkedRows"
  :fetch-all="fetchAllUsers"
  :filename="$t('route.system-manage_user')"
/>
```

`checkedRows` 页面已有（`@selection-change` 写入），直接透传即可，**不需要改 `useVxeTable`**。

## 4. 数据流

```
页面 ──:data(当前页)──┐
     ──:checked-data─┼→ TableExportAction ──:scopes/:scope──→ FieldSelectDialog
     ──:fetch-all────┘        ↑                                      │
                              └──── confirm({ scope, fields }) ──────┘
                              │
                    按 scope 选 rows → exportRowsToXlsx(rows, fields, filename)
```
