# 报价设置页「渠道名称」未定义修复

> 日期：2026-09-20 ｜ 状态：已实施

## 背景

用户贴 IDE 截图：`src/views/channel-quote/receive/modules/quote-setting/index.vue` 模板中

```html
<span class="font-medium">{{ channelName || channelId }}</span>
```

`channelName` 被标红（未定义标识符），类型提示里作用域仅剩 `{ channelId, $t, activeTab, ... }`。

## 根因

`channelName` 的 computed 定义此前被注释掉（`// const channelName = computed(() => String(route.query.name ?? ''));`），而模板恢复了引用 → 编译/类型报错。

数据来源本身是通的：收货渠道列表跳转时 `routerPushByKey('channel-quote_receive_quote-setting', { query: { channelId, name } })` 已把渠道名带进 query，直接敲 URL 时 `v-if="!channelId"` 走引导空态。

## 修复

`src/views/channel-quote/receive/modules/quote-setting/index.vue`：

- 恢复 `channelName` computed（`String(route.query.name ?? '')`），并在其上方补一行注释说明「缺失时回落展示 channelId」；
- 其余逻辑（tab↔URL 同步、keep-alive、空态、五个分页面板）零改动。

## 验证

- `pnpm typecheck` exit 0（不再报 `channelName` 未定义）。
- `npx oxlint` / `npx eslint`（该文件）：0 warnings 0 errors。
- `npx oxfmt --check`：通过。
