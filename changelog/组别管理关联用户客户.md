# 组别管理列表新增关联用户、关联客户

用户需求："组别管理列表新增关联用户、关联客户"。

## 问题定位

- 组别列表页 `src/views/system-manage/group/index.vue`（useVxeTable + Table），此前无关联弹窗。
- 后端 tms-user 关键事实（零改动）：
  - 用户的组别字段是 **`groupIds: [String]`（数组）**（`lib/common/models/user.js`），且 `lib/services/group.js` 的 `get` 中 `userService.count({ groupIds: group._id })` 证实；`/user/query` 用 `where: { groupIds: '<groupId>' }` 走 MongoDB 数组成员匹配。
  - 客户的组别字段是 **`groupId: String`（单值）**（`lib/common/models/customer.js`）；`/customer/query`（queryCommon）用 `where: { groupId }` 精确过滤。
- 复用站点/角色页已确立的 `RelationModal` 模式。

## 实施内容

1. `src/service/api/group/index.ts`：新增 `fetchGetGroupUserList({ page, size, groupId })`（`/user/query`，`where: { groupIds }`）、`fetchGetGroupCustomerList({ page, size, groupId })`（`/customer/query`，`where: { groupId }`），均 flat 解包 `{ data, error }`。
2. `group/index.vue`：
   - 「所属站点」后新增「关联用户」「关联客户」两列（宽 90、居中，查看按钮插槽）。
   - 挂两个 `RelationModal` 实例：用户列=姓名/账号/所属站点/状态，客户列=编码/名称/所属站点/状态。
   - `openRelationModal('user'|'customer', row)` 先探查 `page:1,size:1`，无数据 `common.noData` 提示不弹窗。
   - `cacheKey` 升级为 `system-manage-group-v3`。
3. `src/typings/api/system-manage.d.ts`：`UserSearchParams.where` 补 `groupIds?: string`。
4. i18n：`page.manage.group.relationUser`（关联用户/Related Users）、`page.manage.group.relationCustomer`（关联客户/Related Customers），并同步 `src/typings/app.d.ts` Schema。
5. 「查看」按钮文案复用 `page.manage.site.view`。
