# 标签设计工作区无限画布改造

- 日期：2026-09-11
- 关联：打印设计页 `src/views/system-manage/print-design/index.vue`
- 前置设计：[标签打印模板设计器设计方案](./标签打印模板设计器设计方案.md)

## 需求

把标签设计页中间区域从「固定纸张 + NScrollbar 滚动」改造成「无限工作台 + 浮层纸张」：中间整块变成可拖动的工作区，标签纸张浮在上面；鼠标拖动平移工作区、滚轮缩放纸张；刻度（`.hiprint_rul_wrapper`）增加显示/隐藏按钮。

## 关键约束

hiprint 是 **DOM 渲染**（字段为真实 DOM 元素，依赖 jQuery 拖拽/吸附），不是 `<canvas>` 绘制，**不能把中间改成真 canvas、也不能重写设计器**。本方案用「外层视口 + flex 居中 stage + 纸张浮层」达到交互效果，且完全不碰 hiprint 渲染逻辑。

## 决策（用户确认）

| 项       | 结论                                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------------------- |
| 拖拽语义 | 拖动空白区 = 平移工作区；拖动纸张上 = 仍交给 hiprint 拖字段元素。平移/缩放是纯视图态，不写 designJson，刷新复位 |
| 缩放语义 | 滚轮 = 缩放纸张（调用 hiprint 原生 `template.zoom(scale, true)`）                                               |
| 刻度按钮 | 顶部工具栏，紧挨「隐藏网格」                                                                                    |
| 工作区   | 铺满中间区、隐藏滚动条，靠拖动平移（真正无限画布手感）                                                          |
| 缩放锚点 | 围绕纸张中心（缩放时补偿 translate，纸张中心保持画布中心，不漂移）                                              |
| 缩放范围 | 放宽到 0.2–4.0（步进 0.1）                                                                                      |

## DOM 结构改造（index.vue）

```html
<div class="print-design-canvas"            <!-- 视口：relative; overflow:hidden; flex 居中; @mousedown + @wheel.prevent -->
     @mousedown="handleCanvasMouseDown"
     @wheel.prevent="handleWheel"
     :class="{ 'hide-ruler': !showRuler }">
  <div class="pd-stage" :style="{ transform: `translate(${tx}px, ${ty}px)` }">
    <div id="hiprint-printTemplate">        <!-- hiprint 挂载点，保留 padding:16px 让标尺负 margin 可见 -->
      <div class="hiprint-printPaper design">…<!-- hiprint 自己加 transform:scale()（zoom 控制）-->
        <div class="hiprint_rul_wrapper">…</div><!-- 刻度：showRuler 控制显隐 -->
```

- 移除中间 `NScrollbar`（右侧属性面板的 NScrollbar 保留）。
- `.pd-stage` 由画布 flex 居中，初始 `tx=ty=0` 即纸张居屏幕中心；平移 = 累积 `tx/ty`。

## 交互逻辑

### 平移（tx/ty）

- `handleCanvasMouseDown(e)`：若 `e.target.closest('.hiprint-printPaper')` 命中 → 不拦截，交 hiprint 处理字段拖拽；否则 `startPan`：记录 `startX=e.clientX, startY=e.clientY, baseTx=tx, baseTy=ty`，并监听 `document` 的 mousemove/mouseup。
- `document:mousemove`：`tx = baseTx + (e.clientX - startX)`；`ty = baseTy + (e.clientY - startY)`。
- `document:mouseup`：移除监听，结束。
- cursor：`.print-design-canvas { cursor: grab }`，panning 时 `cursor: grabbing`。

### 缩放（围绕纸张中心补偿）

```ts
const MIN_SCALE = 0.2;
const MAX_SCALE = 4.0;
const SCALE_STEP = 0.1;

function applyZoom(next: number) {
  next = Math.min(MAX_SCALE, Math.max(MIN_SCALE, Number(next.toFixed(1))));
  if (next === scale.value) return;

  const paper = document.querySelector<HTMLElement>('.hiprint-printPaper');
  const pw = paper?.offsetWidth ?? 0; // 布局尺寸，不含 transform
  const ph = paper?.offsetHeight ?? 0;
  const delta = next - scale.value;

  // hiprint zoom 以纸张左上角为缩放锚（scale<=1 origin "0 0"；scale>1 origin "-scale% -scale%"），
  // 缩放后纸张布局中心向右下偏移 pw*delta/2、ph*delta/2；补偿 translate 使其回到画布中心。
  tx.value -= (pw * delta) / 2;
  ty.value -= (ph * delta) / 2;
  scale.value = next;
  templateRef.value?.zoom(next, true);
}

function handleWheel(e: WheelEvent) {
  applyZoom(scale.value + (e.deltaY < 0 ? SCALE_STEP : -SCALE_STEP));
}
```

- 工具栏 +/- 缩放按钮改为调用 `applyZoom(scale.value ± SCALE_STEP)`，行为一致。

### 刻度显隐按钮

- ToolBar 新增 prop `showRuler: boolean` + emit `toggleRuler`，按钮紧挨「隐藏网格」，文案 `page.manage.printDesign.hideRuler` / `showRuler`。
- index.vue 新增 `const showRuler = ref(true)`，给 `.print-design-canvas` 加 `:class="{ 'hide-ruler': !showRuler }"`。
- CSS：

```css
.print-design-canvas.hide-ruler .hiprint_rul_wrapper {
  display: none !important;
}
```

- 现有 `showGrid`、保存/预览/清空逻辑全部保留，仅新增上述态。

## 风险与兜底

- **风险**：hiprint 字段拖拽落点若依赖页面绝对坐标而非相对纸张 rect，则祖先 translate 可能导致字段落点偏移。
- **兜底**：实现后做最小验证（平移后拖一个字段，确认落点准）；若偏移，平移改为控制滚动（`scrollLeft/Top`，保留 NScrollbar 但隐藏其条）而非 transform —— 对 hiprint 零侵入。
- 可选：对 `tx/ty` 加宽松 clamp，防止纸张被拖出视口过远。

## 验证

1. 进入设计页，纸张初始居中于工作区。
2. 在空白区按住拖动，工作区平移（cursor grabbing），松开停止。
3. 滚轮向上/下，纸张围绕中心缩放，范围 0.2–4.0；工具栏 +/- 同步。
4. 平移后拖一个字段元素，落点准确（风险点验证）。
5. 点「隐藏刻度」，标尺消失；再点恢复。
6. 刷新页面，平移/缩放/刻度状态复位（不持久化）。

## 实现注意（给开发的叮嘱）

- 不要在 `handleCanvasMouseDown` 里拦截纸张内事件，否则会破坏 hiprint 字段拖拽。
- 补偿公式依赖 `.hiprint-printPaper` 的 offsetWidth/Height（布局尺寸），不要读被 transform 影响的值。
- i18n 必须 zh-cn/en-us 同步，否则 TS 报错。
