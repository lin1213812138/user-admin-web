# 标签设计器缩放控件优化

> 日期：2026-09-12　模块：`src/views/system-manage/label-designer`

用户反馈工具栏缩放区（− / 80% / ＋ / 重置缩放 四个元素混排）难看。经确认采用**紧凑按钮组**方案：

- `NButtonGroup` 组合 `[-] [80%] [+]`，百分比居中、整体只有一组边框，视觉统一。
- 中间百分比本身是按钮：**点击直接重置为 100%**（`title` 悬停提示复用 `resetZoom` 键，i18n 键保留不删）。
- 独立「重置缩放」文字按钮删除；`zoomIn` / `zoomOut` / `zoomReset` 逻辑不变。

`tool-bar.vue` 单文件改动，`pnpm typecheck` 通过。

## 追加：文字字符换图标

用户反馈「−」「＋」文字字符太小：换成 iconify 图标 `icon-ic-round-remove` / `icon-ic-round-add`（`#icon` 插槽 + `text-icon` 类，与打印设计工具栏同款模式），尺寸/颜色随主题。

## 追加：重置提示改 NTooltip

原生 `title` 换成 `NTooltip`（`#trigger` 包裹百分比按钮，内容用 `resetZoom` 键），交互更符合项目组件风格。
