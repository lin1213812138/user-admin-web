# 标签条码标题与编码值同行

## 需求

用户截图：条码的标题（「单号（条形码）」）显示在条码上方独立 DOM 前缀，与条码图内下方的编码值文本分离。要求「标题和编码值写在一起」，且**标题大小与编码值一样**。

## 方案迭代

1. **第一版（已废弃）：bwip-js `alttext` 方案**——把「标题:编码值」整行画进条码 PNG。用户实测出现乱码（文本行开头多「OO??」等异常字形）。node 渲染 PNG 实证：**bwip-js 内置位图字体仅覆盖 Latin-1，中文字符画成乱码/空白**（`DrawingCanvas` 基于 `DrawingBuiltin`，文本走 `FontLib.getglyph` 逐字符位图渲染，无中文字形）。
2. **第二版（最终）：DOM 文本行渲染**——条码 PNG 只画条形（`includetext` 移除），标题 + 半角冒号 + 编码值合为条形下方 DOM 文本行（居中、同字号），画布与打印两端结构一致。

## 最终改动

- `modules/barcode.ts`
  - `renderBarcode` 签名简化为 `{ symbology, text }`：PNG 固定只画条形（`scale:3, height:10`），删 `includetext`/`textxalign`/`textsize`/`textyoffset`/`alttext` 逻辑。
- `modules/element-renderer.vue`（画布端）
  - 条码独立分支：竖排 flex column = 条码 img（`flex-1 min-h-0` + object-contain）+ 文本行（`shrink-0` 居中）。
  - 文本行内容 =（`titleText` 开启时）`标题:` +（`displayValue !== false` 时）编码值；两者都关不渲染行。
  - 新增 `barcodeLineVisible` / `barcodeLineStyle`：行字号统一用「字号」（`fontSize || 10` 兜底），`textGap` 语义由「图内文本偏移 pt」改为「行与条形间距 px」（数值沿用）。
  - 追代：文本行超宽自动换行（`break-all`，长编码值任意字符处折行，溢出由外层 `overflow-hidden` 裁剪），不再 nowrap 截断。
- `modules/render-element-html.ts`（打印端同步）
  - 条码分支同构：无行时直出 img；有行时 `flex-direction:column` 包裹（img 区 `flex:1 min-height:0` + 文本行 `flex:none`），`escapeHtml` 处理标题/编码值；文本行 `word-break:break-all` 换行同步。
- `modules/property-panel.vue`
  - 条码 case 移除 `titleStyleItems`（标题字号/颜色/字重对合并行无效），保留 条码类型/字号/间距/边框。

## 兼容性

- options 未增删字段，designJson 不变；旧数据 `displayValue !== false`、`fontSize || 10` 兜底保留。
- 视觉变化：编码值字体从 bwip 位图字体变为页面字体（预期内）；条码 PNG 变纯条形后按 `object-contain` 在剩余空间自适应。
- 二维码/图片/矩形的标题 DOM 前缀不受影响。

## 经验

- **bwip-js 的 PNG 内文本（includetext/alttext）只能渲染 Latin-1**，任何中文拼图内方案都不可行；需要中文文本时必须走 DOM 渲染层。
