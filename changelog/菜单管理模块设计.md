# 菜单管理模块设计

> 日期：2026-08-31
> 状态：设计中（待用户确认）

## 背景

`system-manage/menu` 页面目录为空，现有 `system-manage.ts` 只含用户、角色接口，无菜单 CRUD。
用户希望新增「菜单管理」模块，参照截图表单字段。

## 设计决策（经用户确认）

1. **列表展示形式**：树形表格（`vxe-table` 树形行，支持展开/折叠），新增时通过「上级菜单」下拉选择层级。
2. **数据来源**：本地 mock 优先，跟随现有 `system-manage.ts` 的 DEV 模式约定（DEV 下 `import.meta.env.DEV` 直接返回 mock），后端就绪后切换真实接口。
3. **菜单范围**：列表只展示「目录」与「菜单」两类，**不含按钮**（按钮权限后续在角色分配里处理）。
4. **表单字段**：完全采用截图表单全套字段——上级菜单、菜单类型（目录/菜单）、菜单名称、菜单图标、路由地址、组件路径、权限标识、排序、状态、是否可见、是否缓存、是否外链、重定向。

## 实现方案

### 1. 类型声明 `src/typings/api/system-manage.d.ts`

新增：

- `MenuType = 'catalog' | 'menu'`（目录 / 菜单）
- `Menu`：`id, parentId, menuName, menuType, icon, routePath, componentPath, permission, sort, status, visible, keepAlive, isExternal, redirect, children?`
- `MenuList = Api.Common.PageResponse<Menu>`（mock 返回扁平数组，前端转树）
- `MenuCreateParams` / `MenuUpdateParams` / `MenuSearchParams`

### 2. Mock `src/service/api/mock.ts`

新增 `mockMenuList`（含 2~3 层目录/菜单示例），及 `fetch` 后端的增删改改查逻辑在 `system-manage.ts`。

### 3. 接口 `src/service/api/system-manage.ts`

- `fetchGetMenuList`：DEV 返回 mock（扁平数组）；`transform` 在前端 `buildMenuTree` 成树。
- `fetchCreateMenu` / `fetchUpdateMenu` / `fetchDeleteMenu`（DEV 下改 mock 内存数组后返回）。
- 注明：走 mock 强转分支，**无 `{ data, error }` 包裹**。

### 4. 页面 `src/views/system-manage/menu/index.vue`

- `useVxeTable`，`columns` 配置：菜单名称（detail+图标）、类型（Tag）、路由地址、组件路径、排序、状态、创建时间、操作。
- 树形：`transform` 返回 `records`（已建树），`pagination` 设为 `null`（树形不分页）。
- 操作列：编辑 / 删除（NPopconfirm）。顶部按钮：新增、列设置、刷新。

### 5. 抽屉 `src/views/system-manage/menu/modules/menu-operate-drawer.vue`

- 复用 `CommonDrawer` + `NFormWrap` 模式。
- 上级菜单：select，选项为整棵树（排除自身及后代），placeholder「顶级菜单」。
- 菜单类型：select（目录/菜单），切换「目录」时隐藏路由/组件相关项（用 computed `formItems` 控制）。
- 其余字段按截图表单：图标(input)、路由地址、组件路径、权限标识、排序(number)、状态(switch)、可见(switch)、缓存(switch)、外链(switch)、重定向(input)。

### 6. 路由 & i18n

- 新建 `views/system-manage/menu/index.vue` 后运行 `pnpm gen-route`（或 `pnpm dev`）自动生成路由。
- `src/router/routes/index.ts` 的 `customRoutes` 补 `system-manage_menu` 的 icon/title。
- `zh-cn.ts` / `en-us.ts`：补 `route.system-manage_menu` 与 `page.manage.menu.*` 全部文案（含 form 字段）。

## 验收

- `pnpm typecheck` + `pnpm lint` + `pnpm build` 通过。
- 菜单管理页可展示树形列表、新增/编辑（含上级菜单选择）、删除、列设置、刷新。
