# 共用「字段选择导出」组件设计

> 日期：2026-09-05
> 状态：v3 已定稿（用户浏览器手动验证下载中）

## 版本沿革

- **v1**：每页手写「导出按钮 + 字段弹窗」两套入口，引擎待定。
- **v2**：通用 `Table` 增加 `action-export` 自动内置「字段勾选导出」到右侧操作栏，引擎统一 exceljs（`@vxe-ui/plugin-export-xlsx` 仅全局注册备用）。
- **v3（当前）**：按用户反馈拆分——**`action-export` 回归 vxe-table 原生一键导出**（右上操作栏，所见即所得）；**字段勾选/全量/含隐藏列/status 文案的 exceljs 导出**改由页面把 `TableExportAction` 放进**左侧操作栏**，两套并存、按页面需要开启。

## 背景

系统各表格页（用户/角色/菜单等，基于通用 `Table` + `useVxeTable`）需要导出 Excel：

- 轻量路径（绝大多数页）：右上操作栏一键导出当前表格，所见即所得；
- 完整路径（个别数据敏感页，如用户管理）：弹窗勾选字段、拖拽排序、含隐藏列、分页全量、status 转文案。

## v3 修订说明

1. **通用 `Table` 的 `action-export` = vxe 原生导出**：
   - 在 `<vxe-table>` 上挂 `ref`，按钮调用实例 `exportData({ type: 'xlsx', filename, sheetName, message: false })`；
   - 依赖 `@vxe-ui/plugin-export-xlsx`（已在 `src/plugins/vxe-table.ts` 注入 exceljs 全局注册），**只导出当前表格渲染列 + 当前已加载数据**；
   - 新增可选 prop `export-filename` 控制文件名，缺省 `导出_时间戳`；
   - **不再**内置字段弹窗 / 全量取数 / status 文案（那是 exceljs 那条管线的职责）。
2. **exceljs 字段选择导出 = `TableExportAction`（表格左侧操作栏）**：
   - 保留 v2 的组件能力（自带触发按钮 + `FieldSelectDialog` 字段勾选弹窗 + `exportRowsToXlsx`），入口从「Table 内部自动挂载」改为「页面自行放进 `operation-left`」；
   - Props 不变：`columns`（全量列配置，可含隐藏列）/ `data` / `extraFields` / `fetchAll`（分页页拉全量）/ `filename`；
   - `exportRowsToXlsx` 与 `createDefaultExportName` 从 `@/components/Export` 统一导出，exceljs 仍动态 import。
3. **类型与清理**：删除不再被使用的 `TableExportConfig` 接口；`Export/index.ts` 出口收敛为 `TableExportAction` / `DataExport` / 类型与工具函数。

## 引擎分工（核心）

| 场景                                     | 引擎     | 入口                                              |
| ---------------------------------------- | -------- | ------------------------------------------------- |
| 当前页一键导出（渲染列 + 已加载数据）    | vxe 原生 | `Table` 右上 `action-export`（页面按需开启）      |
| 字段勾选 / 全量 fetchAll / 隐藏列 / 文案 | exceljs  | 页面左侧操作栏放 `TableExportAction`              |
| 非表格页 / 自定义触发                    | exceljs  | `DataExport`（`v-model:visible` + fields + data） |

## 落地记录（v3）

- `Table/table.vue`：删除 `exportConfig` prop 与 `TableExportAction` 自动挂载；新增 `action-export`（原生）+ `export-filename`；`handleNativeExport()` 调 vxe 实例 `exportData`。
- `views/system-manage/user/index.vue`（示例页）：右上开 `action-export`（演示原生导出）；左侧 `operation-left` 放 `TableExportAction`（`:columns="columnConfigs"` + `:fetch-all="fetchAllUsers"` + 文件名「用户管理」），两套并存验证。
- `Export/`：`table-export-action.vue` 语义改为「放左侧操作栏的字段选择导出」；`type.ts` 删除 `TableExportConfig`；`index.ts` 收敛导出。

## 验收

- 用户管理页右上「导出」：点击直接下载 xlsx（含当前列、当前数据），无字段弹窗。
- 用户管理页左侧「导出」：弹字段弹窗 → 默认全选 → 勾选/拖拽 → 导出列序一致、status 为启用/禁用、分页页导出全量。
- `pnpm typecheck` + `pnpm lint` 通过；通用 `Table` 改动不破坏既有页面。
