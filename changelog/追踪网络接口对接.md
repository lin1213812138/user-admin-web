# 追踪网络接真实接口

> 2026-09-17。用户贴 tms-user `TrackConfigSchema`（轨迹抓取配置，code 1027）：「接一下追踪网络的接口」。

## 现状定位

- **界面本就有**：`系统设置 → 轨迹抓取 → 追踪网络` 子 tab（`TrackNetworkTable.vue` + `TrackNetworkDrawer.vue`）一直走 `service/api/trace-config` 的 **DEV mock**，字段是虚构的 `serverAddress / systemType`（真实接口不存在），且从未有真实 URL。用户明确："没让你改界面，界面本来就有"——任务是换数据源，不是建页面。
- **后端事实**（tms-user）：`/track-config/{create,update,delete,query,get}` 走通用 `queryCommon`，**真分页** `{page,size,keyword}` → `{list,total}`；`name` 唯一（`uniqField:'name'`，重复报 102701「轨迹抓取配置已存在」）；`delete` 仅单 `_id`；模型 `trackType` 实为 **String**（用户贴的 schema 写 Number 有出入）；`queryCommon` 的 `keyword` 必须配 `keywordFields` 才生效（provider 是后端配 `['name']`）。

## 四项决策（用户确认）

1. `trackType` 以仓库模型 **String 字符串码**为准（ups/fedex/kdzs/sd/hl/k5/kjv5/nm/ry/ydd/xzh/t6/zgyz/track17）。
2. **不新建页面**，就地在现有追踪网络组件上接真实接口。
3. 承运网络 tab 的 `trackConfigId` **顺带接上**（数据源即本接口）。
4. 名称关键字搜索由**后端加一行** `keywordFields: ['name']`（与 provider 写法一致）。

## 实施

- **后端（tms-user，1 行）**：`lib/services/track-config.js` 的 `query` 改 `queryCommon(assign(params, { keywordFields: ['name'] }))`。
- **service**：新建 `src/service/api/track-config/index.ts`（`fetchGetTrackConfigList / fetchCreateTrackConfig / fetchUpdateTrackConfig / fetchDeleteTrackConfig`，tms-user 真实接口、无 DEV mock，flat request 解包 `{data,error}`）；删除 `service/api/trace-config/`，桶文件 `service/api/index.ts` 去掉悬空的 `./trace-config` 导出。
- **常量**：新建 `src/constants/track-config.ts`：`TRACK_TYPE_OPTIONS`（14 码 → 显示名）+ `trackTypeLabel()`。
- **类型**：`typings/api/system-manage.d.ts` 的 `TraceConfig*` 类型族就地改造为模型形状（`_id/name/trackType/url/account/password/key/web/channel/accountNo/creator/updateBy/createDate/updateDate`），查询参数 `{page,size,keyword}` → `{list,total}`（弃用模板 `PaginatingQueryRecord` 形状）。
- **TrackNetworkTable**：列对齐 7 列——网络名称(detail)/系统类型(trackType 插槽映射显示名)/地址/账号/渠道名称/修改人/更新时间(dayjs 格式化)；补 `search-action` 关键字搜索框（后端 keywordFields 生效）；补单行删除（NPopconfirm，后端仅单 `_id`）；cacheKey 升 **`trace-config-track-network-v2`**（列结构变更）。
- **TrackNetworkDrawer**：表单 9 字段对齐模型——name 必填、trackType 下拉必选（`TRACK_TYPE_OPTIONS`，`filterable:false`）、url/account/password/key/web/channel/accountNo 全可选；编辑原样回填；提交改 `{error}` 解包（原 try/catch 是 mock 抛异常写法）；移除不再使用的 `category` prop（eslint `vue/no-unused-properties`）。
- **i18n 三处**（zh-cn / en-us / `app.d.ts` I18n Schema）：`traceCapture.col` 删 serverAddress/systemType、增 trackType/url/account/channel；`traceCapture.form` 删 serverAddress(Pair)/systemType(Pair)、增 trackType + url/account/password/key/web/channel/accountNo（含 Placeholder）；`dataManage.ship.carrier` 增 `trackConfig`。
- **承运网络联动**（`Carrier.vue`）：挂载拉 `/track-config/query {page:1,size:500}` 建 `trackConfigOptions`（与 weightRuleOptions 同法）；表单 `trackConfigId` 下拉 + 列表「追踪配置」名称列插槽；编辑回填注释更新；`data-manage-ship.d.ts` Carrier 注释同步（trackConfigId 数据源已就绪，remoteGroupId 仍缺）。
