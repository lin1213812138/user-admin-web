# 报价设置页改左右布局（对齐系统设置）

> 日期：2026-09-20 ｜ 状态：已实施，待手动冒烟 ｜ spec：`docs/superpowers/specs/2026-09-20-报价设置左右布局-design.md`

## 背景

> 用户原话：**「这个能不能像系统设置一样改成左右的？」**（截图＝报价设置页：标题「测试收货渠道」+ 横向 tab：地址分区 / 渠道报价 / 渠道加收 / 客户报价 / 销售成本价）

即：把该页的横向 tab 结构改成与「系统设置」页一致的**左侧竖向 tab 栏 + 右侧内容区**布局。

## 方案确认（用户口径）

用户「可以」定稿三项、再回「开始」＝确认实现（命中宽泛口令）：

| #   | 项             | 结论                                             |
| --- | -------------- | ------------------------------------------------ |
| Q1  | 左栏顶部标题   | **渠道名称**（最贴近截图；缺失回落 `channelId`） |
| Q2  | 是否贴边       | **贴边**（与系统设置观感一致）                   |
| Q3  | 子面板切换方式 | **维持现有 `v-if` 重建**（零行为变化）           |

## 实施

1. `src/views/channel-quote/receive/modules/quote-setting/index.vue`
   - 引入公共组件 `VerticalTabLayout`（系统设置 / 资料管理同款），替换 `LCard + 横向 NTabs`；
   - `tabs` 结构 `{ key, label }` → `{ value, label }`（组件约定）；
   - 绑定用 `:value="activeTab"` + `@update:value="handleTabChange"`（**不用 `v-model`**：`activeTab` 是字面量联合类型，保留 `resolveTabKey` 校验，类型与行为都不变）；
   - 右栏插槽沿用原 5 个面板的 `v-if` 链（`FeeExtPanel` 的 `:channel-id="channelId"` 原样保留）；
   - 空态（无渠道上下文 → `NEmpty`）保留；根节点改为单层 `div` 包裹、说明注释置于根节点内部（规避「顶层注释 ⇒ 多根 Fragment ⇒ 布局层 Transition 收尾失败 ⇒ 离开本页后内容区永久空白」的既有坑）；
   - `defineOptions` name、`loadChannelContext` / `onActivated`、`?tab=xxx` 双向同步逻辑**零改动**；
   - 内层容器去掉 `LCard` 与 `gap-12px py-8px pl-10px`（贴边由布局层配置承担）。
2. `src/layouts/base-layout/index.vue` — `contentShowPadding` 排除列表新增 `'channel-quote_receive_quote-setting'`（内容区去掉默认 16px 外边距，左栏贴内容区左缘）。
3. `src/components/VerticalTabLayout/README.md` — 「已接入页面」表新增本页。

## 不做的事

不改 `VerticalTabLayout` 组件本体、5 个子面板、路由 / 菜单 / 权限 / i18n key；不接任何接口；不动 `LCard` / `Table` / `LButton` 本体。
