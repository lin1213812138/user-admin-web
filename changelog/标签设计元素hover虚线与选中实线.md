# 标签设计元素 hover 虚线与选中实线

## 需求

用户反馈画布元素选中态的 2px 蓝色虚线太粗，且未选中元素无任何可交互提示：

1. hover 未选中元素 → 显示虚线（比原选中虚线细）；
2. 选中（聚焦）元素 → 显示实线；
3. 缩放手柄仍只在选中态出现。

## 设计（brainstorming 确认）

三态形态：

| 状态           | 描边                   | 手柄                     |
| -------------- | ---------------------- | ------------------------ |
| 未选中 + hover | `1px dashed` 主题蓝    | 无                       |
| 选中           | `2px solid` 主题蓝     | 8 个缩放手柄（现状保留） |
| 拖拽/缩放中    | 实线不变（选中态延续） | 有                       |

- 继续用 `outline + outline-offset: 2px`，不碰布局、不影响元素内容渲染；
- hover 用纯 CSS `:hover` 伪类（`.element-item:not(.is-selected):hover`），零 JS 状态；
- hover 不渲染手柄（手柄 v-if 本就绑定选中态），避免未选中出现一排蓝方块；
- 颜色沿用 `var(--n-primary-color)`，暗色模式自动适配；
- 已知取舍：outline 宽度受画布 `scale(zoom)` 影响，缩小视觉上不足 1px、放大更粗，与原行为一致，先接受。

## 实施

仅改 `design-canvas.vue`：

- 元素容器 class 增加 `element-item` 基类（供 hover 选择器锚定）；
- 新增 `.element-item:not(.is-selected):hover { outline: 1px dashed ... }`；
- `.is-selected` 的 `2px dashed` 改 `2px solid`，其余（offset/z-index）不变。

eslint / oxlint / typecheck 全过。

## 手测清单

- 悬停未选中元素出现细虚线，移开消失；
- 点击选中后变实线 + 手柄；
- 拖拽/缩放过程中描边保持实线；
- 点空白取消选中后恢复无描边，再 hover 仍有虚线。

## 追代：缩放手柄优化（用户确认「先试一下」）

用户反馈选中态 8 个蓝色方块手柄「看起来很奇怪」。问题分析：8px 蓝底方块定位在盒边 `-4px`（中心贴元素边），而描边画在盒外 2~4px（`outline-offset: 2px` + 2px 线宽），手柄与描边线错位重叠，且方块偏大显笨重。

优化（经典设计器风格，Figma/PPT/hiprint 同款）：

- 手柄 8px 蓝底方块 → **6px 白底 + 1.5px 蓝边圆点**（`border-radius: 50%` + `box-sizing: border-box`），白底在描边与内容间形成分隔，视觉更轻；
- 对齐修正：描边中心线在盒外 3px，手柄定位 `-4px` → `-6px`，使 6px 圆点中心精确压在描边中心线上；
- 8 个位置与 cursor、缩放逻辑零改动；暗色模式下白底圆点对比清晰，无需特判。

仅改 `.resize-handle` / `.handle-*` 样式常量。oxlint 通过。

**三迭代（同日）**：白底蓝边圆点被用户否定（「不好看，没有和线重合」）——白底 6px 圆盘压 2px 蓝线会把线切断，1.5px 细边在画布缩放下发虚，观感如珠子浮在线外。终稿：**6px 实心主题色小方块（border-radius: 1px，无边框）**，与描边同色视觉连成一体、必然重合，保留 `-6px` 中心压线定位。教训：**压线手柄必须与线同色实心**——白底/描边款在细线（≤2px）上会切断线条连续性，scale 缩放下更明显。

**四迭代（同日，用户并行改动后的对齐修正 + 减细）**：用户并行把描边改为贴边（`outline-offset: 0`）+ 线宽 `calc(Npx / var(--canvas-zoom))` 补偿（`--canvas-zoom = store.zoom` 绑定在 viewport style），使缩放后线宽恒定——但手柄定位没同步，错位 2px。修正链：

- 错位根因：线中心在盒外 `N/2 ÷ zoom`，手柄中心必须 = 同值；
- 手柄定位公式：`calc(-3px - (N/2)px / var(--canvas-zoom, 1))`（N=线宽物理 px，手柄 6px 中心 = 定位+3px）；
- 用户最终要求线不加粗：选中线定稿 `calc(1px / zoom)`（与 hover 一致），手柄定位 `calc(-3px - 0.5px / zoom)`。

教训：**贴边 outline 的中心线随线宽/缩放变化，压线手柄定位必须用同一 zoom 补偿公式推导**；与用户并行改动同文件时先重读再改。

**五迭代（同日）**：用户反馈 4 个边中点手柄太小难点中 → 沿边方向拉长：上下（n/s）改 10×6px 横条（width: 10px，translateX 居中不受影响）、左右（e/w）改 6×10px 竖条，4 角保持 6px 方块；中心压线几何不变（拉长的方向与压线轴垂直）。
