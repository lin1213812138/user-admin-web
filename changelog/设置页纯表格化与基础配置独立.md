# 设置页纯表格化 + 基础配置独立成模块

> 日期：2026-09-17
> 触发语：用户截图设置页左侧 tab 栏 ——「全部都要使用纯表格的形式，初始化数据里面要把基础配置提出来成为一个单独的模块」

## 1. 需求与两次修正

**原始需求**：① 设置页子模块统一「纯表格」形态；② 初始化数据里的「基础配置」提出来成为设置页左侧独立 tab。

**修正 1（形态理解偏差）**：首轮把「纯表格」理解为「模块内左侧竖向 tab + 右侧一张表格」，用户纠正 ——「跟录单格式一样」，即 **页面本身就是一张表格，不要任何左侧分类 tab**。

**修正 2（越界拆分）**：跑偏时把「轨迹抓取配置」的 4 个子模块也拆成了设置页左侧 4 个 tab，用户纠正 ——「我应该只让你把基础配置提出来吧？其他的为什么也给我提出来了？」。**只有基础配置需要「提出来」**，轨迹抓取配置保持原样（`git restore` 已还原 `TraceCapture.vue`，设置页 tabs 撤销回 7 项）。

## 2. 最终形态（设置页 7 个 tab）

| tab          | 内容                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| 录单格式     | 纯表格（名称搜索 + 新增/编辑 Drawer）                                                    |
| 打印格式     | **纯表格**：4 个分类并入一张表，新增「分类」列 + 搜索区分类筛选；新增/复制表单内可选分类 |
| 导出格式     | **纯表格**：13 个分类并入一张表（分类列 + 筛选 + 表单内分类字段）                        |
| 运单号规则   | 纯表格                                                                                   |
| 轨迹抓取配置 | **保持原样未改**（组件内卡片 + 4 个子 tab + 表格）                                       |
| 基础配置     | **本次拆出的独立模块**，表单页（原「初始化数据」内部第 1 项）                            |
| 初始化数据   | **纯表格**：4 个分类并入一张表（分类列 + 筛选 + 表单内分类字段）                         |

## 3. 实施结果

- **数据层**：`print-format` / `export-format` 的 `fetchGetXxxTemplateList` 参数 `categoryId` 改可选（不传 = 全部分类）并支持 `keyword` 名称模糊；`mock.ts` 的 `mockGetInitDataList` 的 `category` 改可选；`Api.SystemManage.InitDataSearchParams.category` 改可选。
- **打印格式** `print-format/PrintFormat.vue`：纯表格（分类列 + 分类筛选 + 名称搜索；列 = 模板名称/分类/标签尺寸/是否默认/已生成标签/备注/最后编辑/编辑时间；行内 = 设计/查看/复制/设为默认）；Drawer 表单加「分类」下拉；cacheKey `setting-print-format-v2`。
- **导出格式** `export-format/ExportFormat.vue`：同上改造（分类列 + 筛选；顶部新增/批量删除/字段模板下载；行内编辑/下载）；Drawer 表单加「分类」；cacheKey `setting-export-format-v2`。
- **初始化数据** `init-data/InitData.vue`：重写为纯表格（中文名称/英文名称/分类/备注 + 分类筛选 + 中文名称搜索 + 批量/行内删除）；`init-data-form-drawer.vue` 表单加「分类」下拉、新增提交改用表单内分类；cacheKey `setting-init-data-v2`；`InitDataCategory.vue` 不再被引用。
- **基础配置**：`init-data/BasicInfoForm.vue` 迁移改名 `basic-config/BasicConfig.vue`；i18n `initData.info.*` → `basicConfig.info.*` + 新增 `basicConfig.title`；`initData.basicInfoTitle/basicInit/businessInit` 删除；i18n 三处（zh-cn / en-us / `app.d.ts`）同步，并新增各模块 `category`（分类）文案；设置页 tabs 与 componentMap 增加 `basic-config`（排 `init-data` 前）。
- **撤销/回退**：轨迹抓取配置的 4 tab 拆分已撤销（`TraceCapture.vue` 恢复原样、设置页 tabs 回 7 项、`componentMap` 回普通结构）；`VerticalTabLayout` 的子模块接入全部回退（现仅设置页外壳使用），组件 `README.md` 已接入表同步为 1 行。
