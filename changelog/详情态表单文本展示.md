# 详情态表单改为文本展示

## 需求

用户附用户管理「详情」抽屉截图："如果是查看详情，form 表单能不能直接显示为文本不显示这种禁用效果"。

现状：详情态给 `FormWrap` 传 `:disabled="isDetail"`，整张表单被禁用 → 所有控件灰显（截图里账号、站点、状态、日期等都是灰底）。

## 澄清确认

- 改法归属：**直接改封装的 `FormWrap` 组件**（用户："能不能直接改封装的 form 组件？"）；
- 空值统一显示 `-`；
- 密码字段保持脱敏（固定 `••••••`，不暴露明文）。

## 设计

- `FormWrap` 新增 `mode?: 'edit' | 'view'`（默认 `'edit'`），**与既有 `disabled` 正交**：`disabled` 语义不变（禁用控件、仍占位），`view` 是"只读文本展示"；属性面板单字段 `disabled`、InputFormat 的 `!isEditing` 等既有用法不受影响。
- view 态沿用同一套 `FormItemConfig` / 24 栅格 / `section` 分区 / label 位置（`labelPlacement`），**只把值区域换成文本**，不渲染任何控件。
- view 态 `mergedRules` 返回 `{}`：不参与校验，也不显示必填星号。
- 值映射（`viewText()`）：
  - input / textarea / number / date → 原值；
  - password → 固定 `••••••`；
  - select → 用 `options` 反查 label（`3` → 普通用户、`1` → 启用），查不到回退原值；
  - switch → `checkedText` / `uncheckedText`，缺省回退 i18n `common.enable` / `common.disable`；
  - checkbox → 选项 label 用 `、` 拼接；
  - image → 值是 URL（http/data/blob）时渲染 `NImage` 缩略图可点开预览，否则显示文件名文本（当前 model 存的就是文件名）；
  - color → 色块 + 色值；icon-picker → 复用 `IconRenderer` 渲染图标 + key；
  - custom（插槽）→ 仍走插槽，由业务自行决定；section → 原样保留。
- 空值判定沿用 `null / undefined / '' / 空数组`（**0 与 false 是有效值**），空值用灰色 `text-gray-400` 占位、正常值 `text-14px`。

## 改动文件

- `src/components/Form/index.vue`：新增 `mode` 属性 + `isView` / `isEmptyValue` / `isUrlValue` / `optionLabel` / `viewText` / `viewTextClass`；模板内 `NFormItem` 拆成 `isView` / `else` 两条分支，**原控件链整体挪进 `else` 分支、逻辑零改动**（缩进由 oxfmt 统一）。
- `views/system-manage/user|site|group|role/modules/*-operate-drawer.vue`：`:disabled="isDetail"` → `:mode="isDetail ? 'view' : 'edit'"`。
- `views/system-manage/setting/modules/print-format/PrintFormat.vue`：`:disabled="drawerMode === 'view'"` → `:mode="drawerMode === 'view' ? 'view' : 'edit'"`。
- `src/typings/components.d.ts`：因模板新增 `NImage`，unplugin-vue-components 自动补登记（生成产物，非手改）。

## 有意不动

- `views/system-manage/setting/modules/input-format/InputFormat.vue` 的 `:disabled="!isEditing"`：其下方紧邻的 `FieldMapping` 仍是禁用态组件，单独把上半部分表单改成文本会风格割裂（已写入设计并经用户确认）。
- i18n：无新增 key（`-` 是符号；switch 复用已存在的 `common.enable` / `common.disable`）。
