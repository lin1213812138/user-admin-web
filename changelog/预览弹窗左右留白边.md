# 预览弹窗左右留白边

## 问题

上一轮把 `NCard` 左右内边距清零后，弹窗内的预览纸张完全贴合弹窗边缘、没有任何留白，
观感上纸张贴边太紧，希望左右各留一点白边。

## 方案

`src/views/system-manage/print-design/modules/preview-modal.vue` 中，给 `NModal` 透传给 `NCard` 的
`content-style` 恢复一个适中的值：

```diff
- :content-style="{ paddingLeft: 0, paddingRight: 0 }"
+ :content-style="{ paddingLeft: '16px', paddingRight: '16px' }"
```

容器仍为 `w-fit`，宽度跟随纸张；`NCard content` 左右各 16px padding 给纸张留出白边，
上下内边距保留默认避免纸张贴 title/footer。

## 影响

- 弹窗宽度 = 纸张宽度 + 32px（左右各 16px 白边）。
- 纸张不再贴弹窗边缘，视觉更协调。
