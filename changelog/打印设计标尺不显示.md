# 打印设计标尺不显示

## 问题现象

打印设计画布左上角没有 mm 刻度标尺（`.hiprint_rul_wrapper` 水平 / 垂直标尺），纸张只剩网格，没有刻度尺。

## DOM 排查结论

元素本身存在且正常：`.hiprint-printPaper.design` 下确实有 `.hiprint_rul_wrapper`，内部 `.h_img` / `.v_img` 的 `src` 都是有效的 `data:image/svg+xml;base64,...`（hiprint 内置标尺 SVG）。纸张高度为 149mm、宽度 100mm，`overflow: visible`。

→ 元素与图片都在，**真正缺失的是让它定位 / 定尺寸的 CSS**。

## 根因

hiprint 的设计态样式（含 `.hiprint_rul_wrapper`、`.h_img`、`.v_img`）来自它的全局 CSS。本仓库只在**预览弹窗的 iframe** 里以 `?url` 形式引入了 `print-lock.css`（`preview-modal.vue` 的 `printLockCss`），设计画布本身从未加载过这份样式。

设计器里绝大多数视觉（元素位置、网格、选中框）都能正常显示，是因为 hiprint 在 JS 运行时直接以**行内样式**写在元素上；唯独标尺完全依赖 class 样式（绝对定位、负 margin、SVG 尺寸），拿不到样式就「塌缩」成不可见。

## 修复

`src/views/system-manage/print-design/index.vue` 的全局 `<style>` 中，显式补充标尺样式并限定在 `#hiprint-printTemplate` 作用域（预览在独立 iframe 里渲染，不会被本样式影响）：

```css
#hiprint-printTemplate .hiprint_rul_wrapper {
  position: absolute;
  height: 100%;
  width: 100%;
  overflow: hidden;
  pointer-events: none;
  margin: -16px;
  padding-left: 15px;
  padding-top: 15px;
  box-sizing: content-box !important;
  border-top: 1px solid rgb(201, 190, 190);
  border-left: 1px solid rgb(201, 190, 190);
}
#hiprint-printTemplate .hiprint_rul_wrapper .h_img {
  position: absolute;
  top: 0;
  left: 15px;
  width: 400mm;
  height: 15px;
  max-width: none;
}
#hiprint-printTemplate .hiprint_rul_wrapper .v_img {
  width: 400mm;
  max-width: none;
  transform: rotate(90deg);
  transform-origin: 0 100%;
  height: 15px;
  position: absolute;
  top: -2px;
  left: 0;
}
```

## 二次问题：放大才可见，100% 时被裁剪

### 现象

标尺 SVG 与 DOM 均存在，100% 缩放下画布左上角看不到标尺；放大到 200% 后标尺出现。

### 根因

`.hiprint_rul_wrapper` 通过 `margin: -16px` 伸出 `.hiprint-printPaper` 左上角外侧，而设计画布用 `NScrollbar` 包裹 `#hiprint-printTemplate`。负 margin 区域落在 `#hiprint-printTemplate` 的 border box 之外、`NScrollbar` 的 `overflow: hidden` 容器之内，被滚动容器裁剪掉了。放大时由于渲染/滚动区域变化，标尺才进入可视范围。

### 补充修复

`src/views/system-manage/print-design/index.vue` 全局 `<style>` 中，给设计容器 `#hiprint-printTemplate` 增加 `position: relative; padding: 16px;`，让标尺负 margin 伸出的部分落在容器自身的 padding 区域内（仍属于 content box，不会被 NScrollbar 裁剪）：

```css
#hiprint-printTemplate {
  position: relative;
  padding: 16px;
}
```

同时保留原 `.hiprint_rul_wrapper` / `.h_img` / `.v_img` 样式不变。

## 验证

刷新设计页，100% 缩放下画布左上角应出现水平与垂直 mm 刻度尺；放大/缩小、切换网格、拖拽元素后标尺仍正常显示；标尺只在设计态显示，预览弹窗不受影响。
