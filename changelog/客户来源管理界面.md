# 客户来源管理界面（客户管理 → 客户来源）

> 日期：2026-09-20
> 状态：已实施
> 用户提供 `tms-user` `CustomerSourceSchema` 与列表截图，要求在「客户管理」下新增客户来源管理页。

## 现状（已查 tms-user 源码）

- 路由：`/customer-source/query|get|create|update`（POST）。**无 delete 路由** → 前端不提供删除（与截图操作列只有「编辑」吻合）。
- `query`：`getCtxQueryParams` 合并 `ctx.request.body`，沿用 customer-level 的 POST body `{ page, size, keyword, where }`；后端固定 `keywordFields: ['name']`、`sort: { order: 1 }`。
- `create`/`update`：`uniqField: 'name'`，名称必填且唯一；**update 必须随行回传 name**（避免写入 `nameUpdate` 脏字段）。
- 字段：`name`(必填)、`order`(排序 默认0)、`status`(0-禁用/1-启用 默认1)、`note`(备注)、`creatorId`/`creator`、`createDate`/`updateDate`(毫秒时间戳)。

## 设计决策

- 完全复用客户等级页范式（`useVxeTable` + `Table` + `NFormWrap` + `GroupDrawer`），与用户「跟客户等级一样做就行了」一致。
- 列表列**严格按截图**：排序 / 名称(`type:'detail'`) / 备注 / 状态(`type:'status'`) / 操作（编辑 + 行内启用·停用切换，**无删除**）。
- 搜索：名称关键字（单输入框 + 查询/重置）。
- 工具栏：新增 + 导出。**导出改用项目已封装的 `TableExportAction`**（`src/components/Export/table-export-action.vue`，自带按钮 + 字段勾选弹窗 + xlsx），传入 `:columns="columnConfigs"` / `:data="data"` / `:fetch-all="fetchAllSources"` / `:filename`，并用 `v-auth="'system:customerSource:export'"` 控制按钮显隐；不再手写 CSV。同步将参照页 `customer-level` 的手写 CSV 导出也替换为该组件（保持一致）。
- 抽屉表单：名称(必填) / 排序 / 备注(textarea) / 状态(select，启用=1/停用=0)。
- i18n 命名空间用 `customerSourceManage`（加 Manage 后缀）：因 `customer.customerSource` 扁平键已被客户列表页占用（字典下拉 `sourcePlaceholder` 等）。
- 路由由 `pnpm gen-route` 自动生成（`routes.ts`/`imports.ts`/`transform.ts`/`elegant-router.d.ts` 均含新 key），生成后再手工补 `meta`（icon/order:3/permission/`keepAlive`）。
