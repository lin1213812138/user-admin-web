# 字段映射：卡片头部加各模块「一键全选」按钮

日期：2026-09-07
涉及文件：`src/views/system-manage/setting/components/FieldMapping.vue`、`src/views/system-manage/setting/modules/InputFormat.vue`

## 背景 / 需求

录单格式页「字段映射」卡片里，每个模块（运单信息 / 收件人信息 / 发件人信息 / 物品信息 / 子件信息）都有十几个复选框，逐项勾选很慢，需要**每个模块一个一键全选**。

## 方案选型

确认过的三种位置（用户最终选 B）：

- A 分组标题后面放三态全选 Checkbox —— 用户否决（位置不对）。
- **B 卡片头部（「字段映射」标题同一行右侧）放一排按钮，每个模块一个，点击切换该模块全选 / 清空** ✅
- C 每行字段末尾放全选 —— 未选。

按钮而非 Checkbox 的原因：头部是模块级快捷操作区，按钮文案带模块名（「全选 运单信息」）比抽象勾选框更直观，且不占分组行宽度。

## 实现

`FieldMapping.vue`

- 新增 `disabled` prop（默认 `false`），同时作用于字段 `NCheckbox` 与头部全选按钮（原来非编辑态也能勾选字段，属于顺带修的小问题）。
- 新增五个纯函数（无额外状态，全部由 `modelValue` 推导，切格式/保存后自动一致）：
  - `checkedCountOf(group)`：该组已勾选字段数（只统计配置里存在的 key）。
  - `isGroupAllChecked(group)`：全选判定；**空分组视为未全选**，避免出现永远高亮却点不动的按钮。
  - `isGroupIndeterminate(group)`：勾了部分字段。
  - `groupButtonType(group)`：全选 → `primary`，半选 → `tertiary`，未选 → `default`（三态兼作状态反馈）。
  - `toggleGroup(group)`：已全选 → 写 `[]`；未全选 / 半选 → 写 `group.fields.map(f => f.key)`。只替换该组 key，其余组不受影响。
- `toggleField` 增加判重（`current.includes(field)`），避免后端数据存在重复 key 时被写入两次。
- 卡片 `#header-extra` 用 `NSpace wrap` 渲染按钮组：`size="tiny"`、文案 `` `${g.title} ${已选数}/${总数}` ``（如「运单信息 2/7」）、`title` 提示为点击后的动作（`$t('common.selectAll')` / `$t('common.unselectAll')`，复用既有 key，zh/en 无需改动）、空分组按钮 `disabled`。
  - 不用「全选 + 模块名」而用「模块名 + 计数」的原因：① 全选态点下去是清空，固定文案会与动作相反；② 计数天然区分未选/半选/全选；③ 窄容器下 5 个按钮不易折行顶高卡片头部。
- `fill` / 非 `fill` 两段模板保持原结构（既有重复，本次未做大重构），两段都补了 `:disabled`。

`InputFormat.vue`

- 传 `:disabled="!isEditing"`，非编辑态下字段与全选按钮一起禁用。

## 交互规则

| 当前状态       | 按钮外观        | 点击后             |
| -------------- | --------------- | ------------------ |
| 未选 0/7       | default         | 勾选该模块全部字段 |
| 半选 2/7       | tertiary        | 勾选该模块全部字段 |
| 全选 7/7       | primary         | 清空该模块         |
| 只读（非编辑） | 同上但 disabled | 无响应             |
| 空分组         | disabled        | 无响应             |

## 代码评审（requesting-code-review，2026-09-07）

评审结论 Needs work，已修：

- 全选态按钮文案仍是「全选」但点击是清空 → 改为三态 type + 计数 + tooltip 提示动作。
- 半选无反馈 → 新增 `isGroupIndeterminate`，`tertiary` 态区分。
- 空分组按钮可点 → `:disabled="disabled || g.fields.length === 0"`。
- `toggleField` 未判重 → 追加前先 `includes`。
- 头部 5 个长文案按钮窄容器折行 → 文案精简为「模块名 + 计数」、`size="tiny"`、`justify-end` + `wrap`。
