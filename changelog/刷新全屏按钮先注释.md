# 刷新全屏按钮先注释

- **日期**：2026-09-16
- **用户指令**：截图红框标标签栏右侧前两个图标（刷新 / 全屏九宫格）：「这两个可以先注释一下」

## 背景

上一轮刚在标签栏右侧加了主题模式切换（`ThemeSchemaSwitch`）与主题配置入口（`ThemeButton`），右侧操作区变为「刷新 → 全屏 → 主题模式 → 主题配置」。用户要求把**刷新与全屏**两个按钮先注释下线，只保留主题类两个按钮。

## 改动（仅 `global-tab/index.vue`，注释不删码）

模板注释引发三级 unused 连锁（同文件串行处理）：

1. 模板：`ReloadButton` + `FullScreen` 两行包进单个 HTML 注释块（格式满足 `vue/html-comment-content-newline`：`<!--` 后、`-->` 前须换行，说明文字与代码同块）；
2. `async function refresh()` 注释（失去唯一引用）；
3. `const appStore = useAppStore();` 注释（refresh 注释后无引用）；
4. `import { useAppStore } from '@/store/modules/app';` 注释（声明注释后无引用）。

各处注释均标注「恢复按钮时一并取消注释」。

## 不改项

- `ThemeSchemaSwitch` / `ThemeButton` 保留；`useThemeStore` / `useTabStore` 仍被使用不动；`GlobalContent` 对 `appStore.reloadFlag` 的使用不受影响（app store 本身仍在，只是本文件不再引用）。
