# 侧边栏底部用户区主题适配

## 用户反馈

用户截图红框标侧边栏底部用户区（`超级管理员`）："这一块没有自适应主题"。

## 问题定位

- 侧边栏底部用户区在 `src/layouts/modules/global-sider/index.vue`（header 下线后用户区从 `user-avatar.vue` 移至侧栏底部）。
- 截图为**浅色主题 + inverted 深色侧栏**（内容区白色、侧栏深色）。
- `DarkModeContainer` 在 `inverted` 时强制 `text-#1f1f1f`（深色文字），用于让菜单文字在深色背景上可见；但底部用户区里的 `UserAvatar` → `ButtonIcon` 是 Naive UI 的 quaternary `NButton`，其文字颜色由 Naive 浅色主题的内联 CSS 变量（`--n-text-color`）控制，同为深色 → **深色文字落在深色侧栏背景上几乎不可见**。
- 分隔线用的是 `border-gray-200 dark:border-gray-700`：浅色主题下解析为 `gray-200`（亮灰），在深色侧栏上表现为一条突兀的亮线。

## 修复方案

只改 `global-sider/index.vue`，不动公共组件（`DarkModeContainer` / `user-avatar.vue` / `button-icon.vue`）：

1. 底部用户区按 `darkMenu`（= 浅色主题且侧栏 inverted）动态切换样式：
   - inverted：新增 `sider-footer--inverted` 类 + 分隔线 `border-white/10`（深色背景上的弱分隔线）。
   - 其他情况保持现状 `border-gray-200 dark:border-gray-700`。
2. `.sider-footer--inverted` 设浅色文字 `rgba(255, 255, 255, 0.82)`；因 `NButton` 通过内联 CSS 变量设置颜色，普通 class 无法覆盖，用 scoped `:deep(.n-button)` + `color !important` 强制继承浅色（图标 `SvgIcon` 走 `currentColor`、用户名 `span` 走继承，均随之生效）。

## 影响面

- 仅侧边栏底部用户区，浅色主题 inverted 侧栏下生效；深色主题（`darkMenu` 为 false）与原逻辑完全一致，零回归。

## 验证

- `read_lints` 无诊断；视觉效果待用户复核。
