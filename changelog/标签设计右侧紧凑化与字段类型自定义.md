# 标签设计：右侧面板紧凑化 + 业务字段拖入类型自定义

> 日期：2026-09-12

## 需求

1. 右侧属性面板「字体和样式都小一点」——表单控件与文案偏大。
2. 选中拖入的业务字段元素，「字段类型」清一色显示「长文本」：用户要求「每个里面加个类型，设置的是什么类型就显示什么类型，不要固定」。

## 问题定位

- 需求 1：`FormWrap`（src/components/Form/index.vue）未透传 `size`，naive `NForm` 默认 medium（控件高 32px、label 14px）。
- 需求 2：`design-canvas.vue` 的 `onDrop` 业务字段分支**硬编码** `type: 'longText'`（原注释「业务字段统一用长文本」），`FieldDef` 上没有类型字段。

## 方案（用户确认：类型机制可配置，不固定）

### 右侧紧凑化

- `FormWrap` 新增可选 prop `size?: 'small' | 'medium' | 'large'`（默认 `medium`，透传 `NForm :size`，naive size 机制让内部 NInput/NSelect/NInputNumber/NSwitch/NColorPicker 统一变小），其它页面零影响；
- `property-panel.vue` 三个 `NFormWrap` 传 `size="small"`；
- scoped CSS 将面板内 `.n-form-item-label` 字号压到 12px（naive small 档 label 仍是 14px）。

### 字段类型自定义

- `FieldDef`（constant.ts）新增 `elementType?: ElementType`，「设置什么类型拖出来就是什么类型」，缺省 `text`；
- `BUSINESS_FIELDS` 按字段语义设置：`goodsName → longText`（名称可能换行），其余（单号/SKU/数量/批次/仓库/日期）→ `text`，后续随时可调（如 sku 改 barcode）；
- `field-panel.vue` 拖拽 payload 带上 `elementType`；
- `design-canvas.vue`：新增 `FIELD_TYPE_LABEL_KEYS` 映射（text/longText/barcode/qrcode → 对应 `basic*` 文案 key），`onDrop` 按字段定义类型创建；不在映射内的类型（image/rect/线条等无数据绑定语义）回退 `text`。

## 踩坑

- `(FIELD_ELEMENT_TYPES as string[]).includes(payload.elementType)`：`elementType` 可能为 `undefined`，`includes` 参数不接受 → 补 `?? ''` 兜底（TS2345）。

## 验证

- `pnpm typecheck` 通过；label-designer 目录与 Form 组件 lint 0 错误。
