# 字段映射卡片头部「没有左右布局」定位

日期：2026-09-17
涉及文件：`src/views/system-manage/setting/components/FieldMapping.vue`

## 现象

用户贴录单格式抽屉里的「字段映射」卡片截图，红框圈出**卡片头部一行**（左侧标题「字段映射」+ 右侧 5 个模块按钮：「运单信息 2/7 / 收件人信息 0/4 / 发件人信息 0/3 / 物品信息 0/4 / 子单信息 2/3」），问「这个为什么没有左右布局呢」。

即：标题与按钮组**全挤在左侧**，按钮组后面还剩约 400px 空白 —— 没有呈现「标题在左、按钮组在卡片最右」的两端分布。

（卡片**内容区**的分组行本身是左右布局：左 `w-180px` 分组标题 + 右侧字段网格，本次不涉及。）

## 定位

1. naive-ui `NCard` 头部默认结构（`node_modules/naive-ui/es/card/src/styles/index.cssr.mjs` L71-93）：

   ```
   .n-card-header      { display: flex; align-items: center; }
   .n-card-header__main  { flex: 1; min-width: 0; }   /* 吃满剩余宽度 */
   .n-card-header__extra { display: flex; align-items: center; }
   ```

   `__main` 默认 `flex: 1 1 0` 会撑满剩余宽度，从而把 `__header-extra`（按钮组）**顶到卡片最右** —— 这才是 naive 默认的「左右布局」。

2. 本组件在 `FieldMapping.vue` L212-219 加了一段 scoped 覆盖：

   ```css
   :deep(.n-card-header__main) {
     flex: none !important;
   }
   ```

   来由：2026-09-17「系统设置右侧空白排查」时，设置页改左右布局后右侧内容区只有 886px，标题被 5 个按钮组挤成 **0 宽竖排**，故改成「按内容宽、不参与挤压」。

3. 副作用：`flex: none` 同时**去掉了「撑满剩余宽度」的能力** → `__main` 只占标题内容宽，`__header-extra` 紧随其后，行尾留白 → 截图里「都靠左」的效果。

4. 该覆盖的原始场景**现已不存在**：`FieldMapping` 目前只在「录单格式」抽屉（`input-format-drawer.vue`，`width="70%"`，约 1300px）里使用，控件总宽约 640px，根本不会发生挤压，只剩副作用。

## 候选修法（待用户确认，未改任何代码）

| 方案 | 做法                                                                                               | 宽容器                                   | 窄容器                                          |
| ---- | -------------------------------------------------------------------------------------------------- | ---------------------------------------- | ----------------------------------------------- |
| A ✅ | `flex: 1 1 auto !important; min-width: max-content !important`（保留撑满能力、禁止压到内容宽以下） | 标题块撑开，按钮组回卡片最右（左右布局） | 标题保持整行不竖排，按钮组靠 `NSpace wrap` 换行 |
| B    | 保留 `flex: none`，改给 `__header-extra` 加 `margin-left: auto`                                    | 按钮组回最右                             | 挤压压力落在 extra 上（按钮换行/溢出风险）      |
| C    | 直接删除这段覆盖                                                                                   | 恢复 naive 默认左右布局                  | 回到「标题 0 宽竖排」隐患                       |
| D    | 结构改法：模块按钮从头部挪成**卡片内左侧竖排导航 + 右侧只显示当前模块字段**                        | 变更交互结构，需重新设计                 | —                                               |

## 决策与实施（用户确认选 A ✅）

`FieldMapping.vue` 样式块改为：

```css
:deep(.n-card-header__main) {
  flex: 1 1 auto !important;
  min-width: max-content !important;
}
```

- `flex: 1 1 auto`：保留「撑满剩余宽度」的能力 → 宽容器里标题块撑开，按钮组被顶到卡片最右（左右两端分布）。
- `min-width: max-content`：窄容器里标题最多压到自身内容宽（不竖排、不换行），按钮组靠 `NSpace wrap` 换行。
- 仍必须 `!important`：naive 原生规则特异性 0,3,0 高于 `:deep` 编译出的 0,2,0。
