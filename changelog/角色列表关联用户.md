# 角色列表加个关联用户

用户需求："角色列表加个关联用户"。

## 问题定位

- 角色列表页 `src/views/system-manage/role/index.vue`（useVxeTable + Table，操作列已有编辑/权限/删除）。
- 后端 tms-user `/user/query`（`lib/services/user.js` → `queryCommon`）将 `where` 原样透传为 MongoDB 过滤条件，`User.roleIds` 为数组字段，`where: { roleIds: '<roleId>' }` 命中数组包含该值的用户，**后端零改动**。
- 站点列表已有同类"关联用户"模式（`RelationModal` 公共组件 + 空数据探查提示），直接复用。

## 实施内容

1. `src/service/api/role/index.ts`：新增 `fetchGetRoleUserList({ page, size, roleId })` → POST `/user/query`，`where: { roleIds: roleId }`，返回 `Api.SystemManage.UserList`（flat 请求，调用方解包 `{ data, error }`）。
2. `src/typings/api/system-manage.d.ts`：`UserSearchParams.where` 补充 `roleIds?: string`。
3. `role/index.vue`：
   - 「角色类型」后新增「关联用户」列（宽 90、居中），渲染「查看」文字按钮。
   - 点击 `openRelationModal(row)`：先探查 `page:1,size:1`，无数据时 `window.$notification` 提示 `common.noData` 不弹窗。
   - 复用 `@/components/common/relation-modal.vue`，列 = 姓名/账号/所属站点/状态（与站点页关联用户弹窗一致）。
   - `cacheKey` 升级为 `system-manage-role-v3`（新增列后避免旧列配置缓存残留）。
4. i18n：`page.manage.role.relationUser`（zh：关联用户 / en：Related Users），并同步 `src/typings/app.d.ts` Schema（否则 vue-tsc TS2353）。
5. 「查看」按钮文案复用 `page.manage.site.view`。
