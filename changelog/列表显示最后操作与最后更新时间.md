# 录单格式列表新增「最后操作 / 最后更新时间」两列

> 日期：2026-09-17
> 触发语：「列表显示最后操作，以及最后更新时间」（附列表截图，红框圈出列头区域）

## 1. 背景

录单格式列表（`views/system-manage/setting/modules/input-format/InputFormat.vue`，2026-09-17 已接真实接口）当前列为：格式名称 / 客户可用 / 是否默认 / 排序 / 备注 / 状态 / 操作。用户要求补上「最后操作」「最后更新时间」。

后端 `OrderTemplate` 文档里对应字段已存在且由中间件自动维护：`updateBy`（修改人名称，create 时也写入创建人）、`updateDate`（毫秒时间戳）。

## 2. 决策（用户两项确认）

| 项       | 结论                                                       |
| -------- | ---------------------------------------------------------- |
| 列位置   | **放在最后面**（状态之后、操作列之前，即表格最右）         |
| 时间格式 | **`YYYY-MM-DD HH:mm:ss`** 带秒（对齐系统日志页），列宽 170 |

## 3. 实施

| 文件                                                       | 改动                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.../input-format/InputFormat.vue`                         | ① `import dayjs`；② 列定义在「状态」之后追加两列：`updateBy`「最后操作」（width 100）+ `updateDate`「最后更新时间」（width 170），两列均 `fixed: 'right'`、`align: 'center'`、`sortable: false`（操作列本身 `fixed="right"` 且由 Table 内部最后渲染，故固定右列按数组顺序排列 = 状态 → 最后操作 → 最后更新时间 → 操作，真正落在最右）；③ 新增 `formatDateTime(ts?)`（毫秒时间戳 → `YYYY-MM-DD HH:mm:ss`，空值 `--`）；④ 模板加 `#updateBy`（空值 `--`）与 `#updateDate` 两个插槽；⑤ cacheKey `setting-input-format-v2` → **`-v3`** |
| `locales/langs/zh-cn.ts` / `en-us.ts` / `typings/app.d.ts` | 三处同步新增 `setting.inputFormat.lastOperation`（最后操作 / Last Operator）、`lastUpdateTime`（最后更新时间 / Last Update Time）                                                                                                                                                                                                                                                                                                                                                                                                  |

**为什么要升 cacheKey**：`useVxeTable` 应用本地列配置时是 `cached.map(saved => ...)`（**以缓存数组为准**，默认列只用来给同 key 覆盖兜底），默认里新增的列若不在缓存数组中就**不会渲染**；升版本可确保两列一定出现（代价：已保存的列宽/顺序/显隐重置为默认）。
