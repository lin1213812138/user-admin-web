# 标签设计数据预览栏

> 日期：2026-09-12
> 模块：`src/views/system-manage/label-designer/**`、`src/locales/langs/*`、`src/typings/app.d.ts`

## 需求

属性面板右侧再加一栏「数据预览」：元素可配置**标题名称**，并通过**关联标题**开关控制标题是否显示；另含字段类型（只读）、占位文本、底部绑定信息条（参考截图）。

用户随后指出：该栏与现有「内容与绑定」卡重复 → **删除「内容与绑定」卡，其字段（文本/编码值/图片地址 + 绑定字段）全部并入「数据预览」**。

## 数据模型（types.ts）

新增公共接口 `DataPreviewExtras`，由 `TextOptions` / `BarcodeOptions` / `QrcodeOptions` 继承（image/rect/线条无标题能力）：

```ts
title?: string;       // 标题名称
showTitle?: boolean;  // 关联标题开关（默认关）
placeholder?: string; // 占位文本
```

均为可选字段，旧模板 designJson 完全兼容。

## 渲染（画布与打印同步，所见即所得）

- `element-renderer.vue`（画布）与 `render-element-html.ts`（预览/打印 HTML）实现同一结构：`showTitle` 开且 `title` 非空时，元素内部改为 **flex 上下结构**——标题行在上（8pt、居中、黑字、不换行），内容区 `flex:1` 占剩余高度。
- 打印 HTML 用 `wrapContent()` 统一包裹：无标题时保持原 DOM；有标题时套 flex 列容器。

## 占位文本生效规则（render-utils.ts）

`resolveDisplayText` 回退链调整为：**示例内容（text/value/src）→ 占位文本 placeholder → `{{字段}}`**。绑定了字段但没填示例值时，显示占位文本而不是 `{{item.no}}`。

## 属性面板（property-panel.vue）

- 删除「内容与绑定」`NCard` 与 `contentItems`。
- 新增「数据预览」`NCard`：`NCollapse` 可折叠（箭头在右、默认展开），`NFormWrap` `label-placement="left"`、全部 `span: 24`（贴合截图的左标签右控件单列布局），沿用 `grid-x-gap=8` 防窄面板溢出。
- 字段顺序（文本/条码/二维码）：标题名称 → 字段类型（disabled 只读下拉，展示当前元素类型文案）→ 关联标题（switch）→ 占位文本 → 文本/编码值 → 绑定字段；图片类型只有：字段类型 → 图片地址 → 绑定字段。
- 「标题名称」用 `type: 'custom'` 插槽渲染 `NInput`，输入框 suffix 放 `NTooltip` 问号说明。
- `fieldTypeDisplay` 是 **UI-only key**：进 model 用于回显，提交时随 `x/y/width/height` 一起被 `reservedKeys` 过滤，不会写进元素 options（同时规避 eslint `no-dynamic-delete`，用 `Object.fromEntries + filter` 代替 delete）。
- 底部灰条 `fieldBindText`：`字段: {标题或字段名} ({field})`，未绑字段显示「未绑定」。
- 显示条件：选中元素类型 ∈ text/longText/image/barcode/qrcode；rect/线条不显示。

## i18n

新增 key（zh-cn / en-us / `typings/app.d.ts` 三处同步）：`dataPreview`、`propTitleName`、`titleNameTip`、`propFieldType`、`propLinkTitle`、`propPlaceholder`、`placeholderInputTip`、`fieldTypeText/LongText/Barcode/Qrcode/Image`、`fieldLabel`、`fieldUnbound`。

## 验证

`pnpm typecheck` 通过；eslint 无错误（修复过程：`UI_ONLY_KEYS` 声明前移到 watch 之前、动态 delete 改 filter、删除残留的 `contentItems`）。

## 追加（同日）：三张卡统一折叠式

用户要求把全部卡片做成展开收起式：「位置与尺寸」「样式」改为与「数据预览」一致的 `NCard + NCollapse + NCollapseItem` 结构（箭头在右、默认展开）。两张卡的标题文案顺带从硬编码中文改为 i18n：新增 `sectionGeo`（位置与尺寸 / Position & Size）、`sectionStyle`（样式 / Style），zh-cn / en-us / `typings/app.d.ts` 同步。

## 追加（同日）：底部信息条显示字段中文名

用户指出信息条 `字段: orderNo (orderNo)` 的第一个位置应显示字段**名称**而非 key。原实现误用了「标题名称」做回退。修复：

- 业务字段清单（FieldDef / BUSINESS_FIELDS）从 `field-panel.vue` 抽到 `constant.ts` 共享，field-panel 默认值改为引用 `BUSINESS_FIELDS`（props.fields 覆盖能力保留）。
- `fieldBindText` 改为 `字段: {getFieldLabel(field) || field} ({field})`，例如 `字段: 单号 (orderNo)`；标题名称不再参与该信息条。

## 追加（同日）：每个业务字段自带标题

用户澄清「需要标题」是指**每个业务字段都有自己的标题**（不是单独加一个「标题」字段）：

- `FieldDef` 新增 `title?: string`（字段标题，缺省回退 label），`BUSINESS_FIELDS` 每项显式配置（当前与 label 相同，可逐个调整文案）。
- 拖入链路打通：字段面板 dragstart 带 `title: f.title || f.label` → `DropPayload.title` → `ElementSeed.title` → `defaultOptionsFor` 预填 `options.title` 并自动 `showTitle: true`（基础元素拖入仍不带标题）。
- 曾经误加的 `{ key: 'title', label: '标题' }` 字段条目已撤销。

## 追加（同日）：标题可配置样式

用户反馈标题太小且需要可配置。改动：

- `DataPreviewExtras` 新增 `titleFontSize / titleColor / titleFontWeight / titleAlign`（可选，渲染层回退默认 10pt / #000000 / normal / center）。
- 默认标题字号 8pt → **10pt**；新拖入的文本/条码/二维码元素在 `defaultOptionsFor` 带全套标题样式默认值。
- 「样式」卡最前面新增标题样式组：标题字号 / 标题颜色 / 标题字重 / 标题对齐（四类元素共用，span 12 两行排布），i18n key `propTitleFontSize/propTitleColor/propTitleWeight/propTitleAlign` 三处同步。
- 画布（element-renderer.vue `titleStyle` computed）与打印 HTML（render-element-html.ts 内联样式）同步消费；标题行原 `text-center text-black` class 由样式值接管。
- 注意：`element-renderer.vue` 期间有用户侧改动（新增 baselineAlign 基线对齐），本次只改标题行，未触碰该逻辑。
