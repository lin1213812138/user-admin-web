# 标签设计器目录整理（modules 按职责拆分）

> 日期：2026-09-14　模块：`src/views/system-manage/label-designer`

## 背景

`label-designer/modules/` 下 16 个文件平铺混放，类型定义、常量、渲染引擎、画布交互、面板 UI 交织在一起，阅读和新增文件时难以定位归属。用户要求分门别类。

## 方案（已与用户确认）

- **方案 A：按职责分 4 组**（用户选定）；
- **只移动、不重命名**（用户选定），文件名全部保持原样，changelog 可追溯；
- `index.vue` 留在 `label-designer/` 根下不动（elegant-router 路由入口依赖它）；
- `modules/` 目录名保留——安全先例：同项目 `setting/modules/` 下已有嵌套子目录（如 `input-format/InputFormat.vue`）且未生成任何路由；
- **零逻辑改动**，仅文件移动 + 相对 import 路径改写。

目标结构：

```
modules/
├── core/      # 类型/常量/元素清单/序列化（无 UI、无副作用）
│              types.ts  constant.ts  basic-elements.ts  export-format.ts
├── render/    # 无 UI 渲染（画布与打印共用）
│              barcode.ts  render-utils.ts  render-element-html.ts
├── canvas/    # 画布容器、元素渲染组件、交互、拖拽幽灵
│              design-canvas.vue  element-renderer.vue  use-canvas-interaction.ts  drag-ghost.ts
└── panels/    # 面板与弹窗 UI
               tool-bar.vue  field-panel.vue  property-panel.vue  preview-modal.vue  shortcut-help.vue
```

## 实施方式

用 `git mv` 逐批移动（保留文件历史），再用替换工具改写上述 29 条 import；不改任何其他代码。

## 验证

1. `git status` / `git diff --stat`：确认改动只有文件移动 + 29 条 import 行；
2. `pnpm typecheck` 通过；
3. **`pnpm gen-route` 后 `git status`**：`src/router/elegant/**`、`src/typings/elegant-router.d.ts` 零 diff（确认子目录未产生新路由，这是本次最大风险点）；
4. `pnpm dev` 打开 `/system-manage/label-designer` 目检：字段/基础元素拖入、选中拖动缩放、属性面板、保存、预览；
5. `pnpm lint`。

## 实施记录（2026-09-14，已完成）

1. `git mv` 移动 16 个文件（全部 R 状态、文件历史保留），29 条 import 改写完成，`git diff --stat` 改动面与设计清单完全一致；
2. `pnpm typecheck` 通过（vue-tsc 无错误）；
3. **路由安全双重确认**：
   - 源码级：`@elegant-router/core` 的 `pagePatterns = ["**/index.vue", "**/[[]*[]].vue"]`——只有 `index.vue` 与动态参数页才生成路由，`modules/` 下任意层级的 .vue 结构上不可能被扫成路由；
   - 实测级：临时启动 `pnpm dev`（`[elegant-router] watcher ready`），`git status` 对 `src/router` / `src/typings` 零 diff；
4. 产出模块 `README.md`（使用方式、目录结构、关键约定、扩展指南、可维护性说明）；
5. 备注：`panels/property-panel.vue` 中用户先前未提交的 3 处文案 key 改动（`propText`/`propValue` → `propTestData`）原样保留，未做任何回退；
6. 环境备注：`pnpm gen-route` 因 `node_modules/.bin/sa.cmd` 旧 shim 指向已删除的 `bin.ts` 报 `ERR_MODULE_NOT_FOUND`（与本次改动无关）；路由生成改用 `pnpm dev` 触发（同一条链路），未修 shim。

## 回退预案

`git reset && git checkout -- . && git clean -fd src/views/system-manage/label-designer/modules`
（`git clean` 仅清理本次新增的 4 个子目录，执行前先 `git status` 确认无未跟踪的既有文件被误删）
