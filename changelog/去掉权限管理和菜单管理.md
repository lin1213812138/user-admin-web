# 去掉权限管理和菜单管理

## 需求

用户：「去掉权限管理和菜单管理」。

## 定位

侧边栏「权限管理」一级菜单（`/permission-manage`）只有一个子项「菜单管理」（`/permission-manage/menu`），两者属同一模块，整体移除。

涉及代码：

| 文件                                                      | 说明                                                                                                       |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `src/views/permission-manage/`                            | 菜单管理页面（index.vue + modules/menu-operate-drawer.vue），整目录删除                                    |
| `src/service/api/menu/`                                   | 菜单 CRUD service，仅被上述页面使用                                                                        |
| `src/service/api/index.ts`                                | 删 `export * from './menu'`                                                                                |
| `src/service/api/mock.ts`                                 | 清理 mockMenuList / mockCreateMenu / mockUpdateMenu / mockDeleteMenu 及 menus 数据                         |
| `src/typings/api/system-manage.d.ts`                      | 删 Menu / MenuType / MenuList / MenuSearchParams / MenuCreateParams / MenuUpdateParams（已确认无其他引用） |
| `src/locales/langs/zh-cn.ts`、`en-us.ts`                  | 删 route 段 `permission-manage` / `permission-manage_menu`、page.manage 段 `menu` 分支                     |
| `src/constants/menu-permissions.ts`                       | MENU_PERMISSION_TREE 删「权限管理 → 菜单管理」分组及未用的 `menu = op('menu')`                             |
| `src/router/elegant/*`、`src/typings/elegant-router.d.ts` | 删目录后 `pnpm gen-route` 自动重生成                                                                       |

## 方案

- 路由为 static 模式（`VITE_AUTH_ROUTE_MODE=static`），菜单由前端目录自动生成，删除 `views/permission-manage/` 并重新生成路由即可让菜单消失，无需改后端。
- **保留**：角色管理（`system-manage/role`）、用户管理中的分配角色、`menu-permissions.ts` 其余配置（角色管理「分配权限」抽屉仍使用）。
- 后端已存角色 auths 中如含菜单管理相关码，回显时找不到对应行会被自然忽略，无副作用。

## 验证

- `pnpm typecheck` 0 error；`pnpm lint` 0 error（仅 link.vue 2 条既有 warning，与本任务无关）；`pnpm fmt` 已执行。

3. `src/views/system-manage/role/modules/role-permission-drawer.vue`：列标题借用 `page.manage.menu.menuName` → 改为纯文本「菜单名称」（与其余列写法一致）。
