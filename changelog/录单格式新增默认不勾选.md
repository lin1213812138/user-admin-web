# 录单格式新增：字段映射默认一个都不勾

日期：2026-09-19
范围：`src/views/system-manage/setting/modules/input-format/field-list-mapper.ts`（`initialMappingOf`）、`input-format-drawer.vue`（仅一条注释）
前序记录：[录单格式新增不再默认全选字段](./录单格式新增不再默认全选字段.md)、[字段映射改为行式布局](./字段映射改为行式布局.md)

## 背景

用户要求「打开新增弹窗默认不选择」。

同日早些时候，新增态的初始勾选已经从「底稿全量」收窄为「★ 必填 + 锁定字段」；本次再收窄为**空**（一个都不勾）。

## 决策

| 决策点           | 结论                                                                                                                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 初始勾选         | `initialMappingOf` 的过滤条件由 `item.required === 1 \|\| item.disabled === true` 改为**只保留** `item.disabled === true`                                                                       |
| 锁定字段为何仍勾 | 锁定项在编辑器里勾选框不可取消（`f.disabled`），且 `mappingToFieldList` 对锁定项强制保留（只有 `disabled !== true` 才允许按「未显示」丢弃）；初始不勾会出现「界面看着没选、保存却被带上」的错位 |
| 编辑态           | 不受影响，仍走 `fieldListToMapping` 全量回显                                                                                                                                                    |
| 保存链路         | `mappingToFieldList` 一行未动                                                                                                                                                                   |
| 交互默认         | 勾选「显示」仍按既有行为自动带必填（本次不改）                                                                                                                                                  |

## 影响

- 新增格式时字段映射整片为空，需要用户手动勾选要展示的字段；
- 若默认模板里存在 `disabled === true` 的字段，那些字段仍会保持勾选（这是不可取消的锁定项，属预期）。

## 验证

- `npx oxfmt --check`（两个文件）→ `All matched files use the correct format`；
- `npx oxlint`（两个文件）→ 0 warnings 0 errors；
- `pnpm typecheck` → exit 0；
- 未做浏览器冒烟，人工确认点：打开新增抽屉 → 字段映射全空（有锁定字段时仅它保持勾选）。
