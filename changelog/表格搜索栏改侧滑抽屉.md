# 表格封装搜索栏改为侧滑抽屉

- 日期：2026-09-18
- 关联：spec `docs/superpowers/specs/2026-09-18-searchbar-drawer-design.md`、plan `docs/superpowers/plans/2026-09-18-searchbar-drawer.md`

## 需求

`Table` 组件里由 `searchItems` 驱动的内联可折叠搜索栏（`SearchBar`，内部 `NCard` + `NFormWrap`，CSS grid 行高 `1fr ↔ 0fr` 收展）改为**右侧滑出抽屉**，释放表格上方纵向空间。

采用默认决策（brainstorming 澄清环节确认方向）：右侧滑出 · 点「搜索」自动关闭 · 抽屉内表单纵向堆叠。

## 定位

原搜索栏是 `Table` 模板内联渲染的 `SearchBar` 折叠卡片，收缩态默认隐藏整块表单，展开态在表格上方占一行卡片。多条件筛选时挤压表格高度，且折叠/展开需要二次点击。改为 `NDrawer` 侧滑后，表格上方不再常驻搜索卡片，搜索条件收纳在抽屉里，点图标即开、填完即筛即关。

## 实施

- `src/components/SearchBar/search-bar.vue` 整文件重写：复用项目封装的 `CommonDrawer`（`@/components/common/drawer.vue`，内部即 `NDrawer`+`NDrawerContent`）作为抽屉外壳，受控 `v-model:show`、`:title="$t('common.search')"`、`:width="420"`，内容区用 `#footer` 插槽固定「重置 / 搜索」按钮，默认插槽内放 `NFormWrap` 展示搜索项；`SearchBar` 对外 emits `search` / `reset` / `update:show`。抽屉内强制单列：派生 `drawerItems` 把每个 item 的 `span` 收敛为 24（不改调用方原始配置）。不再自行写裸 `NDrawer`，与全站其它弹窗（user/site 等 OperateDrawer）保持一致。
- `src/components/Table/table.vue`：
  - 删除属性 `searchDefaultCollapsed` 及其 `withDefaults` 默认值、删除 `searchCollapsed` ref（已确认无任何调用方使用该属性）。
  - 新增 `searchDrawerVisible` ref 与 `handleSearch`（emit `search` 并关闭抽屉）/ `handleReset`（emit `reset` 保持打开），二者定义在 `emit` 声明之后以规避 `no-use-before-define`。
  - 删除模板内联 `<SearchBar>` 折叠块；operation-right 搜索图标按钮由「切换折叠」改为 `@click="searchDrawerVisible = true"`（`:type` 改 `default`）；根容器闭合前新增 `<SearchBar v-model:show="searchDrawerVisible" :items="searchItems" :model="searchModel ?? {}" @search="handleSearch" @reset="handleReset" />`。

## 契约与回归

- `Table` 对外契约 `searchItems` / `searchModel` / `@search` / `@reset` 完全不变 ⇒ 23 个调用页面（`system-manage/*`、`data-manage/*`、`customer-manage/*`、`channel-quote/*` 等）**零改动**。
- 独立的 `search-action` 自定义快捷搜索插槽与 `searchActionFlush` 属性保持内联、不受影响。
- `SearchBar` 旧 `collapsed` / `gridResponsive` 等内联形态 props 随重写废弃；全仓搜索确认 `SearchBar` 仅被 `Table` 引入，无外部直接引用。
- `common.filter` 不存在（仅 `expandFilter`/`collapseFilter`），按钮 title 沿用已有 `common.search` 避免 vue-tsc 报错。
