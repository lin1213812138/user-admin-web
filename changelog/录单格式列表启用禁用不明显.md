# 录单格式列表启用禁用不明显

## 现象

系统设置 → 录单格式，左侧「录单格式列表」每项右侧的「启用 / 禁用」是 12px、`opacity: 0.85` 的半透明纯文字，启用与禁用没有任何颜色差异，扫一眼无法区分。

## 定位

- 截图中的列表**不是通用 `Table` 组件**，而是 `src/views/system-manage/setting/components/MasterDetail.vue` 渲染的左侧导航（页面通过 `:show-status="true"` 开启状态显示）。
- 状态渲染处：`MasterDetail.vue` 模板里的 `<span class="menu-item__status">`。
- 2026-09-04 首次排查时误判为通用表格 `src/components/Table/table.vue` 的 `type:'status'` 列并做了改动，随后已 `git checkout` 完整撤销该文件。**教训：改通用组件前先确认用户截图对应的实际组件链路（本例是 InputFormat.vue → MasterDetail.vue）。**

## 修复

`src/views/system-manage/setting/components/MasterDetail.vue`：

1. 状态由半透明纯文字改为 `NTag size="tiny" round :bordered="false"` 实心彩色徽标：
   - 启用 = 主题 `successColor`（绿）实心；
   - 禁用 = 主题 `errorColor`（红）实心。
2. 配色用 `useThemeVars()` 取主题色，亮色模式下文字白色；暗黑模式下主题色偏亮，通过 `useThemeStore().darkMode` 把文字换成 `#1f1f1f` 保证可读。
3. `.menu-item__status` 样式去掉 `opacity: 0.85`，加 `flex-shrink: 0` 防止长名称挤压徽标。

由于状态徽标在 `MasterDetail` 内实现且由各页面 `showStatus` 控制显隐，此修复对所有传入 `showStatus` 的设置页 tab（录单格式等）统一生效。

## 二次调整（拥挤 → 轻量化）

用户反馈实心彩色块在 240px 窄列表里显得拥挤（色块视觉重、贴边）。改为**「小圆点 + 文字」**轻量方案：

- 6px 圆点：启用 = `successColor`、禁用 = `errorColor`（经根节点 CSS 变量 `--status-enable` / `--status-disable` 注入，跟随明暗主题）；
- 文字恢复普通继承色（12px），圆点与文字间距 5px；
- 移除 NTag、`useThemeStore` 依赖；暗黑模式下圆点本身用主题色即可，不再需要换算文字色。
