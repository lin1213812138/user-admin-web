# 标签设计器：拖入元素按「预览所在位置」创建

日期：2026-09-14
范围：`modules/canvas/design-canvas.vue`、`modules/canvas/drag-ghost.ts`

## 背景

用户反馈：「能不能拖进来是在什么位就显示在什么位置，不要以鼠标为起始点画？」

现状：`onDrop` 把**鼠标落点**当元素左上角（`x = 落点比例 × 纸张宽`）；而上一轮起拖拽预览是
「跟手」定位的（预览左上角 = 指针 − 抓取偏移）。两者错开一个「抓取偏移」，松手瞬间元素会
相对预览跳一下、落在偏离的位置。

## 方案

`drag-ghost.ts` 新增导出 `getDragOffset()`（返回当前拖拽记录里的抓取偏移）。

> drop 一定早于 dragend，`onDrop` 执行时 `state` 仍在，取得到偏移。

`design-canvas.vue` 的 `onDrop` 改为按**预览左上角**换算元素坐标：

```ts
const grab = getDragOffset();
const x = Math.max(0, mmToPt(((e.clientX - grab.x - rect.left) / rect.width) * size.w));
const y = Math.max(0, mmToPt(((e.clientY - grab.y - rect.top) / rect.height) * size.h));
```

- 松手时元素左上角与预览左上角对齐 → 松手即「落在预览所在位置」，不再有跳变；
- 预览左上角可能落在纸张外（从条目中后段抓取时），`Math.max(0, …)` 钳到纸张左上边界；
- 落点有效性判定不变（**指针**必须在纸张内才创建元素）。

## 注意

元素与预览**尺寸不同**（预览 = 面板条目尺寸，元素 = 默认元素尺寸），所以是**左上角对齐**、
不是完全重合——这正是用户要的「位置一致」。
