# 标签设计：左侧字段面板折叠分组

> 日期：2026-09-12

## 需求

用户参考打印设计页左侧面板（运单信息/收发件人信息… 一组带右侧 `>` 箭头的折叠项）的样式，要求标签设计器左侧字段面板也做成展开收起效果。

## 方案（A，用户确认）

`field-panel.vue` 模板重组：两个平铺分组（基础元素 / 字段）改成一个 `NCollapse` 容器 + 两个 `NCollapseItem`：

- `arrow-placement="right"`（箭头在右，与参考图及右侧属性面板一致）；
- `:default-expanded-names="['basic', 'fields']"` 默认全展开（展开便于直接拖拽，收起会隐藏拖拽目标）；
- header 用 13px font-medium 标题，沿用现有 i18n 键 `basicElements` / `fields`；
- 组内结构零改动（基础元素 2 列网格、字段单列列表），拖拽逻辑零改动；
- NCollapse/NCollapseItem 走 unplugin 自动按需引入，无需 import（与 property-panel 同模式）。

否掉方案 B（手写 toggle 折叠）：仓库原则禁造轮子，组件库有 NCollapse。

## 追加：外观与参考图（打印设计左侧）对齐

用户发当前效果截图（箭头紧贴标题文字、标题加粗）要求「要一样」。查 naive 源码定位：

- `right-arrow-placement` 样式只给箭头 `margin-left: 4px`，箭头**紧跟标题排列**，不贴右；header-main 是 `flex:1` 容器，让标题 slot 自身 `flex-1` 撑满后箭头才被推到最右（参考图 hiprint 面板效果）。
- 参考图标题为常规字重（非加粗），去掉 `text-13px font-medium`，回落 naive 默认（`--n-title-font-size: 14px`、常规字重）。

两处 header 改为 `<span class="flex-1">{{ $t(...) }}</span>`。

> 教训：改 header 时曾误把 `$t()` 换成硬编码中文，已即时修正——禁止硬编码文案。

## 验证

- `pnpm typecheck` 通过；label-designer 目录 oxlint 0 警告 0 错误；
- 手测：两组可独立折叠/展开、箭头贴右（收起 `>` / 展开 `∨` 旋转）、拖拽元素入画布正常。
