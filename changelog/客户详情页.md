## 追加：弹窗内表格自适应高度（用户贴截图"为什么没有自适应高度"）

**根因**：`Table` 的 `height` 默认 `100%`，但弹窗内容区高度链是断的——Drawer slot 根只有 `min-h`（无确定高度），NScrollbar 内容层也是 auto 高，vxe 拿不到 100% 就塌成内容高度（空表只剩表头+分页约 110px），`min-h` 撑出的剩余空间全成空白（截图两处红框）。

**修复**：打通「弹窗内容区 → tabs 卡片 → pane → 表格」高度链——

1. Drawer slot 根：`flex h-[calc(100vh-120px)] flex-col gap-16px overflow-hidden`（视口定高， Drawer header+padding 预留 120px）；
2. `NSpin` 加 `content-class="flex min-h-0 flex-1 flex-col gap-16px"`（NSpin 会打断 flex 链，必须用 content-class 续上）；
3. tabs 卡 `NCard`：`flex flex-1 min-h-0 flex-col` + `content-style="flex:1 1 0;min-height:0;display:flex;flex-direction:column"`（NCard content 默认不拉伸）；
4. `NTabs` 加 `h-full min-h-0 flex-1` + scoped deep：`.n-tabs-pane-wrapper / .n-tab-pane { height: 100%; padding-bottom: 0 }`；
5. address/file/oplog 三个 tab 根容器 `min-h-560px` → `h-full`，oplog 表格删掉固定 `height="480px"` 改回默认 100%。

## 坑

1. `/ship-to/query` 的 keyword 不传 `keywordFields` 会被 queryCommon 忽略（`keyword && !isEmpty(keywordFields)` 短路）。
2. `/ship-to/delete` 是 `{ids: string[]}` 数组，不是单个 `_id`；`/file/delete` 反而是单个 `_id`。
3. `/file/query` 走 queryAllCommon 无 total，useVxeTable 泛型第一个参数不能直接用 CustomerFileList，需内联 `{ list; total }`。
4. `useVxeTable` api 回调返回值必须匹配泛型 TList（首次把 `{list,total}` 字面量返回给 `{list}` 型报 TS2322）。
5. `target="_blank"` 必须带 `rel="noopener noreferrer"`（vue/no-template-target-blank error）。
6. i18n key 必须同步 app.d.ts Schema（既有结论第三次复现）。
