# 封装蓝条标题卡片组件（LCard）

## 需求

用户贴出「计泡规则新增抽屉」截图，要求封装一个通用卡片组件：标题前面带主题色（蓝）竖条，且 body（内容区）padding 可控——NCard 自带 header/content padding 太大，需要收紧并可自定义。

## 决策

- 基于 `NCard` 封装（保留边框/圆角/`header-extra` 原生能力），不重复造容器。
- 组件名 `LCard`（与同目录 `LButton` 命名风格一致），文件位于 `src/components/basic/l-card/index.vue`，走 unplugin-vue-components 自动按需引入，模板中直接写 `<LCard>` 即可。
- 竖条颜色默认取 `useThemeVars().primaryColor`，自动跟随主题（暗色模式同样生效），支持 `bar-color` 覆盖。
- padding 收紧为组件默认值，均可通过 props 覆盖：
  - `header-padding` 默认 `'10px 16px'`（NCard 默认约 `16px 24px`）；
  - `content-padding` 接受 `string | number | false`：`number` 按 px、`false` 完全去内边距（便于内部自行布局，如嵌套表格/表单贴合）。
- 标题支持 `title` prop 与 `#title` 插槽两种方式；无标题且无 `#header-extra` 时不渲染 header。
- 竖条尺寸 `3px × 14px` 圆角条，与截图中样式一致；标题 `15px / 600`。

## 实现

新增 `src/components/basic/l-card/index.vue`（组件名 `LCard`）；`src/typings/components.d.ts` 登记项 `LCard`（dev 启动后由插件自动维护）。

### 使用示例

```vue
<LCard title="基础信息">
  <!-- 内容，默认 content-padding: 12px 16px -->
</LCard>

<!-- 去掉内容内边距 -->
<LCard title="进位规则" :content-padding="false">
  <div class="p-12px">...</div>
</LCard>

<!-- 自定义 padding / 竖条颜色 / 头部右侧扩展 -->
<LCard title="计泡比率" content-padding="8px 12px" header-padding="8px 12px" bar-color="#18a058">
  <template #header-extra>
    <NButton quaternary size="tiny">操作</NButton>
  </template>
</LCard>
```

## Props 一览

| Prop              | 类型                        | 默认              | 说明                         |
| ----------------- | --------------------------- | ----------------- | ---------------------------- |
| `title`           | `string`                    | `''`              | 标题文字（或用 #title 插槽） |
| `bar-color`       | `string`                    | 主题 primaryColor | 标题竖条颜色                 |
| `content-padding` | `string \| number \| false` | `'12px 16px'`     | 内容区内边距，false 为 0     |
| `header-padding`  | `string`                    | `'10px 16px'`     | 头部内边距                   |
| `bordered`        | `boolean`                   | `true`            | 是否显示边框                 |
