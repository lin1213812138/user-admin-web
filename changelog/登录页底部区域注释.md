# 登录页底部区域注释

## 需求

用户附登录页截图，红框标出密码登录表单底部区域：「这块内容也注释一下」，即：

1. 「验证码登录」「注册账号」两个模块切换按钮；
2. 「其他账号登录」分割线；
3. 超级管理员 / 管理员 / 普通用户 三个快捷账号登录按钮。

沿用此前惯例：**只注释不删除**，代码保留便于日后恢复。

## 改动

仅 `src/views/_builtin/login/modules/pwd-login.vue` 一个文件：

- 模板：上述三块整体包进单个 HTML 注释块（`<!--` 后、`-->` 前换行，满足 `vue/html-comment-content-newline`）。
- script 注释保留（连锁 unused）：
  - `loginModuleRecord` 导入（仅被注释的切换按钮使用）；
  - `AccountKey` / `Account` / `accounts` / `handleAccountLogin`（仅被注释的快捷账号区使用）。
- **保留** `toggleLoginModule` 及 `useRouterPush`：模板上方「忘记密码」按钮（`toggleLoginModule('reset-pwd')`）仍在使用，第一轮注释后 lint 报 `vue/no-undef-properties` 警告，已恢复声明。

## 验证

- read_lints 0 诊断。
- 视觉效果待用户 dev 复核：登录卡底部到「确认」按钮为止。

## 恢复方式

取消模板注释块 + script 三处注释（`loginModuleRecord` 导入、`Account` 相关定义与 `handleAccountLogin`）即可。
