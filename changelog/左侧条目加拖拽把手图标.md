# 标签设计器：左侧条目加拖拽把手图标

> 用户需求（附参考截图，红框圈出条目左侧的 ⠿ 图标）：「每个元素前面能不能像这个一样加个拖拽的图标？」

## 改动

`panels/field-panel.vue` 两组条目（业务字段、基础元素）在文字前加拖拽把手图标：

```html
<icon-mdi-drag class="mr-6px shrink-0 text-14px text-#c0c4cc dark:text-#555" />
```

- 图标沿用项目既有先例 `components/Table/table-column-config.vue` 的 `icon-mdi-drag`（六点把手）+ `cursor-move` 语义，**无需新增依赖**；
- 条目容器由 inline 流改为 `flex items-center`（图标与文字垂直居中）；图标 `shrink-0` 防挤压、浅灰 `text-#c0c4cc`（暗黑 `#555`）与辅助文字同调；
- **仅视觉提示**：整条仍可拖（拖拽会话由整条 `pointerdown` 建立），图标不是唯一拖拽区；label / 字段 key 的既有间距（`ml-4px`）不变。

## 验证

- `npx oxfmt` / `npx oxlint --fix` / `npx eslint --fix` 单文件：0 error。
- `pnpm typecheck`：0 error。
- 手动冒烟建议：左侧两组条目左侧出现灰色 ⠿ 图标；拖出条目的预览与落纸行为不变。

## 二次调整：图标加深 + hover 高亮（用户截图反馈）

反馈：「图标看不清楚，然后元素hover加个border，类似这种的」（截图 hover 态 = 主题色边框 + 主题色文字）。

- 拖拽把手图标：`text-#c0c4cc dark:text-#555` → **`text-#8c8c8c dark:text-#999`**（明显加深、可辨识）；
- 条目 hover（容器加 `group`）：
  - 边框 `hover:border-primary` + **`dark:hover:border-primary`**——暗黑下必须单独写：`hover:border-primary` 与 `dark:border-#2a2a2a` 同特异性 `(0,2,0)`，靠源顺序不可靠；`dark:hover:` 为 `(0,3,0)` 稳定胜出；
  - 条目名 `group-hover:text-primary`（`(0,3,0)` 稳定胜出 `dark:text-#777` 的 `(0,2,0)`），`transition-colors` 平滑过渡；
  - 字段 key（辅助信息）与拖拽图标不参与变色（与截图一致）；
  - 主题色类 `hover:border-primary` 沿用项目既有先例（`components/custom/icon-picker.vue`）。

### 二次验证

- `npx oxfmt` / `npx oxlint --fix` / `npx eslint --fix` 单文件：0 error。
- `pnpm typecheck`：0 error。

## 三次修正：hover 文字色改用 scoped CSS（用户截图对比「跟前面的效果不一样」）

用户对比截图：参考效果 hover = 蓝边框 + **蓝文字**；我方 hover 只有蓝边框、文字没变主题色。

- 根因：`group-hover:text-primary` 与元素自身的 `text-#999` / `dark:text-#777` 叠加时未能稳定生效（UnoCSS 变体生成的优先级与源顺序不可控；项目内亦无 `group-hover:` 先例可参照）；
- 修法：容器 `group` → `field-entry`、条目名加 `entry-title`，hover 文字色改由 **scoped CSS** 控制：

  ```css
  .field-entry:hover .entry-title {
    color: rgb(var(--primary-color, 32 128 240));
  }
  ```

  - 含 scoped 属性后特异性 (0,4,0)，稳定压过 `text-#999`(0,1,0) 与 `dark:text-#777`(0,2,0)，且不依赖 UnoCSS 输出顺序；
  - 色值口径与 `text-primary` 完全一致（`rgb(var(--primary-color))`，见 `src/theme/vars.ts`），带 `#2080f0` 兜底；

- 边框 hover 仍由 `hover:border-primary dark:hover:border-primary` 承担（该写法已生效，保持不变）。

### 三次验证

- `npx oxfmt` / `npx oxlint --fix` / `npx eslint --fix` 单文件：0 error。
- `pnpm typecheck`：0 error。
