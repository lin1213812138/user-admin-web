# 标签设计：画布平移缺少抓手光标

> 日期：2026-09-13

## 需求

用户反馈「标签拖动的时候鼠标没有显示拖动的样式」，澄清后确认为：**拖动整块画布（无限画布平移）时，鼠标始终是默认箭头，没有抓手手势**。

## 根因

`src/views/system-manage/label-designer/modules/design-canvas.vue`：

- `.label-designer-canvas`（即 `viewportRef`，平移手势的挂载元素）的样式块只有 `touch-action: none`，**完全没有 `cursor` 规则**；
- 平移链路 `onViewportPointerDown` / `onPanMove` / `onPanUp` 只处理坐标与 transform，全程不动光标。

对照姊妹页 `src/views/system-manage/print-design/index.vue` 的同款平移是有的（`.print-design-canvas { cursor: grab }` + `.print-design-canvas.panning { cursor: grabbing }`），label-designer 这版漏了。

## 方案（用户确认：方案 1-4 全部实施）

1. 容器加手掌光标：`.label-designer-canvas { cursor: grab }`。
2. 平移进行中换握拳：

   ```css
   .label-designer-canvas.panning,
   .label-designer-canvas.panning * {
     cursor: grabbing !important;
   }
   ```

   **为什么必须带 `*` + `!important`**：`cursor` 是每个元素独立生效的属性，父级声明压不住子元素自身写死的光标（继承值一律输给元素自己的声明，与优先级无关）。平移途中指针会滑到纸张 / 元素 / 缩放手柄上，若不带这两样，会被 `.element-item`、`.resize-handle` 自身的光标压过去，出现「握拳 ↔ 箭头 ↔ 缩放」来回闪。

3. `panning` 类用 `viewportRef.value.classList.add/remove` **命令式**加/摘（`onViewportPointerDown` / `onPanUp`），不走响应式 —— 与现有「平移高频帧只直写 DOM、不碰响应式」的写法一致，也避免平移动一下就让元素列表 `v-for` 重渲染；类名抽成 `PANNING_CLASS` 常量。同时补 `pointercancel` 监听（指针被系统/浏览器收回时不会走 `pointerup`），并在 `onBeforeUnmount` 兜底摘类，防止残留到其它页面。
4. 连带修语义错位：容器变手掌后，纸上元素会**继承**手掌，但拖元素是「移动」而非「平移」，故给 `.element-item` 显式写 `cursor: move`（`.resize-handle` 的 8 个缩放光标是自带声明，不受影响）。
