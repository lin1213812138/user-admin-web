# 数据初始化界面（系统设置 → 初始化数据）

> 用户需求：把「系统设置 → 初始化数据」标签页（`views/system-manage/setting/modules/init-data/InitData.vue`，当前为占位组件）替换为图片中的完整界面，并按要求改为左右布局。
> 设计确认（四轮澄清 + 布局迭代）：
>
> 1. 在现有「系统设置 → 初始化数据」标签页内实现，替换 `InitData.vue`（不动路由，标签页由 `setting/index.vue` 的 `componentMap` 已挂好 `init-data`）。
> 2. 四个标签页（渠道类别 / 承运网络 / 计泡规则 / 操作配置）先用**统一默认结构**：序号 / 中文名称 / 英文名称 / 备注 / 操作（编辑、删除），「+ 添加一行」新增。
> 3. 数据**先用本地 mock**（与站点/客户一致，DEV 下走 mock.ts，无后端也能跑）。
> 4. **【布局迭代】改为左右布局**：左栏两个导航项「基本信息初始化 / 业务数据初始化」，右栏对应显示「基本信息表单」或「下方四表格」；基本信息从只读改为可编辑 `NFormWrap` 表单（含保存）。

## 实施方案（方案 A：左右容器 + 通用表格子组件 + 分类配置）

### 1. 文件结构

```
views/system-manage/setting/modules/init-data/
  InitData.vue                     # 容器：左右布局（左栏菜单 + 右栏内容切换）
  BasicInfoForm.vue                # 基本信息表单（可编辑 + 保存）
  InitDataCategory.vue             # 通用表格子组件（接收 category prop）
  init-data-form-drawer.vue        # 新增/编辑抽屉（NFormWrap：中文名/英文名/备注）
  init-data-info.ts                # 左侧菜单枚举 + 分类枚举/文案 key
```

> 不抽 `InitDataCategory` 之外的额外文件；四个标签页共用同一组件，仅 `category` 不同。

### 2. 左右布局容器 `InitData.vue`（复用通用组件 `MasterDetail`）

- 直接复用 `views/system-manage/setting/components/MasterDetail.vue`（系统设置模块的通用左右布局组件），不再手写左栏。
- 左栏 `items` 由 `InitData.vue` 以 `computed` 提供两项固定导航：`{ id:0, name: $t(basicInit) }` / `{ id:1, name: $t(businessInit) }`；`v-model:selected-id` 控制右栏切换，`showSearch/showActions/showStatus/editable` 均关闭，`listTitle` 取 `initData.title`。
- 右栏 slot：`selectedId===0` 渲染 `BasicInfoForm`；否则渲染 `NTabs` 四表格（沿用原逻辑）。
- **任何可滚动区域统一使用 naive-ui `NScrollbar`**：`MasterDetail` 左栏菜单已内置 `NScrollbar`；`BasicInfoForm` 表单区用 `NScrollbar` 包裹（原 `overflow-auto` 改为 `NScrollbar`）。表格内部滚动由 `vxe-table` 组件自身负责。

### 3. 基本信息表单 `BasicInfoForm.vue`

- `NFormWrap` 9 字段（`page.manage.setting.initData.info.*` 文案）：
  - 公司名称 `companyName`（input，必填）
  - 公司地址 `companyAddress`（textarea）
  - 公司网址 `companyUrl`（input）
  - 系统名称 `systemName`（input）
  - 联系电话 `contactPhone`（input，span 12）
  - 默认出发地 `defaultOrigin`（input，span 12）
  - 员工登录 `staffLogin`（switch，支持/不支持，span 12）
  - 客户登录 `customerLogin`（switch，支持/不支持，span 12）
  - 公司LOGO `companyLogo`（input，URL 占位，span 24）
- 默认值内联在组件（DEV 不接接口，后续接后端改 service 回填）。
- 底部「保存」按钮 `$t('common.save')`，DEV 无后端接口，仅本地提示 `$t('common.saveSuccess')`。

### 4. 四个标签页（通用表格 `InitDataCategory.vue`）

- Props：`category: InitDataCategoryKey`（`'channel' | 'network' | 'bubble' | 'operation'`）。
- 列：**序号（show-seq）/ 中文名称 / 英文名称 / 备注 / 操作**（编辑、`NPopconfirm` 删除），表格上方「+ 添加一行」按钮（放在 `operation-left` 插槽）。
- 数据：本地 mock，按 `category` 分四组独立数组，走 `useVxeTable` + `Table`（与 site/customer 同范式）。
- 增删改：`Drawer`（`init-data-form-drawer.vue`）+ `NFormWrap`，字段：
  - 中文名称 `cnName`（input，必填）
  - 英文名称 `enName`（input，必填）
  - 备注 `remark`（textarea）
- 列配置持久化 `cacheKey` 按 `init-data-<category>` 区分；`defaultPageSize: 20`。
- `category` 仅影响：mock 数据源 key、列表 `cacheKey`、标签页文案（由父级 `tabs` 提供，组件本身不感知文案）。

### 5. i18n（zh-cn / en-us 同步）

`page.manage.setting.initData` 段：

- `basicInit` / `businessInit`：左栏两个菜单项标题
- `info.*`：9 个基本信息字段名
- `channel` / `network` / `bubble` / `operation`：四个标签页标题
- `cnName` / `enName` / `remark`：表单字段
- `cnNamePlaceholder` / `enNamePlaceholder` / `remarkPlaceholder`
- `initData` 由字符串改为带 `title` 的对象（仿 `printFormat` 惯例），`setting/index.vue` 引用 `.title`。

`common` 段补充 `save`（保存 / Save）—— 原 `common` 段无 `save`，按钮统一复用。

### 6. 类型与 mock（`typings/api/system-manage.d.ts` + `service/api/mock.ts`）

```ts
// typings/api/system-manage.d.ts
/** 初始化数据分类 */
type InitDataCategory = 'channel' | 'network' | 'bubble' | 'operation';

interface InitDataItem {
  id: number;
  category: Api.SystemManage.InitDataCategory;
  cnName: string;
  enName: string;
  remark: string;
  createByName: string;
  createTime: string;
  updateByName: string;
  updateTime: string;
}

type InitDataList = Api.Common.PaginatingQueryRecord<InitDataItem>;
type InitDataSearchParams = Api.Common.CommonSearchParams & { category: Api.SystemManage.InitDataCategory };
type InitDataCreateParams = {
  category: Api.SystemManage.InitDataCategory;
  cnName: string;
  enName: string;
  remark: string;
};
type InitDataUpdateParams = InitDataCreateParams & { id: number };
```

`mock.ts` 新增：四类 `InitDataItem[]` 数组（每类若干样例）+ 导出 `mockGetInitDataList / mockCreateInitData / mockUpdateInitData / mockDeleteInitData`（按 `category` 过滤、分页、同分类中文名查重）。

### 7. service 接口（`service/api/system-manage.ts`）

新增四个函数，DEV 走 mock（与站点一致 `as unknown as Promise<T>`）：

- `fetchGetInitDataList(params)` → `/system/init-data/list`
- `fetchCreateInitData(params)` → `/system/init-data/create`
- `fetchUpdateInitData(params)` → `/system/init-data/update`
- `fetchDeleteInitData(ids)` → `/system/init-data/delete`
