# 菜单管理操作列「增加子菜单」

> 日期：2026-09-01
> 关联：`src/views/system-manage/menu/index.vue`、`src/views/system-manage/menu/modules/menu-operate-drawer.vue`

## 需求

在菜单管理页的操作列新增「增加子菜单」功能，点击后在该行下挂一个子菜单。

## 设计决策（已与用户确认）

1. **按钮显隐**：每行都显示（catalog / menu 类型），点击即在该行下挂子级。当前菜单模型无 button 类型，统一显示最简单。
2. **父级字段**：抽屉打开时「上级菜单」下拉自动选中当前行，但用户仍可改选其它父级（预选且可改）。

## 实现方案

### 1. `src/views/system-manage/menu/index.vue`

- 新增状态 `subParentId: ref<number | null>(null)`。
- 新增函数 `openSubDrawer(row: MenuItem)`：`operateType.value = 'add'`、`editingId.value = null`、`subParentId.value = row.id`、`drawerVisible.value = true`。
- `<Table>` 的 `MenuOperateDrawer` 调用增加 `:parent-id="subParentId"`。
- `#action` 插槽在「编辑」前增加「增加子菜单」按钮（`NButton type="primary" text`）。

### 2. `src/views/system-manage/menu/modules/menu-operate-drawer.vue`

- 新增 prop `parentId?: number | null`（默认 `null`）。
- `watch(visible)` 的 add 分支（`operateType === 'add'`）：若 `props.parentId != null`，则 `model.value.parentId = props.parentId`，覆盖默认 `0`。edit 分支不变。

### 3. i18n 三处同步

- `zh-cn.ts` / `en-us.ts` 的 `page.manage.menu` 下新增 `addSubMenu`：`增加子菜单` / `Add Submenu`。
- `src/typings/app.d.ts` 的 `App.I18n.Schema.page.manage.menu` 下新增 `addSubMenu: string`。

## 不改

- 不锁定父级字段、不新增接口、不改动 mock、不动 `useVxeTable`。

## 验证

- `pnpm typecheck` 通过（i18n 键三处同步）。
- `pnpm lint` 通过。
- 手动：菜单页每行出现「增加子菜单」，点击后抽屉「上级菜单」预选当前行，提交后新子级出现在对应父级下。
