# 标签设计缩放连体与移除垂直对齐

## 背景

用户截图反馈标签设计器工具栏两处问题：

1. 缩放控件（`- 100% +`）三个独立控件（quaternary 图标按钮 + text 百分比按钮 + quaternary 图标按钮，靠 `gap-8px` 间隔），视觉松散，要求「优化一下」；
2. 「垂直对齐」按钮要求去掉。

## 方案确认

### 缩放控件

候选三案：

- **方案 A（采纳）**：`NButtonGroup` 连体按钮组 —— 左右 quaternary 图标按钮 + 中间固定宽 56px 的 quaternary 百分比按钮。纯 Naive UI 组合，不造轮子。
- 方案 B（否）：自定义 border 容器包裹，观感更整体但需手写样式。
- 方案 C（否）：`NInputNumber`，步进 10% 语义不符、样式过重。

交互保持不变：点击 `-` / `+` 步进 10%（钳制 20%~400%），点击中间百分比重置为 100%，tooltip 提示保留。

### 垂直对齐按钮

删除按钮，死代码一并清理（避免死键堆积，参照 `labelDesign.title` 死键未删的教训）。

## 追代：quaternary 连体不可见 → 改 default 带边框

用户反馈「没变化」：`NButtonGroup` 包三个 `quaternary` 按钮后外观与独立三控件几乎无异。根因是 **Naive UI 的按钮组连体本质 = 相邻按钮合并边框（负 margin + 圆角归零），`quaternary` 无边框则合并无从体现**。

修正：缩放三按钮去掉 `quaternary` 改 default（带边框），组内共享边线形成一体化控件，与同工具栏撤销/重做组（`NButtonGroup` + default）视觉同款。图标、56px 定宽、点击重置 100%、tooltip 全部保留。typecheck / lint 通过。
