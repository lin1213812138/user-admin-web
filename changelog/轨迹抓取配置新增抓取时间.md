# 轨迹抓取配置：新增「抓取时间」子 tab

日期：2026-09-17
设计文档：[docs/superpowers/specs/2026-09-17-capture-time-tab-design.md](../docs/superpowers/specs/2026-09-17-capture-time-tab-design.md)

## 背景

用户附两张截图：「系统设置 → 轨迹抓取配置」需新增「抓取时间」：

1. 主表格字段 = 操作日志 / 操作系统 / 操作类型 / 操作人 / 操作时间（抓取执行记录）；
2. 表格工具栏左侧按钮 → 弹窗「系统每天将在以下时间自动抓取轨迹」+ 时间行（可删除）+「添加时间」+「保存配置」。

该模块此前因「字段待定」被注释隐藏（见 `changelog/抓取时间模块先注释.md`），本次字段确定后恢复。

## 澄清确认（ask_followup 三项）

- 位置：恢复为「轨迹抓取配置」第 4 个子 tab（追踪网络 / 轨迹改造 / 轨迹关键词 / 抓取时间）；
- 图1 五列即该 tab 主表格列（展示抓取执行记录），工具栏左侧按钮打开配置弹窗；
- 数据先走前端 DEV mock（后端 tms-user 暂无抓取时间接口）。

- `views/system-manage/setting/modules/trace-capture/CaptureTimeModal.vue`：`NModal`(420) 时间点配置（打开读配置回显、添加 / 删除行、仅剩 1 行时删除禁用、空值 / 重复校验、保存成功提示 + 关闭）；
- `service/api/capture-time/index.ts`：`fetchGetCaptureTimeRecordList` / `fetchGetCaptureTimeConfig` / `fetchSaveCaptureTimeConfig`（DEV mock 分支 + 非 DEV 真实 request 占位）。

改动：

- `TraceCapture.vue`：`configTabs` 取消 `capture-time` 注释（恢复 4 个子 tab）、模板加 `CaptureTimeTable v-else-if` 分支、头注释同步；
- `service/api/mock.ts`：末尾新增抓取时间 mock 段（6 条抓取记录 + 配置 `['03:00']`，`timeStampOf` 辅助构造毫秒时间戳）；删除旧 capture-time 同构分类数据（"定时抓取 / 10.0.3.1:6000"，已无页面使用）；
- `service/api/index.ts`：barrel 追加 `export * from './capture-time'`；

## 坑

DEV mock 分支返回裸值、非 DEV 为 flat request，`fetchGetCaptureTimeConfig()` 返回类型是联合类型 → 调用处需 `(await ...) as Api.SystemManage.CaptureTimeConfig` 收窄（否则 typecheck TS2339 / TS7006）。

## 调整：时间选择控件改为小时下拉框（同日追加，两轮）

用户反馈「抓取时间设置只能选择小时」→ 追问确认要求「能不能直接用个下拉框」。

- 先实测原控件：`NTimePicker`（`format="HH:mm"`）面板时（00-23）/分（00-59）两列均正常（面板点击 45 → 值 03:00 → 03:45），排除功能缺陷，按需求调整；
- 第一轮：改动 `CaptureTimeModal.vue`：`NTimePicker` → `NSelect`（选项为整点 `00:00` ~ `23:00`），时间行值由毫秒时间戳改为字符串（`loadConfig` / `handleSave` 同步简化，移除 `dayjs` 依赖）；
- 第二轮（最终）：用户反馈「我不是说了只要小时吗？」⇒ 选项与显示改为**纯小时 `00` ~ `23`**（不带 `:00`），保存值同步为 `"03"` 形式；mock 默认配置改 `['03']`；
- 验证：typecheck 0 / lint 0 error / fmt；playwright 实测 dev 9111：下拉回显 `03`、选项渲染 `00` ~ `09`（虚拟滚动可见项）、选择 `08` 保存成功 → 重开回显 `08` → 改回 `03` 保存成功，console 0 errors（期间 HMR 的 404/500 为文件重组的瞬态抖动，刷新后恢复）。

> 另：同期用户将 trace-capture 子模块重组为独立目录（`track-network/`、`track-transform/`、`track-keyword/`、`capture-time/`，本模块两文件随迁 `capture-time/`），重组后 typecheck 仍 0 错误。
