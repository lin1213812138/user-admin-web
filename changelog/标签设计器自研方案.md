# 标签设计器自研方案（替代 vue-plugin-hiprint）

- 日期：2026-09-11
- 设计文档：[docs/superpowers/specs/2026-09-11-label-designer-custom-design.md](../docs/superpowers/specs/2026-09-11-label-designer-custom-design.md)

## 决策背景

现有 `src/views/system-manage/print-design/` 基于 `vue-plugin-hiprint`，存在依赖重（jQuery / jspdf / bwip-js / html2canvas / socket.io-client）、自带属性面板暗黑模式适配差、撤销重做需 `history:true` 等痛点。用户决定**完全自研替代 hiprint**，用纯数据驱动的 Vue 组件树重写。

## 关键决策（已与用户确认）

1. **画布交互全手写**：移动 / 选中 / 8 向缩放全部用 pointer 事件手写，不引入 moveable / selecto 等 DOM 操作库。
2. **条码/二维码用算法库**：采用 `bwip-js`（单依赖、1D+2D 全覆盖，hiprint 同款引擎），其余逻辑全自研；不手写编码算法。
3. **逻辑单位统一 mm**：模板 JSON 用 mm 作坐标单位，打印直接用 CSS `100mm` 还原真实尺寸（比 hiprint 的 pt round-trip 更准）。
4. **撤销重做快照式**：Pinia store 内 `past/future` 快照栈，一次完整操作（move/resize 抬起 / 属性 change）提交一次。
5. **v1 砍掉 table 元素**：字段绑定 + 列配置最重，单独立项；v1 支持 text / longText / image / barcode / qrcode / rect / hline / vline。
6. **右侧属性面板用仓库已有 FormWrap**：天然支持暗黑模式，替代 hiprint 原生 `#Setting` 面板。
7. **预览生成静态 HTML**：文本/矩形/线用绝对定位 div，条码/二维码用 `bwip-js` 转 dataURL 内嵌 `<img>`，iframe `srcdoc` 注入后 `window.print()`。

## 依赖变动

- 新增：`bwip-js`。
- 移除：`vue-plugin-hiprint`、`jquery`、`@types/jquery`、`src/typings/hiprint.d.ts`、`vite.config.ts` 的 `optimizeDeps.include` 两项。
