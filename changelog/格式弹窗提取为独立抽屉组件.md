# 打印格式 / 导出格式：新增弹窗提取为独立抽屉组件

- 日期：2026-09-19
- 范围：`src/views/system-manage/setting/modules/{print-format,export-format}`、`docs/superpowers/specs/2026-09-19-format-drawer-extract-design.md`
- 触发语：「把新增弹窗提出来，录单格式和导出格式一样」

## 需求与确认

现状：录单格式已有独立 `input-format-drawer.vue`；打印格式（新增/复制/查看）与导出格式（新增/编辑）的抽屉都内联在页面里。ask_followup 确认范围 = **打印格式 + 导出格式都提取**，三个格式模块组织方式统一（对齐 `input-format-drawer.vue` 范式）。

## 实施

| 文件                                             | 内容                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `print-format/template-type.ts`（新增）          | `TEMPLATE_TYPE_OPTIONS` + `templateTypeLabel()`：表格列 / 搜索下拉 / 抽屉 select 三处共用，消除重复定义                                                                                                                                                                                                                                                                                              |

要点：

- 三个格式模块抽屉契约统一：`show` + `row`（+ 各自的 mode / 默认值 props），成功 emit `submitted` 由父刷新列表，成功提示留在抽屉内。
- `defaultTemplateType` 承接原「新增时类型/类别跟随列表筛选」行为（原来直接 read 页面 `filterTemplateType` / `filterType` ref）。
- 打印格式原先无提交 loading，本次与导出格式对齐补上 `submitting`（仅按钮 loading，无行为变化）。

## 顺手修正（记录在案）

`PrintFormat.vue` 原内联提交未检查 `{ error }`：接口失败也会关抽屉并提示「保存成功」（叠加 request 拦截器的错误弹窗 ⇒ 双提示）。提取后统一为 `if (error) return`（保持抽屉打开），与导出格式 / 录单格式一致。
