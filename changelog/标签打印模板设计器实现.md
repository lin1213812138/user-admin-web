## 关键坑与决策

1. **页面位置**：不能放 `views/system-manage/setting/` 下（会生成子路由 + 父路由自动 redirect → 与守卫叠加曾致重定向死循环），故放到 `views/system-manage/print-design/`。
2. **菜单隐藏**：`customRoutes` 的 `name` 类型是 `CustomRouteKey`（只有 `root` / `not-found`），**不能**用来覆盖自动生成的路由；改为在 `build/plugins/router.ts` 的 `onRouteMetaGen` 里给 `system-manage_print-design` 写 `hideInMenu: true`，再 `pnpm build` 重生成路由。
3. **jQuery 必须锁 3.x**：`pnpm add jquery` 默认装 4.0.0，与 hiprint（jQuery 3 API）不兼容，已改 `jquery@^3.7.1`。
4. **jQuery 全局与加载顺序**：hiprint 依赖全局 `$`，静态 import 会被提升 → `use-hiprint.ts` 在运行时先 `await import('jquery')` 挂 `window.$ / window.jQuery`，再 `await import('vue-plugin-hiprint')`，并 `disAutoConnect()` 关 socket。
5. **provider 必须传分组**：`addPrintElementTypes(key, e)` 内部读 `e[].printElementTypes`，扁平 `PrintElementType[]` 不生效 → 业务字段按分组包成 `PrintElementTypeGroup`，tid 规则 `${groupKey}.${fieldKey}`，`options.field` 绑定数据字段、`options.testData` 提供设计态示例值。
6. **缩放**：`PrintTemplate.zoom(t, e)` 的第二参为 true 时才把 scale 记到实例 → 调 `zoom(scale, true)`。
7. **纸张**：`setPaper(w, h)` 传数值走 `editingPanel.resize(...)`，传字符串走内置纸张类型（找不到会抛错）→ 只传数值。
8. **getHtml 返回 DTO**：不是字符串，可能返回对象或数组 → `preview-modal.vue` 用 `toHtmlString()` 递归取 `html()`。
9. **清空**：dist 里未确认 `PrintTemplate.clear()` 存在 → 代码判空，缺失时销毁重建实例。
10. **i18n 层级**：`printDesign` 必须放 `page.manage` 下（不是 `page.manage.setting`）；`app.d.ts` 的 Schema 同步时容易插错括号层级（曾误插到 `page` 下）。
11. **lint**：`*.d.ts` 里「只有构造函数的 class」会触发 `no-extraneous-class` → 改成「接口 + 带构造签名的 const」；自定义事件名必须 camelCase（`zoomOut` / `zoomIn`）。
12. **DEV 裸数据**：`print-format.ts` 在 DEV 下返回裸数据，但函数返回类型推断成 `Template | FlatResponseData<...>` 联合 → 调用处按约定断言为 `Api.PrintFormat.Template`。

## 修复记录

- **2026-09-07 拖拽失效**：根因是 `NCollapse` 默认 `displayDirective="if"`，折叠分组字段未挂载到 DOM，初始化 `buildDraggableItems` 只执行一次，导致折叠组字段未注册拖拽。修复：
  - `field-panel.vue` 默认展开第一组，保证首屏可见字段可立即拖拽。
  - `use-hiprint.ts` 的 `buildDraggableItems` 改为 `MutationObserver` 持续监听面板 DOM，新增 `.ep-draggable-item` 时自动补注册，并用 `data-hiprint-bound` 标记避免重复绑定。
  - `index.vue` 在 `handlePanelReady` 时保存清理函数，组件卸载时 disconnect。
- **2026-09-07 设计器加载失败**：页面显示「设计器加载失败：TypeError: hiprintObj.disAutoConnect is not a function」。根因是 `vue-plugin-hiprint` 模块顶层导出 `hiprint`、`defaultElementTypeProvider`、`disAutoConnect`、`autoConnect`、`hiPrintPlugin`，而 `PrintTemplate/PrintElementTypeGroup/PrintElementTypeManager/init` 挂在 `hiprint` 上；`disAutoConnect` 并不在 `hiprint` 对象上。修复：
  - `use-hiprint.ts` 改调 `mod.disAutoConnect?.()`。
  - `src/typings/hiprint.d.ts` 将 `disAutoConnect / autoConnect` 从 `HiprintStatic` 移到模块顶层 `export function`。
  - `index.vue` 在 catch 中加 `console.error` 并在消息中显示真实错误，方便后续定位。
- **2026-09-07 设计画布网格**：hiprint 默认设计器不带网格背景，用户难以对齐。新增：
  - 顶部工具栏加「显示网格 / 隐藏网格」切换按钮。
  - `index.vue` 增加 `showGrid` 状态（默认开启），给 `#hiprint-printTemplate` 动态加 `show-grid` 类。
  - 通过无 scoped 的 `<style>` 为 `.show-grid .hiprint-printPaper.design` 加 `10mm` 间隔的线性渐变网格背景，并适配暗黑模式；预览/打印页面不带 `show-grid`，因此不会打印网格。
- **2026-09-07 切换纸张后页码位置未更新**：用户从较小纸张切换到 100×150mm 后，页码「1-1」仍停留在原位置。根因是 hiprint 的 `setPaper` 内部调用 `designPaper.resize`，仅在页码超出边界时才做钳制，且 resize 使用的是 `designPaper` 自己保存的 `paperNumberLeft/Top`；在 `setPaper` 之后再改 `editingPanel` 的值无法生效。修复：
  - `use-hiprint.ts` 新增 `resetPaperNumberPosition(template)`，在 `setPaper` 之前把 `editingPanel.designPaper.paperNumberLeft/Top` 与 `editingPanel.paperNumberLeft/Top` 都设成极大值。
  - `index.vue` 的 `applyPaper(true)` 先调用 reset 再调用 `setPaper`，让 hiprint 自动钳制回新纸张右下角默认值（width-30pt、height-22pt）。
  - 初始加载时调用 `applyPaper()`（不重置），避免覆盖用户手动调整过的页码位置。
- **2026-09-07 左侧面板样式重构**：用户反馈左侧字段面板样式不明显、基础元素未折叠、卡片之间有间隙、标题未居中且折叠状态出现空白白条。将 `field-panel.vue` 从 `NCollapse` 改为原生 `<details>`/`<summary>` 自实现的类菜单折叠面板（彻底规避 NCollapse 折叠态残留白块的坑）；分组项上下相连、无间距、无圆角，标题统一 40px 高度并垂直居中，自定义三角箭头随展开旋转；字段项改成白底小卡片带缩进；默认全部折叠（用户要求）；已适配暗黑模式。
- **2026-09-07 画布溢出滚动条**：用户反馈把元素拖到画布外会出现整页滚动条。根因：滚动容器是 `AdminLayout` 的布局主滚动元素（id=`__SCROLL_EL_ID__`，来自 `@sa/materials` 的 `LAYOUT_SCROLL_EL_ID`）。修复：页面挂载时给 `body` 加 `print-design-no-scroll` 类，CSS 中仅对 `#__SCROLL_EL_ID__` 设置 `overflow: hidden !important`；组件卸载时移除 body 类。中间画布容器保持 `overflow-visible`。后续发现同时隐藏 `html/body` 会干扰 hiprint 坐标计算，已去掉。
