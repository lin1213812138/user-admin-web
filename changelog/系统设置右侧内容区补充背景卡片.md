# 系统设置右侧内容区没有背景

## 问题现象

系统设置 - 录单格式等左右布局的 tab 页（`MasterDetail` 组件）：左侧列表包在 `NCard` 里（有白色背景），右侧字段映射区 / 表单区是裸 `div`，没有背景，与左侧视觉不对称，整体看起来「右侧没包上背景」。

## 根因

`src/views/system-manage/setting/components/MasterDetail.vue` 的右侧容器原本是：

```html
<div class="min-w-0 flex-1 flex-col p-16px">
  <div class="flex items-center justify-between pb-12px">操作栏</div>
  <div class="min-h-0 flex-1 overflow-auto"><slot /></div>
</div>
```

只有一层 `div`，没有 `NCard`，所以右侧是透明的、无背景卡片。

## 修复

把右侧整块用 `NCard` 包裹，与左侧列表卡片对称统一：

```html
<div class="min-w-0 flex-1 flex-col">
  <NCard class="h-full" :content-style="{ padding: '0', height: '100%', display: 'flex', flexDirection: 'column' }">
    <div class="flex items-center justify-between px-16px py-12px border-b-1 border-[#ebeef5]">
      操作栏（添加/编辑/删除 + operation-extra 槽）
    </div>
    <div class="min-h-0 flex-1 overflow-auto px-16px py-16px">
      <slot />
    </div>
  </NCard>
</div>
```

要点：

- `NCard` 占满高度（`h-full`），内部用 `content-style` 设为纵向 flex，让操作栏固定顶部、内容区可滚动。
- 操作栏下方加 `border-b-1 border-[#ebeef5]` 分隔线，与左侧卡片的标题区视觉呼应。
- 去掉右侧外层 `p-16px`，改由 `NCard` 内部 `px-16px py-16px` 控制内容间距，使左右两卡片高度与边缘对齐、风格一致。

## 影响范围

`MasterDetail.vue` 被 6 个设置 tab 复用（录单/打印/导出/通知/初始化/站点扫描），它们的右侧详情区都会随之获得背景卡片。
