# 快速搜索栏加阴影（跟随主题圆角）

> 日期：2026-09-16
> 来源：用户「快速搜索栏，能不能加点boxshaw」（box-shadow）+「而且没有使用到全局border-radius」

## 需求

给 `Table` 组件的 `search-action` 快速搜索栏区域加阴影/卡片感；且圆角必须使用全局主题圆角，不能写死。

## 定位

- `card-wrapper` 是 UnoCSS shortcut（`uno.config.ts:22`）= `rd-8px shadow-sm`：阴影 OK，但 `rd-8px` 写死圆角。
- 全局圆角机制：`themeRadius: 6`（`src/theme/settings.ts:8`）→ `theme/shared.ts:260` 注入 naive `common.borderRadius` → NCard 根元素自带 `border-radius: var(--n-border-radius)` 自动跟随。
- `card-wrapper` 的 `rd-8px` 与 NCard 主题圆角是同特异性覆盖（与 NInput width 同机制）→ 用 `card-wrapper` 会让圆角固定 8px、不跟随 `themeRadius`（用户指出的点）。

## 方案（用户确认「可以」）

仅改 `table.vue` 的 search-action 区域：外层包 `NCard`（`:bordered="false"` + `shadow-sm`），**不用 `card-wrapper`**（舍弃其写死的 `rd-8px`），圆角交给 NCard 主题圆角；`content-style: 12px 16px` 收紧内边距（单行内容避免 NCard 默认 padding 显得空）：

```vue
<div v-if="$slots['search-action']" class="mb-12px">
  <NCard :bordered="false" class="shadow-sm" :content-style="{ padding: '12px 16px' }">
    <slot name="search-action" :refresh="refresh" />
  </NCard>
</div>
```

- 圆角 = `themeRadius`（当前 6px），主题设置改圆角会跟着变；白底 + 暗黑模式自动适配（NCard cardColor）。
- 业务插槽内容零改动（站点页现有 `flex-y-center gap-8px` 内容直接进卡片）。

## 附带说明（未改，由用户后续决定）

`card-wrapper` shortcut 全项目通用（SearchBar 等），均被 `rd-8px` 覆盖为固定 8px 圆角、未跟随 `themeRadius`；若要全局统一跟随主题圆角，应改 `uno.config.ts` shortcut 为 `shadow-sm`——影响面大，本轮不动。
