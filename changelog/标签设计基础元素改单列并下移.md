# 标签设计左侧面板基础元素改单列并下移

> 自研标签设计器（`label-designer`，非 hiprint 的 `print-design`）。
> 设计阶段遵循 AGENTS.md 规则 2（本机无 `brainstorming` skill，以等价的结构化设计 + 用户确认替代）：**用户已确认文案样式取方案 A（左对齐 + 灰色）**，已实施并截图核对。

## 需求（用户截图）

截图标注两件事：

1. 「基础元素」区块的 8 个项（文本 / 长文本 / 图片 / 条形码 / 二维码 / 矩形 / 横线 / 竖线）当前是**两列网格 + 文字居中**，要改成**和下面「业务字段」一样的样式**（单列、整行、左对齐的圆角描边条目）。
2. **整个「基础元素」区块移到最下面**（即面板顺序变为：业务字段 → 基础元素）。

## 现状

`modules/field-panel.vue`，纯模板结构：

- `NCollapse` 的 `:default-expanded-names="['basic', 'fields']"`；**`basic` 分组在前、`fields` 分组在后**。
- 基础元素：`<div class="grid grid-cols-2 gap-8px">` + 条目 `class="… p-8px text-center text-13px"`，两列、居中。
- 业务字段：`<div class="flex flex-col gap-8px">` + 条目 `class="… p-8px text-13px"`（无 `text-center`），内含 `<span class="text-#999">{{label}}</span><span class="ml-4px text-#bbb">{{key}}</span>`，整行左对齐。

两者盒子类名本就接近（`cursor-grab rounded border border-#e5e7eb bg-white p-8px text-13px active:cursor-grabbing dark:border-#2a2a2a dark:bg-#1f1f1f`），差异只有：**容器布局（grid 2 列 / flex 单列）、`text-center`、以及业务字段多一个灰色 key 后缀**。

## 设计（待确认）

`modules/field-panel.vue`（**仅模板，不动逻辑、不动 i18n、不动 `basic-elements.ts` 清单**）：

1. **顺序对调**：`NCollapseItem name="fields"`（业务字段）放到前面，`name="basic"`（基础元素）放到最后；
   `:default-expanded-names` 同步改为 `['fields', 'basic']`（仅顺序对齐，两个分组默认仍都展开）。
2. **基础元素容器**：`grid grid-cols-2 gap-8px` → `flex flex-col gap-8px`（与业务字段一致）。
3. **基础元素条目**：去掉 `text-center`，文字包一层与业务字段同款的灰色 span（`text-#999 dark:text-#777`）；盒子其余类名与业务字段条目完全对齐（含 `cursor-grab` / `active:cursor-grabbing`）。
4. **不动的部分**：`draggable="true"` + `@dragstart="onDragStart(...)"`（含上一步接入的 `startDragGhost`）原样保留，拖拽行为与「未落纸回落动画」不受影响。

改完后面板形态：

```
业务字段               ⌄      ← 在上
  单号        orderNo
  单号（条形码） orderNoCode
  …
基础元素               ⌄      ← 移到最下面
  文本
  长文本
  …
```

## 实施结果（用户确认方案 A）

`modules/field-panel.vue`，仅模板改动：

- 两个 `NCollapseItem` 顺序对调：`fields`（业务字段）在前、`basic`（基础元素）在后；`:default-expanded-names` 同步改为 `['fields', 'basic']`（两个分组默认仍都展开）。
- 基础元素容器 `grid grid-cols-2 gap-8px` → `flex flex-col gap-8px`。
- 基础元素条目去掉 `text-center`，类名与业务字段条目逐字对齐（`cursor-grab rounded border border-#e5e7eb bg-white p-8px text-13px active:cursor-grabbing dark:border-#2a2a2a dark:bg-#1f1f1f`），文案包一层 `<span class="text-#999 dark:text-#777">`。
- 未动 `draggable` / `onDragStart` / `startDragGhost` / `basic-elements.ts` / i18n，拖拽与「未落纸回落动画」不受影响。

## 遗留

- 面板整体仍无搜索/过滤（本次范围外）。
