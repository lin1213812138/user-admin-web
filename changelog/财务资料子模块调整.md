# 财务资料子模块调整

> 用户要求把「财务资料（`data-manage_finance`）」按截图改为 4 个子模块：费用类型 / 结算方式 / 银行账户 / 结算币种及汇率。

## 现状

财务资料为「单页 + 左侧 `ArchiveSwitch` 切换」结构（非路由子页面），原本 4 个子模块为：

- 结算账户 `account`
- 币种 `currency`
- 税率 `tax`
- 结算方式 `settlement`

## 设计决策（用户授权「按推荐字段先实现」）

1. **移除「税率(tax)」，新增「费用类型(expense-type)」**：截图里没有税率，取而代之的是费用类型。
2. **费用类型字段（推荐口径 = 归档类统一带编码）**：`code`（类型编码）+ `name`（类型名称）+ `status` + `remark`（与 `settlement` 同属轻量枚举，但沿用 account 的 `code` 习惯）。
3. **顺序严格按截图**：费用类型 → 结算方式 → 银行账户 → 结算币种及汇率。
4. **标题文案对齐截图**：
   - `account`：`结算账户` → `银行账户`
   - `currency`：`币种` → `结算币种及汇率`
   - `settlement`：保持「结算方式」
5. 子模块是页内切换、**不是路由**，故 `src/router/elegant/routes.ts` 不变，无需重跑路由生成。
