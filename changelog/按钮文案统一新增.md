# 按钮文案统一为「新增」

日期：2026-09-15

## 背景

用户："按钮都不要叫添加一行都要叫新增"——「系统设置 → 初始化数据」与「系统设置 → 轨迹抓取配置 → 轨迹改造 / 轨迹关键词」
的工具栏新增按钮文案此前为「添加一行」（原型截图用语），要求全站统一为「新增」。

## 改动

仅改两个 i18n key 的值（key 名 `addRow` 保留，使用点与组件零改动）：

| 文件                         | key                                       | 原值     | 新值 |
| ---------------------------- | ----------------------------------------- | -------- | ---- |
| `src/locales/langs/zh-cn.ts` | `page.manage.setting.traceCapture.addRow` | 添加一行 | 新增 |
| `src/locales/langs/zh-cn.ts` | `page.manage.setting.initData.addRow`     | 添加一行 | 新增 |
| `src/locales/langs/en-us.ts` | `page.manage.setting.traceCapture.addRow` | Add Row  | Add  |
| `src/locales/langs/en-us.ts` | `page.manage.setting.initData.addRow`     | Add Row  | Add  |

生效的按钮共 3 处：`InitDataCategory.vue`、`TraceTransformTable.vue`、`TraceKeywordTable.vue`；
新值与既有 `common.add`（新增 / Add）一致。

## 不改动

- 不改组件引用与 key 名（`addRow`）、不改 `typings/app.d.ts`（类型仍为 `string`）；
- 其它模块的「新增」按钮本就使用 `common.add` / 自有文案，不在本次范围。

## 验证

- `pnpm typecheck` 0 错误；改动文件 oxfmt / oxlint 0；
- 无浏览器端到端，视觉确认由用户进行。
