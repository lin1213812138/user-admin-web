# 标签设计器：左侧拖元素光标改十字箭头

> 用户需求：「左侧拖元素能不能使用十字剪头？不要使用手」。

## 现状

`panels/field-panel.vue` 的两组条目（业务字段、基础元素）光标：

```
cursor-grab ... active:cursor-grabbing
```

- hover 显示**张开的手**（`grab`）；
- 按住时显示**握拳**（`grabbing`）。

## 改动

- `cursor-grab` → **`cursor-move`**（四向十字箭头 ✥），两组条目共 2 处（class 串相同，`replace_all` 一次替换）；
- 删除 `active:cursor-grabbing`：移动光标没有「按压态」语义，按住期间保持四向箭头即可，避免按下一瞬间又变回握拳。

## 范围说明

- **只改左侧面板拖拽条目**；`design-canvas.vue` 的 `cursor: grab` 与 `.panning * { cursor: grabbing }`（画布平移的抓手）**保持不动**——那是「平移画布」语义，与「拖出元素」不同。
