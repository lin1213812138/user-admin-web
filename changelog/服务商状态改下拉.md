# 服务商新增/编辑界面状态字段改为下拉

> 日期：2026-09-19 ｜ 状态：已实施 ｜ 模块：`data-manage/ship/modules/provider`

## 背景

用户要求「服务商新增界面状态改成下拉的」。

## 定位

`src/views/data-manage/ship/modules/provider/ProviderOperateDrawer.vue` 中，状态字段（`status`）原本是 `NFormWrap` 的 `type:'switch'`（启用/禁用，值 1/0），用户希望改用下拉选择。

## 实施

- `formItems` 的 `status` 项由 `type:'switch'`（含 `checkedValue:1` / `uncheckedValue:0` / `checkedText` / `uncheckedText`）改为 `type:'select'`，`options` 复用既有 i18n：`{ label: $t('common.enable'), value: 1 }` / `{ label: $t('common.disable'), value: 0 }`，并 `filterable:false`。
- 数据契约不变：`status` 仍为 `number`（1=启用 / 0=禁用），`emptyForm` 默认 `1`、`openEdit` 回传 `row.status`，提交逻辑零改动。
- 无需新增 i18n key（启用/禁用 沿用 `common.enable`/`common.disable`）。

## 验证

- `pnpm typecheck` 0 / `pnpm lint` 0 error（link.vue 既有 2 warning 无关）。
